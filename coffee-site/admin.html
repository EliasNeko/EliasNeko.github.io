加密后的名单需要站长口令才能打开，口令不会保存在任何地方。

一、从服务器拉取名单

密钥在 server/admin.key 里（或环境变量 ADMIN_KEY），只用于这一次请求。名单返回后可直接用下面的「加密并下载」存档。

三、加密名单（上传到 GitHub 的那份）

加密用 AES-GCM，口令只在加密的瞬间使用，不会写进文件。口令遗失后，这份名单无法恢复，建议另行保存。

四、解密查看（验证用）
