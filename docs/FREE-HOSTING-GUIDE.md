# 免费上线说明

> 一句话：**不用买服务器。** 现在这套东西有三种零成本用法，按“省事程度”从上往下选。

---

## 一、先搞清楚：网站分两半

| 部分 | 放在哪 | 要不要服务器 |
|---|---|---|
| 网页（HTML/CSS/JS） | GitHub Pages，已经在线 | 不要，GitHub 免费给 |
| 会员接口（Java） | 要有台机器一直跑着 | 要么你电脑，要么免费云主机 |

所以「花钱买服务器」这件事，只在你想让**别人随时注册、你不用开电脑**的时候才需要。**而现在不用。**

---

## 二、方案 A：本机 + ngrok（0 元，5 分钟，首选）

**原理**：Java 跑在你电脑上，ngrok 给它开一个外网门牌号。

**步骤**：

1. 装 ngrok（已经装了跳过）
   ```powershell
   winget install ngrok.ngrok
   ```
2. 去 ngrok.com 注册一个免费账号（不用信用卡）
3. 复制页面给你的 authtoken，执行一次：
   ```powershell
   ngrok config add-authtoken 你的token
   ```
4. 后台里的 **Domains** 页面，免费领一个固定域名（形如 `abc123.ngrok-free.app`）
5. 打开根目录的 `start-site.bat`，把这一行改成你的域名：
   ```
   set "NGROK_DOMAIN=abc123.ngrok-free.app"
   ```
6. 双击 `start-site.bat`

**然后就有两个地址**：

- 自己用：`http://127.0.0.1:8080/coffee-site/index.html`
- 发给别人：`https://abc123.ngrok-free.app/coffee-site/index.html`

> 通过 ngrok 地址打开时，网页和接口是同一个地址，**不用改 config.js**，也不会跨域。

**代价**：电脑得开着、Java 窗口不能关。电脑一关，别人就打不开（网页本身还在 GitHub 上，只是注册/登录失效）。

---

## 三、方案 B：Oracle 永久免费云主机（0 元，要绑卡验证）

适合「电脑关了别人也能注册」。

- Oracle Cloud 的 Always Free 套餐：1 核 1G 的小机器，永久免费，**不会扣钱**，注册时验证信用卡（约 ¥1 预授权，会退回）
- 上去之后：装 JDK 17 → 上传 `server/` → `java Server` → 开 8080 端口
- 数据存在那台机器上，不会丢

这条路大概要 30–60 分钟，等你有空我带你一步步来。

---

## 四、方案 C：Render 免费实例（不建议用来存会员数据）

Render 免费 Web Service 能跑 Java（用 Dockerfile），地址固定、不用开电脑，但有三个坑：

1. **15 分钟没人访问就休眠**，下次打开要等 30–50 秒
2. **磁盘是临时的**：重新部署或重启，`users.jsonl` 里的会员数据会丢
3. 想要持久化就得接数据库（又要多学一样）

所以：**当演示可以，存真人注册信息不推荐。**

---

## 五、现在到底该怎么做

1. 今天想给同学看：走**方案 A**，双击 `start-site.bat` 就行
2. 想要 24 小时在线：等周末，走**方案 B**
3. 想先上线看看效果：把 `coffee-site/config.js` 里的地址改成你的 ngrok 域名，推上去，GitHub Pages 也会调后端

---

## 六、钱的问题

| 项目 | 费用 |
|---|---|
| GitHub Pages 托管网页 | 0 元 |
| ngrok 免费账号 + 1 个固定域名 | 0 元 |
| Oracle 永久免费云主机 | 0 元（要验证卡） |
| 域名（可选，想要自己的名字） | 约 30–60 元/年，**不买也能用** |

**结论：一分钱不花，也能让同学正常注册登录。**
