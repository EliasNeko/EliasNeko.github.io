Kotlin：安卓现在的官方语言

跑在 JVM 上，能直接用 Java 的库，但空指针在类型里就被拦住了。

11 节难度 中等更新 2026-10-23

01它是什么

Kotlin 跑在 JVM 上，能直接用 Java 的库，但写起来短很多：空指针在类型里就被拦住了，不用写一堆 getter/setter。安卓现在的官方语言就是它。

学了 Java 再来学 Kotlin，会像从手动挡换到自动挡——但你得先知道自动挡为什么不会熄火。

02装好、跑起来

需要 JDK（17 就行），再装 Kotlin 编译器：

kotlinc -version
kotlinc hello.kt -include-runtime -d hello.jar
java -jar hello.jar
fun main() {
    println("你好，Kotlin")
}
坑：只装 Kotlin 不装 JDK 会提示找不到 java；java -version 先确认 JDK 在 PATH 里。

03val 和 var

val name = "咖啡"      // 不能重新赋值
var price = 32        // 可以
price = 35

val list = mutableListOf(1, 2)
list.add(3)           // 引用没变，内容可以变

val 锁的是「这个变量指向谁」，不是「对象内容不能改」。

坑：val x = 0; x = 1 编译不过；但 val m = mutableListOf(); m.add(1) 可以。别把两者混为一谈。

04空安全

var nickname: String? = null

println(nickname?.length)        // null，不崩
println(nickname ?: "没起名")     // 空的时候给默认值

// println(nickname!!.length)     // 真为空时抛异常，尽量别用

String? 表示「可能是空」，编译器会逼你处理这种情况；String 表示「一定不是空」。

坑：加 !! 等于跟编译器说“我保证不空”，一旦空了就是 NullPointerException。能不用就不用。

05函数

fun add(a: Int, b: Int = 1): Int {
    return a + b
}

fun greet(name: String) = "你好，$name"

val r = add(2)      // b 用默认值
val s = add(b = 3, a = 4)   // 具名参数

单表达式函数可以省略大括号和 return，= 后面直接是结果。

06类、data class

data class Coffee(val name: String, val price: Int)

val c = Coffee("耶加雪啡", 32)
println(c)                      // Coffee(name=耶加雪啡, price=32)
println(c.copy(price = 35))     // 只改价格

class Shop {
    var stock = 10
        private set
    fun sell() { if (stock > 0) stock-- }
}

data class 自动生成 equals、hashCode、toString、copy，省掉一大片样板代码。

坑：普通 class 打印出来是 Shop@1a2b3c，不是内容；要比较内容必须用 data class 或自己写 equals。

07when

fun price(kind: String): Int = when (kind) {
    "咖啡" -> 32
    "茶" -> 18
    "果汁", "汽水" -> 22
    else -> 0
}

when 是表达式，可以直接赋值、直接 return，比 Java 的 switch 灵活得多。

08集合

val nums = listOf(3, 1, 2)
println(nums.sorted())          // [1, 2, 3]
println(nums.map { it * 2 })    // [6, 2, 4]
println(nums.filter { it > 1 })

val m = mutableMapOf("咖啡" to 10)
m["茶"] = 4
for ((k, v) in m) println("$k: $v")

listOf 只读，mutableListOf 可改。能用只读就用只读。

09扩展函数和 lambda

fun String.shout() = this.uppercase() + "!"
println("coffee".shout())

fun repeat(n: Int, action: () -> Unit) {
    repeat(n) { action() }
}

repeat(3) { println("再来一杯") }

扩展函数不用改原类就能加方法；lambda 让「把一段逻辑当参数传」变得很自然。

坑：扩展函数是静态解析的，不会真的改到类里，也不能访问 private 成员。

10动手项目：控制台记账

要求：命令 add 32 咖啡 记一笔，list 列出并算总额，del 2 删第二条，数据存 book.txt。

验收：加三笔、删一笔、总额正确；金额写错给提示不崩；重开程序数据还在。

提示：

  • 读参数用 readLine() 做交互，或 args 做命令行
  • toIntOrNull() 判断金额是否合法
  • 读写文件用 java.io.File，Kotlin 能直接调

11往哪走

想写安卓就上 Android Studio；想写后端看 Ktor；协程（suspend）是它处理异步的方式，比线程轻。

一句话：Kotlin 把 Java 里那些「必须写但没信息量」的代码删掉了，留下的都是要你想清楚的部分。
