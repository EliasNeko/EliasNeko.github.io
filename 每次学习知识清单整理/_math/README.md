# 数学教材 · 生成器

六册数学页的「章 → 节」正文由这里生成，不要再直接改 HTML。

## 文件

| 文件 | 对应 |
|---|---|
| build_math.py | 生成器：读数据、重写页面的章节正文、校验标签 |
| data_g1.py | 高一 · 人教A版 必修一 + 二 |
| data_g2.py | 高二 · 选择性必修一 + 二 |
| data_g3.py | 高三 · 选择性必修三 |
| data_c1.py | 初一 · 湘教版七上 + 七下 |
| data_c2.py | 初二 · 湘教版八上 + 八下 |
| data_c3.py | 初三 · 湘教版九上 + 九下 |
| check.py | 检查六册的章数、节数、空公式、重复 id、标签平衡 |

## 改一节

数据文件里一节就是一行字符串，用 § 分成五段：

```
"1.1 集合的概念§讲什么（定义、条件、符号）§关键公式§怎么用§易错"
```

后三段可以为空，但「讲什么」必须写。正文里不要出现 § 字符，也不要写 HTML 标签（生成器会自动转义）。

## 重建

在 _math 目录运行：

```
python build_math.py g1
python check.py
```

g1 / g2 / g3 / c1 / c2 / c3 对应上表。生成器会覆盖对应页面的整段章节正文，保留页头、公式总表、章节目录、二级结论、期末模拟和页脚。
