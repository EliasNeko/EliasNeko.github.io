学习路线图

不用所有东西都学。挑一条能走通的，走完再换线。

① 前端 · 做看得见的东西 HTML / CSS 打底 → JavaScript 让页面动起来 → 基础全书当手册 → 咖啡店项目练手 → 再补 Git 和 Node.js
② 后端 · 让数据有地方去 Java 或 Python 任选一门 → MySQL 存数据 → Git 管版本 → Linux 会几手命令 → 把咖啡店的订单接上真接口
③ 数据 / 考级 · 稳一点的路 Python 打底 → MySQL 会查会建表 → Anaconda 管环境 → 按二级大纲刷真题 → 有闲再碰数据结构

每条线都不要求你先把另一条学完。卡住了就回目录，从最小的那一节重新开始。
