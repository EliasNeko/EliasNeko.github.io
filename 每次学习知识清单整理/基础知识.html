01三种语言怎么分工

同一张网页，三种语言各管一段：HTML 说「有什么」，CSS 说「长什么样」，JS 说「能干什么」。

<button id="buy" class="btn">加入购物车</button>

.btn { padding: 10px 20px; background: #38bdf8; }

document.getElementById("buy").onclick = function () {
  alert("已加入！");
};
备注：三段代码放在同一个页面里，就是一个能看、能点、还不难看的按钮。三层各干各的，互不打架。

02一个页面是怎么被拼出来的

浏览器先把 HTML 读成一棵「树」（DOM），CSS 给树上的节点化妆，JS 在树上增删改。三个文件，靠两行标签连起来：

<head>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <script src="main.js"></script>
</body>
备注：CSS 放 <head>，页面一出来就是化好妆的；JS 放 </body> 前，保证它运行时元素已经存在。

03标签、元素、属性、值

这四个词会一直出现，先分清：

<a href="https://example.com" target="_blank">点我</a>
 ↑        ↑属性名              ↑值              ↑内容
 标签名                    （自闭合标签：<img src="a.png" alt="">）
叫法意思例子
标签尖括号里的名字a、p、div
元素从开标签到闭标签的整块<p>你好</p>
属性给标签加的设置项href、class、id
值属性的具体内容，通常加引号href="index.html"

04文档骨架

每张网页都是同一个开头，背下来不亏：

<!DOCTYPE html>
<html lang="zh-CN">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>页面标题</title>
    <link rel="stylesheet" href="style.css">
  </head>
  <body>
    这里放看得见的东西
  </body>
</html>
备注：中文乱码先查 charset；手机上排版错乱先查 viewport——这两行没写，后面写再多都白搭。

05文本：标题、段落、强调

<h1>页面主标题</h1>
<h2>章节标题</h2>
<p>一个段落，段落之间会自动留空。</p>
<p>这里有<strong>重要的话</strong>和<em>语气加重</em>。</p>
<br>   换行（不产生新段落）
<hr>   一条分隔线
备注：h1 一页只写一个，它是这张页面的“门牌”；别用 br 去凑段距，那是 CSS 的活。

06列表：ul / ol / dl

<ul>
  <li>无序项一</li>
  <li>无序项二</li>
</ul>

<ol>
  <li>第一步</li>
  <li>第二步</li>
</ol>
备注：导航栏看着是一排文字，本质是个 ul——因为「一组链接」就是列表。把 list-style: none 一加，小圆点就没了。

07链接 <a>

<a href="https://example.com">普通链接</a>
<a href="https://example.com" target="_blank">新标签页打开</a>
<a href="#menu">跳到本页 id=menu 的位置</a>
<a href="mailto:hi@example.com">发邮件</a>
<a href="file.pdf" download>下载文件</a>
备注：href 里的 # 决定「打开新页面」还是「本页跳转」。少了它，浏览器会去找一个同名文件，然后报错。

08图片 <img>

<img src="coffee.jpg" alt="一杯拿铁" width="320" loading="lazy">

<figure>
  <img src="shop.jpg" alt="门店">
  <figcaption>田心南校区的午后</figcaption>
</figure>
备注：alt 不是可选项：图片挂了、网差了、读屏软件读的时候，全靠它。loading="lazy" 让图片滚到眼前才加载，省流量。

09语义化布局

用「意思对」的标签搭页面，而不是一屏的 div：

<header>  页头（logo、导航）</header>
<nav>     导航</nav>
<main>
  <section>  一个独立区块</section>
  <article>  一篇能独立存在的内容</article>
  <aside>    侧边栏</aside>
</main>
<footer>  页脚</footer>
备注：语义标签不改变外观，改变的是「可读性和可维护性」。半年后回来，header 和 div 哪个更好找？

10表格 <table>

<table>
  <caption>本月销量</caption>
  <thead>
    <tr><th>产品</th><th>数量</th></tr>
  </thead>
  <tbody>
    <tr><td>拿铁</td><td>120</td></tr>
    <tr><td>美式</td><td colspan="2">95</td></tr>

备注：表格只用来放「数据」，不要拿它排版页面。手机上看表格会挤，记得配 overflow-x: auto 让它自己横向滚。

11表单（上）：输入框

<form action="/submit" method="post">

  <input id="name" name="name" type="text" placeholder="请输入昵称" required>

  <input type="email" name="email" placeholder="邮箱">
  <input type="password" name="pwd" placeholder="密码">
  <button type="submit">提交</button>
</form>
type用途
text / email / password单行文本 / 邮箱 / 密码
number / range数字 / 滑块
date / time日期 / 时间选择
checkbox / radio多选 / 单选
file / color文件 / 取色器

12表单（下）：选择与多行

<select name="size">
  <option value="m">中杯</option>
  <option value="l" selected>大杯</option>
</select>

<textarea name="note" rows="4" placeholder="备注…"></textarea>

<fieldset>
  <legend>口味</legend>
  <label><input type="radio" name="taste" checked> 原味</label>
  <label><input type="radio" name="taste"> 香草</label>
</fieldset>
备注：label 是隐形的贴心：点文字也能选中输入框。name 才是提交到后端时用的键名，id 只是页面内的名字。

13全局属性

几乎所有标签都能用的属性：

<div id="app" class="box big" style="color:red" title="提示文字"
     data-id="42" hidden lang="zh">内容</div>
属性作用
id全页唯一，JS 找它、锚点跳它
class可重复，给 CSS 和 JS 分组
style内联样式，优先级很高，能少用就少用
data-*存自定义数据，JS 用 dataset 读
hidden直接藏起来，等价于 display:none

16块级与行内

类型代表特点
块级 blockdiv p section h1独占一行，能设宽高
行内 inlinespan a strong跟文字排一行，宽高不生效
行内块 inline-blockimg button input排一行，但能设宽高

17CSS 语法与三种写法

.card {
  color: #e8f0fd;        /* 属性: 值; */
  padding: 24px;
}

/* 三种引入方式 */
<link rel="stylesheet" href="style.css">     外部（推荐）
<style> .card { … } </style>                内部
<div style="color:red">…</div>              内联（优先级高，少用）
备注：外部样式表能被所有页面共用，改一处全站变。这就是为什么我们后来把样式抽成了 lesson.css。

:not(.x)除了 .x 以外的

19优先级：谁说了算

行内 style          1000
#id                 100
.class / :hover      10
标签 / 伪元素          1

/* 同分时：写在后面的赢 */
p { color: red; }
p { color: blue; }   /* 生效 */

/* 最后的手段，别滥用 */
p { color: green !important; }
备注：样式没生效，先看「这条规则有没有被划掉」——被划掉是优先级问题，压根没出现是选择器没匹配上。两种情况解法完全不同。

20盒模型

div {
  width: 300px;
  padding: 20px;
  border: 1px solid #38bdf8;
  margin: 16px;
  box-sizing: border-box;   /* 宽度包含 padding 和 border */
}

/* 几乎所有项目的起手式 */

备注：不加 border-box，width:300 + padding:20×2 + border:1×2 实际占 342px——「为什么布局总是差几个像素」多半是这儿。

备注：中文正文行距 1.8–2.0 比默认舒服得多；letter-spacing 用在标题上像“留白”，用多了会散。

25边框、圆角、阴影

.card {
  border: 1px solid rgba(96, 165, 250, 0.2);
  border-radius: 18px;
  box-shadow: 0 20px 40px rgba(2, 6, 15, 0.55);
}

.btn { border-radius: 999px; }   /* 胶囊按钮 */

.circle {
  width: 80px; height: 80px;
  border-radius: 50%;
}
备注：阴影的四个值是 水平偏移 垂直偏移 模糊 颜色。写成 0.20px 会整条失效——小数点位置错了，浏览器一声不吭。

26display：元素的性格

.a { display: block; }         独占一行
.b { display: inline; }        跟着文字走
.c { display: inline-block; }  排一行，但能设宽高
.d { display: flex; }          弹性布局
.e { display: grid; }          网格布局
.f { display: none; }          从页面上彻底消失
备注：display:none 是“不存在”，visibility:hidden 是“隐身但占位”。做动画时这个区别很重要。

27定位与层级

.parent { position: relative; }    /* 给子元素当参照 */
.badge {
  position: absolute;             /* 相对最近的定位祖先 */
  top: 8px; right: 8px;
  z-index: 2;                     /* 数字大的在上面 */
}
.nav  { position: fixed; top: 0; }  /* 钉在窗口上 */
.title{ position: sticky; top: 0; } /* 滚到顶部时粘住 */
备注：absolute 会到处乱跑，是因为它的父元素没写 position: relative——找不到参照物，就相对整个页面定位了。

28Flex 弹性布局

.box {
  display: flex;
  flex-direction: row;      /* row 横 / column 竖 */
  justify-content: space-between;  /* 主轴 */
  align-items: center;             /* 交叉轴 */
  flex-wrap: wrap;                 /* 放不下就换行 */
  gap: 16px;                       /* 子元素之间的缝 */
}

.item { flex: 1; }   /* 平分剩余空间 */
.item { flex: none; width: 200px; }
备注：口诀：justify 管主轴，align 管交叉轴。中间一根隐形轴，方向由 flex-direction 决定——别死记“水平垂直”。

29Grid 网格布局

.cards {
  display: grid;
  grid-template-columns: repeat(3, 1fr);     /* 三列等宽 */
  gap: 24px;
}

/* 自适应：能放几列放几列，每列最小 260px */
.cards { grid-template-columns: repeat(auto-fit, minmax(260px, 1fr)); }

/* 指定位置 */
.wide { grid-column: 1 / 3; }   /* 从第 1 条线跨到第 3 条线 */
备注：Grid 是「二维」的，同时管行和列；Flex 是「一维」的，只管一条线。卡片墙用 Grid，导航条用 Flex。

30响应式：一套代码，两种设备

/* 手机优先：先写窄屏，再用 min-width 加宽 */
.box { padding: 16px; }

@media (min-width: 768px) {
  .box { padding: 40px; }
}

@media (max-width: 860px) {
  .toc { display: none; }        /* 手机上收起侧栏 */
  .grid { grid-template-columns: 1fr; }
}
备注：再加一层保险：<meta name="viewport" content="width=device-width, initial-scale=1">。没有它，手机上一切都按 980px 缩着排。

31过渡与变换

.btn {
  transition: transform 0.3s, background 0.3s;
}
.btn:hover {
  transform: translateY(-4px) scale(1.05);
  background: #0ea5e9;
}

.rotate { transform: rotate(45deg); }

备注：transition 写「要变什么、变多久」；transform 写「变成什么样」。这两个组合起来，就是网页里 80% 的“高级感”。

32关键帧动画

@keyframes float {
  0%   { transform: translateY(0); }
  50%  { transform: translateY(-12px); }
  100% { transform: translateY(0); }
}

.dot {
  animation: float 3s ease-in-out infinite;
}
备注：animation 后面依次是：名字、时长、缓动、循环次数。infinite 是无限循环——别给所有东西都加，会晕。

40函数

/* 普通函数 */
function add(a, b) {
  return a + b;
}

/* 箭头函数（更短，事件里常用） */
const add2 = (a, b) => a + b;

41数组与常用方法

const prices = [32, 28, 30];

prices.push(26);                    /* 末尾加一个 */
prices.length;                      /* 4 */
prices.map(p => p * 2);             /* [64,56,60,52] 逐个变换 */
prices.filter(p => p < 30);         /* [28,26] 筛选 */
prices.find(p => p === 30);         /* 30 找第一个 */
prices.reduce((a, b) => a + b, 0);  /* 116 累加 */
prices.join(" / ");                 /* "32 / 28 / 30 / 26" */
备注：渲染列表、算总价、做筛选——购物车基本就靠这几个方法。先把 map 和 filter 用熟。

42对象与解构

const coffee = {
  name: "拿铁",
  price: 28,
  size: "大杯"

备注：addEventListener 比 onclick = 好：同一个按钮可以绑多个监听，互不覆盖。

45事件委托：给一百个按钮只绑一次

document.querySelector(".list").addEventListener("click", function (e) {
  const btn = e.target.closest(".buy");
  if (!btn) return;
  console.log("买了：", btn.dataset.name);
});
备注：原理是「事件冒泡」：点按钮，事件会往上冒到父元素。所以只监听父元素，就能接住所有子元素的点击——列表再长也不怕。

48fetch：和后端说话

fetch("/api/orders", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ item: "拿铁", qty: 2 })
