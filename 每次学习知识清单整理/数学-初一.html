上册（2024 秋）

1第 1 章 有理数

负数、数轴、绝对值，再到四则运算与乘方。

1.1认识负数

生活里到处是相反意义的量：零上与零下、收入与支出、向东与向西。为了写清楚，我们先规定一种为正，另一种就在前面加「−」表示，这样的数叫负数；前面带「+」或不带符号的叫正数。0 既不是正数也不是负数，它是正负数的分界。一个数前面的「+」「−」叫符号。有理数可以按正数、0、负数分类，也可以按整数、分数分类。

正数 > 0 > 负数；整数和分数统称有理数；−a 的正负由 a 决定，a 为负数时 −a 是正数

怎么用：先定基准：把哪个量规定为正，另一个量就配相反的符号；写完数别忘带单位。判断一个数是正还是负，先看符号，再看数字。

易错：0 不是正数也不是负数，别把它塞进正数里；−a 不一定是负数，比如 a=−2 时 −a=2；表示相反意义的量，要先说清「规定什么为正」，否则正负号没有意义。

1.2数轴、相反数与绝对值

规定了原点、正方向和单位长度的直线叫数轴，三个要素缺一不可。每个有理数都能在数轴上找到唯一的点：正数在原点右边，负数在左边。只有符号不同的两个数叫互为相反数，0 的相反数是 0，几何上它们关于原点对称。一个数在数轴上对应的点到原点的距离，叫这个数的绝对值，记作 |a|。距离不会是负数，所以绝对值永远大于或等于 0。

|a| = a（a≥0），|a| = −a（a<0）；|a|≥0；a、b 互为相反数 ⇒ a+b=0，|a|=|b|；数轴上两点距离 = |a−b|

怎么用：画数轴三步：定原点、画正方向（箭头向右）、定单位长度。求相反数只改符号；求绝对值先判断正负，再按定义去符号。

易错：只画一条线、不标原点或单位长度，不算数轴；绝对值等于 3 的数是 3 和 −3，别只写 3；|−a| 与 −|a| 不是一回事。

1.3有理数大小的比较

在数轴上，右边的点表示的数总比左边的大，这是比较大小的总原则。由此得到：正数都大于 0，负数都小于 0，正数大于一切负数。两个负数比较，绝对值大的反而小。异号两数比较，正数大；同为正数看绝对值，同为负数也看绝对值，但结论反过来。分数比较可以通分，也可以化成小数。

数轴上右边的数大于左边的数；a>0>b ⇒ a>b；两个负数：|a|>|b| ⇒ a<b；a−b>0 ⇔ a>b

怎么用：先看符号：能定正负就直接定；两个都是负数，再比绝对值，绝对值大的那个反而小；分数先通分或化成小数；拿不准就画数轴标点。

易错：两个负数比大小，别按「绝对值大的大」写；−(−2) 要先化简成 2 再比；带分数化成假分数再通分，别只比整数部分。

1.4有理数的加法和减法

同号两数相加，取相同的符号，把绝对值相加；异号两数相加，取绝对值较大的加数的符号，再用较大的绝对值减去较小的绝对值；互为相反数的两个数相加得 0；一个数与 0 相加，仍得这个数。减去一个数，等于加上这个数的相反数，所以减法可以统一成加法。加法有交换律和结合律，可以凑整、凑相反数，算得更快。

a−b = a+(−b)；同号相加：符号不变，绝对值相加；异号相加：取绝对值大者的符号，大减小；a+(−a)=0

怎么用：减法先变加法：减号变加号，减数变它的相反数。多个数相加先分组：同号的放一起，相反数的放一起，能凑整的放一起。

易错：减去一个负数等于加上一个正数，如 3−(−5)=8，别算成 3−5=−2；异号相加别把绝对值相加；省略加号时符号跟着数走，−3+5 不能写成 3+5。

1.5有理数的乘法和除法

两数相乘，同号得正、异号得负，并把绝对值相乘；任何数与 0 相乘都得 0。多个不等于 0 的数相乘，负因数有奇数个时积为负，有偶数个时积为正。乘积为 1 的两个数互为倒数，0 没有倒数。除以一个不等于 0 的数，等于乘这个数的倒数。乘法和除法是同级运算，从左到右依次算。

同号得正、异号得负；a×0=0；a÷b = a×(1/b)（b≠0）；积的符号由负因数的个数决定

怎么用：先定符号，再算绝对值，分两步走。除法先变乘法：除号变乘号，除数变倒数。乘除混合从左往右，别抢着先算后面的乘法。带分数先化成假分数。

易错：0 不能作除数，也没有倒数；−2÷(−1/2)=4，除以分数别忘取倒数；多个数相乘先数负号个数，别算一个判一个。

1.6有理数的乘方

求 n 个相同因数的积的运算叫乘方，结果叫幂。aⁿ 中 a 是底数，n 是指数，aⁿ 读作 a 的 n 次方。正数的任何次幂都是正数；负数的奇次幂是负数，偶次幂是正数；0 的正整数次幂都是 0。把一个大于 10 的数写成 a×10ⁿ 的形式（1≤|a|<10，n 为整数），叫科学记数法，n 等于原数的整数位数减 1。

aⁿ = a·a·…·a（n 个 a 相乘）；负数的奇次幂为负、偶次幂为正；a×10ⁿ，1≤|a|<10；n = 整数位数−1

怎么用：先认底数：−2² 的底数是 2，(−2)² 的底数是 −2。先定符号，再算绝对值。科学记数法先点小数点，再看整数位数定 n。

易错：−2²=−4 与 (−2)²=4 完全不同；(−2)³=−8，负号别丢；科学记数法里 a 必须满足 1≤|a|<10，360000 写成 3.6×10⁵，不是 36×10⁴。

1.7有理数的混合运算

一个式子里同时有加、减、乘、除、乘方，叫混合运算。顺序是：先算乘方，再算乘除，最后算加减；有括号先算括号里的，按小括号、中括号、大括号的顺序；同级运算从左到右。合理使用运算律，比如加法交换结合律、乘法交换结合律、分配律，可以凑整、简化。

先乘方 → 再乘除 → 后加减；有括号先算括号；同级运算从左到右；a(b+c)=ab+ac

怎么用：动笔前先扫一遍全式，用铅笔标出运算顺序。每算一步抄一行，别跳步。能用分配律凑整就用。结果先定符号再算数。

易错：乘方只管紧挨着它的底数，−3² 不等于 9；减法和除法不满足交换律，别随便调顺序；括号前是负号，去括号时里面每一项都要变号。

本章核心概念
  • 0 既不是正数也不是负数，是正负数的分界
  • 数轴三要素：原点、正方向、单位长度
  • 相反数关于原点对称，绝对值是到原点的距离
  • 有理数运算先定符号，再算绝对值
关键公式 / 结论
|a| = a（a≥0），|a| = −a（a<0）；a−b = a+(−b)；a×10ⁿ（1≤|a|<10）
怎么记 / 怎么用
  • 比较大小：先看符号；两个都是负数，再比绝对值，绝对值大的反而小；拿不准就画数轴。
  • 加减法：减法先变加法，减号变加号、减数变相反数；多个数相加先分组凑整。
  • 混合运算：先乘方，再乘除，最后加减；有括号先算括号，每步只做一件事。
公式小题

计算 −3² + (−2)³ × (−1/2) − |−5|。

看解答
先算乘方：−3² 表示 3 的平方的相反数，3²=9，所以 −3²=−9；(−2)³=(−2)×(−2)×(−2)=−8。再算乘：(−8)×(−1/2)，同号得正，8×1/2=4。|−5|=5。原式 = −9+4−5 = −10，所以结果是 −10。
综合题（绝对值 + 分类讨论）

已知 |a|=3，|b|=2，且 a<b，求 a+b 的值。

看解答
由 |a|=3 得 a=3 或 a=−3；由 |b|=2 得 b=2 或 b=−2。逐组检验 a<b：a=3 时，3<2、3<−2 都不成立，舍去；a=−3 时，−3<2 成立，−3<−2 也成立。所以 a=−3、b=2 时 a+b=−1；a=−3、b=−2 时 a+b=−5。答案：−1 或 −5。
例题

计算 (−2)³ + |−3| × (−2)。

看解答
(−2)³=(−2)×(−2)×(−2)=−8；|−3|=3；3×(−2)=−6。原式 = −8+(−6) = −14。
易错点
  • −2² 与 (−2)² 不一样：前者是 −4，后者是 4
  • 两个负数比大小，绝对值大的反而小，别写反
  • 科学记数法的 a 必须满足 1≤|a|<10
小测（2 题）
  1. 计算 |−5| − (−3)
  2. 用科学记数法表示 360000
点开看答案
  1. |−5|=5；减去 −3 等于加 3，5+3=8。
  2. 360000 的整数位数是 6，n=6−1=5，所以 360000=3.6×10⁵。

2第 2 章 代数式

用字母表示数，列式、求值、整式加减。

2.1代数式的概念和列代数式

用运算符号把数和表示数的字母连接起来的式子，叫代数式。单独一个数或一个字母，也是代数式，比如 5、a。代数式里没有等号、不等号，所以 3x=6 不是代数式。书写有规矩：数字与字母相乘，乘号省略、数字写在前面；1 与字母相乘，1 省略；带分数要化成假分数；除法写成分数线。

单独一个数或字母也是代数式；a×b 写作 ab；1·a 写作 a；a÷b 写作 a/b；含等号、不等号的式子不是代数式

怎么用：列式先找关键词：和、差、积、商、倍、分、多、少。再定运算顺序，先读「的」字前后，弄清楚谁先算。写完代一个数进去检验。

易错：3x=6 含等号，不是代数式；「a 与 b 的平方和」是 a²+b²，「a 与 b 的和的平方」是 (a+b)²，顺序不同结果不同；带分数要化成假分数，别写成 1½x 这种形式。

2.2代数式的值

用具体数值代替代数式里的字母，按照代数式指定的运算算出的结果，叫代数式的值。同一个代数式，字母取不同的值，结果一般不同。代入时，负数、分数要加括号；字母的取值要让代数式有意义，分母含字母时分母不能为 0。求值的一般步骤是：代入、按顺序计算、写出结果。

先化简再代入，通常更省事；整体代入：把 a+b 看成一个整体；分母含字母时，字母取值必须使分母不等于 0

怎么用：一代二算三检查：负数加括号、分数加括号；先乘方，再乘除，最后加减；能化简的先化简；题目给 a+b=5 这种整体条件，就把 a+b 当一个数代进去。

易错：代入负数不加括号，x=−2 时把 x² 写成 −2²，会算成 −4，正确结果是 4；不按顺序算；分母为 0 时硬代，代数式其实没有意义。

2.3整式的概念

数与字母的积叫单项式，单独一个数或一个字母也是单项式。单项式中的数字因数叫系数，所有字母的指数和叫这个单项式的次数。几个单项式的和叫多项式，每个单项式叫项，不含字母的项叫常数项，次数最高的项的次数叫多项式的次数。单项式和多项式统称整式。

单项式的次数 = 各字母指数之和；多项式的次数 = 最高次项的次数；整式包括单项式和多项式；π 是数，不是字母

怎么用：找系数，先看数字因数，别丢符号；找次数，把每个字母的指数加起来，系数不算；判断整式，看分母里有没有字母，有就不是整式。

易错：系数要带符号，−3x²y 的系数是 −3，不是 3；次数只算字母指数，2x² 的次数是 2，不是 3；2/x、√x 都不是整式。

2.4整式的加法与减法

所含字母相同，并且相同字母的指数也相同的项，叫同类项。几个常数项也是同类项。合并同类项时，系数相加，字母和字母的指数都不变。去括号法则：括号前是「+」，去括号后各项符号不变；括号前是「−」，去括号后各项都要变号。整式的加减，就是先去括号，再合并同类项。

合并同类项：系数相加，字母部分不变；a+(b−c)=a+b−c；a−(b−c)=a−b+c；a(b+c)=ab+ac

怎么用：整式加减三步：去括号，看括号前的符号；找同类项，用不同的记号标出来；合并，系数相加。结果按某个字母降幂排列，看着更清楚。

易错：括号前是负号，只改第一项的符号；同类项只看字母和指数，与系数无关；合并时把指数也相加，3x²+2x² 写成 5x⁴ 就错了。

本章核心概念
  • 用字母表示数，字母可以表示任意有理数
  • 代数式不含等号、不等号，单独一个数或字母也是代数式
  • 单项式的系数带符号，次数是字母指数之和
  • 同类项：字母相同，相同字母的指数也相同
关键公式 / 结论
a(b+c) = ab+ac；a+(b−c) = a+b−c；a−(b−c) = a−b+c
怎么记 / 怎么用
  • 列代数式：先找关键词（和、差、积、商、倍、分），再定谁先算，最后代一个数检验。
  • 求值：先化简，再代入；负数、分数代入要加括号。
  • 整式加减：去括号看符号，标出同类项，系数相加，字母和指数不变。
公式小题

当 a=−2，b=3 时，求代数式 2a²−3ab+b² 的值。

看解答
先算各部分：a²=(−2)²=4，2a²=2×4=8；ab=(−2)×3=−6，−3ab=−3×(−6)=18；b²=3²=9。原式 = 8+18+9 = 35。
综合题（整式加减 + 整体代入）

已知 a−2b=3，求 3(a−2b)²−2(a−2b)+1 的值。

看解答
把 a−2b 看成一个整体，令 t=a−2b=3。原式 = 3t²−2t+1 = 3×3²−2×3+1 = 27−6+1 = 22。所以值是 22。
例题

化简 3(a−2b)−2(a−b)。

看解答
去括号：3a−6b−2a+2b。合并同类项：(3a−2a)+(−6b+2b)=a−4b。所以结果是 a−4b。
易错点
  • 去括号时括号前是负号，只变第一项
  • 合并同类项把字母的指数也相加
  • 系数带符号，−3x²y 的系数是 −3
小测（2 题）
  1. 化简 2a−3(a−1)
  2. 用代数式表示「x 的 2 倍与 3 的和」
点开看答案
  1. 去括号：2a−3a+3；合并同类项：(2−3)a+3=−a+3。
  2. 2x 是 x 的 2 倍，再加 3，得 2x+3。

3第 3 章 一次方程（组）

一元一次方程，再扩到二元、三元一次方程组。

3.1等量关系和方程

含有未知数的等式叫方程。只含一个未知数，未知数的次数是 1，并且等号两边都是整式的方程，叫一元一次方程。使方程左右两边相等的未知数的值，叫方程的解；求方程解的过程，叫解方程。列方程的关键，是找到题目里的等量关系，把未知量用字母表示出来。

方程 = 含未知数的等式；一元一次方程：一个未知数、次数 1、两边都是整式；方程的解代入后左右两边相等

怎么用：判断一元一次方程看三样：是不是等式，未知数是不是只有一个，未知数的次数是不是 1。检验解，就把数代回原方程，算左右两边是否相等。

易错：3x+1 没有等号，不是方程；x²+1=0 次数是 2，不是一元一次方程；1/x=2 分母含未知数，也不是。

3.2等式的基本性质

等式两边都加上或减去同一个数或同一个式子，所得结果仍是等式；等式两边都乘同一个数，或除以同一个不为 0 的数，所得结果仍是等式。这两条性质是解方程的依据：移项，本质是两边同加或同减；系数化为 1，本质是两边同除。等式还有对称性：a=b，则 b=a；传递性：a=b，b=c，则 a=c。

a=b ⇒ a±c=b±c；a=b ⇒ ac=bc；a=b，c≠0 ⇒ a/c=b/c；a=b ⇒ b=a；a=b，b=c ⇒ a=c

怎么用：移项：含未知数的项放一边，常数放另一边，移过去的项要变号。系数化 1：两边同除以未知数的系数。做完把解代回原方程检验。

易错：两边同除的数不能是 0；移项要变号，别只移不变号；两边同乘一个式子时，每一项都要乘，别漏项。

3.3一元一次方程的解法

解一元一次方程的一般步骤是：去分母、去括号、移项、合并同类项、系数化为 1。去分母时，两边同乘各分母的最小公倍数；去括号用分配律，注意括号前的符号；移项要变号；最后把方程化成 x=a 的形式。

五步：去分母 → 去括号 → 移项 → 合并同类项 → 系数化为 1；去分母乘最小公倍数，每一项都要乘；移项变号；系数化 1 两边同除系数

怎么用：按顺序走，一步一行，别跳步。去分母先给两边每一项都乘上最小公倍数，不含分母的项也要乘。去括号一次乘完，别只乘第一项。

易错：去分母漏乘不含分母的项，比如 1 或 3；去括号只乘第一项；移项不变号；系数是分数时，除以它等于乘它的倒数。

3.4一元一次方程的应用

用方程解应用题：先审题，找出已知量和未知量；再设未知数，通常设所求量为 x；然后找等量关系列方程；解方程后检验是否符合实际；最后写答。常见类型有行程问题、工程问题、销售问题、配套问题。

路程 = 速度 × 时间；工作总量 = 工作效率 × 工作时间；利润 = 售价 − 进价；售价 = 标价 × 折扣

怎么用：五步：审、设、列、解、答。设未知数要带单位。找等量关系，抓「一共」「比……多」「是……的几倍」「恰好配套」这些词。解完检验：人数不能是小数，时间不能是负数。

易错：设未知数漏单位；单位不统一，分钟和小时混着用；解出负数或分数不检验实际意义；「增加了」和「增加到」分不清。

3.5认识二元一次方程组

含有两个未知数，并且含未知数的项的次数都是 1 的方程，叫二元一次方程。把两个二元一次方程合在一起，就组成二元一次方程组。使方程组中每个方程左右两边都相等的两个未知数的值，叫方程组的解，记作 x=…，y=…。一个二元一次方程有无数个解，但方程组的解通常只有一个。

二元一次方程：两个未知数、含未知数的项次数为 1、两边都是整式；方程组的解要同时满足两个方程

怎么用：判断是不是二元一次方程：数未知数个数、看次数、看是不是整式。检验方程组的解，把 x、y 分别代入两个方程，两个都要成立。

易错：xy=1 里 xy 这一项次数是 2，不是二元一次方程；方程组的解必须同时满足两个方程；二元一次方程有无数个解，别只写一组。

3.6二元一次方程组的解法

解二元一次方程组的基本思想是消元：把两个未知数化成一个未知数。代入消元法：从一个方程里把一个未知数用含另一个未知数的式子表示出来，再代入另一个方程。加减消元法：把两个方程相加或相减，消去一个未知数。某个未知数的系数是 1 或 −1 时，用代入法方便；系数相同或相反时，用加减法方便。

代入法：由 y=ax+b 代入另一个方程；加减法：系数相同就相减，系数相反就相加；消元后解一元一次方程，再回代求另一个未知数

怎么用：先观察系数，再选方法。用加减法，先把某个未知数的系数化成绝对值相等（取最小公倍数）。解出一个未知数后，回代求另一个。最后把解写成一对。

易错：加减时漏乘常数项；两式相减，整式要变号，符号最容易错；求出 x 后忘了回代求 y；写解要成对写，别只写一个。

3.7二元一次方程组的应用

有两个未知量、两个等量关系的问题，适合列二元一次方程组。设两个未知数，按题目中的两个条件分别列方程，组成方程组，解出来以后检验、作答。常见类型有和差倍分问题、行程问题、配套问题、销售问题，还有表格信息题。

两个未知数配两个等量关系；总量 = 各部分之和；路程 = 速度 × 时间；利润 = 售价 − 进价

怎么用：设两个未知数，都带单位。找两个等量关系，一个条件列一个方程。解完检验，再写答。表格题先读懂每一行、每一列表示什么。

易错：只设一个未知数却列了两个方程；两个方程用了同一个条件，等于少一个条件；解完不检验、不写答；单位不统一。

3.8三元一次方程组

含有三个未知数，每个方程中含未知数的项的次数都是 1，这样的方程组叫三元一次方程组。解法还是消元：先选一个未知数，用两个方程消去它，得到二元一次方程组；解出两个未知数后，回代求第三个。

三元 → 消去一个未知数 → 二元 → 再消去一个 → 一元 → 回代求其余未知数

怎么用：先挑系数最简单（1 或 −1）的未知数消。每次消元固定消同一个字母，别换来换去。解出后回代到最简单的原方程。

易错：三个方程要两两配对消元，别只用两个方程；回代时代错方程；解要写成三个数一组。

本章核心概念
  • 方程是含未知数的等式；一元一次方程：一个未知数、次数 1、两边整式
  • 等式两边同加同减、同乘同除（除数不为 0），结果仍是等式
  • 解一元一次方程五步：去分母、去括号、移项、合并同类项、系数化为 1
  • 二元一次方程组用代入消元或加减消元，三元先化二元
关键公式 / 结论
若 a=b，则 a±c=b±c；ac=bc；a/c=b/c（c≠0）
怎么记 / 怎么用
  • 解一元一次方程：去分母（乘最小公倍数，每一项都乘）→ 去括号 → 移项变号 → 合并 → 系数化 1。
  • 选消元方法：系数有 1 或 −1 用代入法，系数相同或相反用加减法。
  • 应用题：审、设、列、解、验、答，设未知数要带单位。
公式小题

解方程 (x−1)/2 − (2x+1)/3 = 1。

看解答
两边同乘 6：3(x−1)−2(2x+1)=6。去括号：3x−3−4x−2=6。合并同类项：−x−5=6。移项：−x=11。系数化为 1：x=−11。检验：左边 = (−12)/2 − (−21)/3 = −6+7 = 1，等于右边。
综合题（方程组 + 实际应用）

甲、乙两人加工零件，甲每天比乙多加工 5 个，两人 3 天共加工 195 个。甲、乙每天各加工多少个？

看解答
设甲每天加工 x 个，乙每天加工 y 个。由「甲比乙多 5 个」得 x−y=5；由「3 天共 195 个」得 3(x+y)=195，即 x+y=65。两式相加：2x=70，x=35；代回 x+y=65 得 y=30。检验：35−30=5，3×(35+30)=195。答：甲每天加工 35 个，乙每天加工 30 个。
例题

解方程组 x+y=5，2x−y=1。

看解答
两式相加，消去 y：3x=6，x=2。把 x=2 代入 x+y=5，得 y=3。所以方程组的解是 x=2，y=3。
易错点
  • 去分母漏乘不含分母的项
  • 移项不变号
  • 加减消元两式相减时，整式要变号
小测（2 题）
  1. 解方程 3(x−2)=2x+1
  2. 解方程组 x−y=2，x+y=6
点开看答案
  1. 去括号：3x−6=2x+1；移项：3x−2x=1+6；合并：x=7。
  2. 两式相加：2x=8，x=4；代入 x+y=6 得 y=2。所以 x=4，y=2。

4第 4 章 图形的认识

立体图形、线段、角，几何的起点。

4.1立体图形与平面图形

各部分不都在同一平面内的几何图形，叫立体图形，比如棱柱、棱锥、圆柱、圆锥、球。各部分都在同一平面内的，叫平面图形，比如三角形、长方形、圆。立体图形可以展开成平面图形，展开图折叠后能还原成立体图形。从正面、左面、上面看立体图形，得到的平面图形叫三视图。点动成线，线动成面，面动成体。

点动成线、线动成面、面动成体；n 棱柱有 2n 个顶点、3n 条棱、n+2 个面；n 棱锥有 n+1 个顶点、2n 条棱、n+1 个面

怎么用：判断展开图能不能折成正方体，看是不是「一四一」「二三一」「二二二」「三三」这几种排布。数顶点、棱、面，按上下底面加侧面来数。三视图按「长对正、高平齐、宽相等」画。

易错：球不是多面体，没有顶点和棱；圆柱的展开图是长方形加两个圆，别只画一个长方形；正方体展开图里不能出现「田」字形。

4.2线段、射线、直线

直线向两方无限延伸，没有端点；射线向一方无限延伸，有一个端点；线段有两个端点，长度有限。两点确定一条直线；两点之间线段最短，这条线段的长度叫两点间的距离。比较两条线段的长短，可以用刻度尺度量，也可以把两条线段叠在一起比。把一条线段分成两条相等线段的点，叫线段的中点。

两点确定一条直线；两点之间线段最短；M 是 AB 的中点 ⇒ AM=MB=½AB；两点间的距离是线段的长度，不是线段本身

怎么用：表示直线用两个大写字母或一个小写字母。数线段条数，按端点从左到右依次搭配，别重复。线段计算先画图，把已知长度标上去，用和差表示未知线段。

易错：直线、射线不能度量长度，只有线段能；距离是一个长度，不是线段；射线的端点写在前面，射线 AB 与射线 BA 不是同一条。

4.3角

有公共端点的两条射线组成的图形叫角，公共端点是角的顶点，两条射线是角的两边。角也可以看成一条射线绕它的端点旋转形成的图形。角可以用三个大写字母表示，顶点字母写在中间，也可以用一个大写字母或一个数字表示。比较两个角的大小，可以量出度数再比，也可以把两个角叠在一起比。角的度量单位是度、分、秒，1°=60′，1′=60″，是 60 进制。两个角的和等于 90°，就说这两个角互为余角；和等于 180°，就说这两个角互为补角。同角或等角的余角相等，同角或等角的补角相等。

1°=60′，1′=60″；∠α 的余角 = 90°−α，补角 = 180°−α；同角或等角的余角相等、补角相等；角平分线：∠AOC=∠BOC=½∠AOB

怎么用：角度计算按 60 进制：度与度、分与分、秒与秒对齐算，满 60 进 1，不够减向上一级借 1 当 60。求余角、补角，先看单位是否统一。

易错：角度是 60 进制，别按 100 进制算；余角是 90°、补角是 180°，别记反；互余、互补是两个角之间的关系，单独一个角不能说「它的余角」而不说和谁互余。

本章核心概念
  • 点动成线、线动成面、面动成体
  • 两点确定一条直线，两点之间线段最短
  • 线段中点把线段分成相等的两段
  • 1°=60′，1′=60″；同角或等角的余角相等、补角相等
关键公式 / 结论
∠α 的余角 = 90°−α；补角 = 180°−α；AM=MB=½AB；1°=60′
怎么记 / 怎么用
  • 数图形：数线段、数角，都按「从一个端点或顶点出发，依次和其他点配对」有序列举，避免重复。
  • 线段计算：先画图，把已知长度标在图上，用和差表示未知线段。
  • 角度计算：度分秒对齐算，满 60 进 1，不够减借 1 当 60。
公式小题

一个角的补角比它的余角的 2 倍多 10°，求这个角。

看解答
设这个角为 x 度，则补角是 180−x，余角是 90−x。由题意：180−x = 2(90−x)+10。去括号：180−x = 180−2x+10。移项：−x+2x = 10。合并：x = 10。检验：补角 170°，余角 80°，2×80+10 = 170，符合题意。答：这个角是 10°。
综合题（角平分线 + 角的和差）

已知 ∠AOB=80°，OC 平分 ∠AOB，OD 在 ∠BOC 内部，且 ∠BOD=20°，求 ∠COD 的度数。

看解答
OC 平分 ∠AOB，所以 ∠BOC=½∠AOB=½×80°=40°。OD 在 ∠BOC 内部，∠BOD=20°，所以 ∠COD=∠BOC−∠BOD=40°−20°=20°。答：∠COD=20°。
例题

32°15′ 的余角是多少？

看解答
余角 = 90°−32°15′。把 90° 看成 89°60′，89°60′−32°15′=57°45′。所以余角是 57°45′。
易错点
  • 角度是 60 进制，别按 100 进制算
  • 余角是 90°、补角是 180°，别记反
  • 直线、射线不能度量长度，只有线段能
小测（2 题）
  1. 32°15′ 的余角是多少？
  2. 线段 AB=10，C 为 AB 的中点，求 AC
点开看答案
  1. 90°−32°15′=89°60′−32°15′=57°45′。
  2. 中点把线段分成相等的两段，AC=½AB=½×10=5。

1第 1 章 整式的乘法

幂的运算、单项式乘多项式、乘法公式。

1.1整式的乘法

同底数幂相乘，底数不变，指数相加；幂的乘方，底数不变，指数相乘；积的乘方，等于把积的每一个因式分别乘方，再相乘。单项式乘单项式，系数相乘，同底数幂相乘，只在一个单项式里出现的字母连同指数照抄。单项式乘多项式、多项式乘多项式，都用分配律，逐项相乘再合并同类项。

aᵐ·aⁿ=aᵐ⁺ⁿ；(aᵐ)ⁿ=aᵐⁿ；(ab)ⁿ=aⁿbⁿ；m(a+b)=ma+mb；(a+b)(c+d)=ac+ad+bc+bd

怎么用：幂的运算先看结构：是相乘、乘方，还是积的乘方，对应三条公式，别混。单项式相乘先定符号，再算系数，最后算字母。多项式相乘逐项相乘，最后合并同类项。

易错：aᵐ·aⁿ 与 (aᵐ)ⁿ 混，一个指数相加、一个指数相乘；(ab)ⁿ 只把 a 乘方，漏掉 b；多项式乘多项式漏项；负号漏乘。

1.2乘法公式

平方差公式：(a+b)(a−b)=a²−b²，两个数的和乘这两个数的差，等于它们的平方差。完全平方公式：(a±b)²=a²±2ab+b²，首平方、尾平方、首尾两倍放中央，中间符号看括号里。公式可以正用，把积展开；也可以逆用，做因式分解；还能变形用，比如 a²+b²=(a+b)²−2ab。

(a+b)(a−b)=a²−b²；(a±b)²=a²±2ab+b²；(a+b)²+(a−b)²=2(a²+b²)；(a+b)²−(a−b)²=4ab

怎么用：用公式前先认结构：是不是「和×差」，是不是「一个整体平方」。数字接近整十整百，就拆成 (100+1)(100−1) 这种形式。中间项的符号，由括号里的符号决定。

易错：(a+b)² 漏掉中间项 2ab；平方差公式里的 a、b 是整体，别只代第一项；(−a−b)² 与 (a+b)² 相等，符号别弄错。

本章核心概念
  • 同底数幂相乘，底数不变、指数相加；幂的乘方，指数相乘
  • 积的乘方，等于各因式分别乘方再相乘
  • 单项式乘法：系数相乘、同底数幂相乘
  • 平方差公式与完全平方公式
关键公式 / 结论
(a+b)(a−b)=a²−b²；(a±b)²=a²±2ab+b²；aᵐ·aⁿ=aᵐ⁺ⁿ；(ab)ⁿ=aⁿbⁿ
怎么记 / 怎么用
  • 幂的运算先认结构：相乘就指数加，乘方就指数乘，积的乘方就分别乘方。
  • 单项式相乘：先定符号，再乘系数，最后按字母分别相乘。
  • 用乘法公式：先认「和×差」还是「整体平方」，再套公式，最后检查中间项。
公式小题

计算 102×98。

看解答
102=100+2，98=100−2，所以 102×98=(100+2)(100−2)。用平方差公式：=100²−2²=10000−4=9996。
综合题（完全平方公式 + 整体代入）

已知 a+b=5，ab=6，求 a²+b² 与 (a−b)² 的值。

看解答
由完全平方公式 (a+b)²=a²+2ab+b²，得 a²+b²=(a+b)²−2ab=5²−2×6=25−12=13。再由 (a−b)²=a²−2ab+b²=13−2×6=13−12=1。也可以直接用 (a−b)²=(a+b)²−4ab=25−24=1，两种算法结果一致。
例题

展开 (2x−1)²。

看解答
把 2x 看成 a，1 看成 b：(2x−1)²=(2x)²−2·2x·1+1²=4x²−4x+1。
易错点
  • (a+b)² 漏掉中间项 2ab
  • aᵐ·aⁿ 与 (aᵐ)ⁿ 混，一个指数相加、一个指数相乘
  • (ab)ⁿ 只把一个因式乘方
小测（2 题）
  1. 计算 101×99
  2. 展开 (x+3)²
点开看答案
  1. 101=100+1，99=100−1，用平方差公式：(100+1)(100−1)=100²−1²=10000−1=9999。
  2. (x+3)²=x²+2·x·3+3²=x²+6x+9。

2第 2 章 实数

平方根、立方根、无理数。

2.1平方根

如果一个数的平方等于 a（a≥0），这个数就叫 a 的平方根，也叫二次方根，记作 x²=a ⇒ x=±√a。其中非负的那个，叫算术平方根，记作 √a；0 的平方根是 0。正数有两个平方根，它们互为相反数；负数没有平方根。求一个数的平方根的运算，叫开平方，开平方与平方互为逆运算。

x²=a（a≥0）⇒ x=±√a；√a≥0；√(a²)=|a|；(√a)²=a（a≥0）

怎么用：求平方根先看被开方数的符号：负数直接写「没有平方根」；正数写 ±√a；只问算术平方根，就不带负号。

易错：√16=4，不是 ±4，因为 √ 表示算术平方根；16 的平方根是 ±4；负数没有平方根；√(a²)=|a|，不是 a。

2.2立方根

如果一个数的立方等于 a，这个数就叫 a 的立方根，记作 ∛a，即 x³=a ⇒ x=∛a。任何数都有唯一的立方根：正数的立方根是正数，负数的立方根是负数，0 的立方根是 0。求立方根的运算叫开立方，开立方与立方互为逆运算。

x³=a ⇒ x=∛a；∛(−a)=−∛a；∛(a³)=a；(∛a)³=a

怎么用：求立方根先看符号：负数的立方根直接提负号。记住几个立方数：1、8、27、64、125、216，反过来就能快速开立方。

易错：负数有立方根，别写「没有」；∛8=2，不是 ±2；立方根只有一个，平方根有两个。

2.3实数

无限不循环小数叫无理数，比如 √2、π、0.1010010001…。有理数和无理数统称实数。实数与数轴上的点一一对应。实数的相反数、绝对值、倒数的意义，与有理数一致；实数可以比较大小，正数大于 0，负数小于 0，两个负数绝对值大的反而小。实数可以进行加、减、乘、除、乘方运算，运算律同样适用。

实数 = 有理数 ∪ 无理数；实数与数轴上的点一一对应；|a|=a（a≥0），|a|=−a（a<0）；√2≈1.414，π≈3.1416

怎么用：判断无理数，看是不是无限不循环小数：含 π、开不尽的方根、有规律但不循环的小数。比较大小，可以平方、估算，或者找中间量。实数运算按有理数的运算顺序。

易错：带根号的不一定是无理数，√9=3 是有理数；π/2 是无理数，22/7 是有理数；是实数与数轴一一对应，不是有理数。

本章核心概念
  • 正数有两个平方根，负数没有平方根
  • 任何数都有唯一的立方根
  • 无限不循环小数是无理数，有理数和无理数统称实数
  • 实数与数轴上的点一一对应
关键公式 / 结论
√(a²)=|a|；∛(a³)=a；x²=a ⇒ x=±√a（a≥0）；x³=a ⇒ x=∛a
怎么记 / 怎么用
  • 求平方根：先看符号，负数写「没有」；正数写 ±√a，算术平方根只写正的那个。
  • 求立方根：先定符号，再找立方数，∛(−a)=−∛a。
  • 比较实数大小：能平方就平方，不能就估算，或者找 0、1 作中间量。
公式小题

计算 √((−5)²) + ∛(−27)。

看解答
先算被开方数：(−5)²=25，√25=5，也可以直接用 √(a²)=|a|=|−5|=5。再算立方根：∛(−27)=−3，因为 (−3)³=−27。原式 = 5+(−3)=2。
综合题（平方根 + 立方根）

已知 2a+1 的平方根是 ±3，3a+b−1 的立方根是 2，求 a+b 的平方根。

看解答
平方根是 ±3，说明 2a+1=3²=9，解得 a=4。立方根是 2，说明 3a+b−1=2³=8；把 a=4 代入，12+b−1=8，解得 b=−3。所以 a+b=4+(−3)=1，1 的平方根是 ±1。
例题

求 √16 与 ∛(−8)。

看解答
√16 表示 16 的算术平方根，4²=16，所以 √16=4。∛(−8) 表示 −8 的立方根，(−2)³=−8，所以 ∛(−8)=−2。
易错点
  • √16 只等于 4，不是 ±4
  • 负数没有平方根，但有立方根
  • 带根号的不一定是无理数，比如 √9=3
小测（2 题）
  1. 求 √81 与 ∛27
  2. −8 有平方根吗？有立方根吗？
点开看答案
  1. 9²=81，所以 √81=9；3³=27，所以 ∛27=3。
  2. −8 是负数，没有平方根；任何数都有立方根，∛(−8)=−2。

3第 3 章 一元一次不等式（组）

解集、数轴表示、实际应用。

3.1不等式的意义

用不等号（>、<、≥、≤、≠）连接起来的式子，叫不等式。使不等式成立的未知数的值，叫不等式的解；所有解组成的集合，叫解集；求解集的过程，叫解不等式。不等式的解集可以在数轴上表示：含等号用实心点，不含等号用空心圈；大于向右画，小于向左画。

不等式用 >、<、≥、≤、≠ 连接；解集是解的全体；数轴表示：大于向右、小于向左；含等号实心，不含空心

怎么用：判断是不是不等式，看有没有不等号。在数轴上表示解集，先定点（实心还是空心），再定方向（向右还是向左）。

易错：x≥3 用实心点，x>3 用空心圈；解集是一个范围，不是某一个数；≠ 也是不等号。

3.2不等式的基本性质

不等式两边都加上或减去同一个数或同一个式子，不等号方向不变；两边都乘或除以同一个正数，方向不变；两边都乘或除以同一个负数，方向改变。这三条性质是解不等式的依据。

a>b ⇒ a±c>b±c；a>b，c>0 ⇒ ac>bc；a>b，c<0 ⇒ ac<bc；a>b，c<0 ⇒ a/c<b/c

怎么用：移项不变号，因为移项相当于两边同加同减。系数化为 1 时，除数是正数就不变号，是负数就变号。不确定符号时，分类讨论。

易错：两边乘除负数忘变号；移项时变号，那是移项，不是性质；两边不能同乘 0，0 也不能作除数。

3.3一元一次不等式的解法

只含一个未知数，未知数的次数是 1，两边都是整式的不等式，叫一元一次不等式。解法与一元一次方程类似：去分母、去括号、移项、合并同类项、系数化为 1。唯一的区别在最后一步：两边乘或除以负数时，不等号要变向。

五步同解方程；系数化为 1：除以正数不变号，除以负数变号；去分母乘最小公倍数，每一项都乘

怎么用：按五步走，一步一行。去分母时每一项都要乘。最后一步盯住系数的正负，负的就变号。解完在数轴上画一遍，检查端点和方向。

易错：去分母漏乘；去括号漏乘；最后一步除以负数忘变号；把解集写成等式。

3.4一元一次不等式的应用

用不等式解决实际问题：设未知数，找不等关系，列不等式，解出解集，再根据实际意义取整数解或特殊解，最后作答。题目里的「至少」「至多」「不超过」「不低于」「超过」「不足」，都是列不等式的关键词。

至少 ≥；至多 ≤；不超过 ≤；不低于 ≥；超过 >；不足 <

怎么用：审题先圈关键词，再设未知数，带单位。列不等式，解出范围。按实际取解，整数解要写全。最后写答。

易错：「至少」和「超过」混淆，一个是 ≥，一个是 >；解出范围后忘了取整数；答案不写单位、不写答。

3.5一元一次不等式组

几个含有同一个未知数的一元一次不等式合在一起，组成一元一次不等式组。不等式组的解集，是各个不等式解集的公共部分。口诀：同大取大、同小取小、大小小大取中间、大大小小无解。

解集 = 各不等式解集的交集；a<b 时：x>a 且 x>b ⇒ x>b；x<a 且 x<b ⇒ x<a；x>a 且 x<b ⇒ a<x<b；x<a 且 x>b ⇒ 无解

怎么用：先分别解每个不等式，再把解集画在同一条数轴上，找公共部分。端点注意实心、空心。

易错：公共部分找错，画数轴最稳；端点取舍看含不含等号；无解也要写「无解」，别空着。

本章核心概念
  • 不等式两边乘或除以负数，不等号方向改变
  • 不等式的解集是一个范围，数轴上空心点不含、实心点含
  • 解一元一次不等式五步，最后一步注意变号
  • 不等式组的解集是各个解集的公共部分
关键公式 / 结论
若 a>b 且 c>0，则 ac>bc；若 a>b 且 c<0，则 ac<bc
怎么记 / 怎么用
  • 解不等式：去分母、去括号、移项、合并同类项、系数化为 1，最后一步盯住符号。
  • 数轴表示：先定点（含等号实心、不含空心），再定方向（大于向右、小于向左）。
  • 不等式组：分别解，画同一条数轴，取公共部分；口诀「同大取大、同小取小、大小小大取中间、大大小小无解」。
公式小题

解不等式 2(x−1) ≤ 3x+4，并把解集在数轴上表示出来。

看解答
去括号：2x−2 ≤ 3x+4。移项：2x−3x ≤ 4+2。合并同类项：−x ≤ 6。系数化为 1，两边同除以 −1，不等号变向：x ≥ −6。数轴上在 −6 处画实心点，向右画箭头。
综合题（不等式组 + 整数解）

解不等式组 2x−1>3，x+2≤5，并写出它的整数解。

看解答
解第一个：2x>4，x>2。解第二个：x≤3。两个解集取公共部分：2<x≤3。在这个范围里的整数只有 3，所以整数解是 x=3。
例题

解不等式 3x+1 ≤ 10。

看解答
移项：3x ≤ 10−1=9。系数化为 1：x ≤ 3。所以解集是 x≤3。
易错点
  • 两边乘或除以负数，忘把不等号变向
  • 数轴上端点的实心、空心弄反
  • 不等式组取错公共部分
小测（2 题）
  1. 解 3x+1 ≤ 10
  2. 解不等式组 x>1 且 x≤3
点开看答案
  1. 移项得 3x ≤ 9，两边同除以 3，x ≤ 3。
  2. 两个解集分别是 x>1 和 x≤3，画在同一条数轴上，公共部分是 1<x≤3。

4第 4 章 平面内的两条直线

相交线、平行线的判定与性质。

4.1平面内两条直线的位置关系

同一平面内，两条直线只有两种位置关系：相交和平行。不相交的两条直线叫平行线，记作 a∥b。两条直线相交成四个角：有公共顶点、两边互为反向延长线的两个角叫对顶角，对顶角相等；相邻的两个角叫邻补角，邻补角互补。两条直线被第三条直线所截，形成同位角、内错角、同旁内角。

对顶角相等；邻补角之和 = 180°；平行线：同一平面内不相交的两条直线；同位角「F」形、内错角「Z」形、同旁内角「U」形

怎么用：认角先找截线：同位角在截线同旁、被截线同侧；内错角在截线两侧、两被截线之间；同旁内角在截线同旁、两被截线之间。

易错：平行线必须强调「同一平面内」；对顶角是两边互为反向延长线，不是随便两个相等的角；内错角是 Z 形，别和同位角混。

4.2平移

把一个图形整体沿某一条直线方向移动一定的距离，叫平移。平移不改变图形的形状和大小，只改变位置。平移后，对应线段平行（或在同一条直线上）且相等，对应角相等，对应点所连的线段平行且相等。

对应线段平行且相等；对应角相等；对应点连线平行且相等；平移不改变形状和大小

怎么用：找平移的方向和距离：看一组对应点，方向就是射线方向，距离就是线段长度。画平移后的图形，先把关键点按方向和距离移过去，再连线。

易错：平移的方向和距离要同时说清楚；对应线段可能共线，所以要说「平行或在同一直线上」；平移不改变图形大小，别把面积算变了。

4.3平行线的性质

两条平行线被第三条直线所截，同位角相等；内错角相等；同旁内角互补。这是由「平行」推出「角的关系」，用的时候，已知条件里必须有平行。

a∥b ⇒ 同位角相等；a∥b ⇒ 内错角相等；a∥b ⇒ 同旁内角互补（和为 180°）

怎么用：先找平行线，再找截线，最后认准是哪一对角。写理由要写完整，比如「两直线平行，同位角相等」。

易错：性质和判定方向弄反：性质是平行 ⇒ 角相等，判定是角相等 ⇒ 平行；同旁内角是互补，不是相等；没有平行条件，不能用性质。

4.4平行线的判定

两条直线被第三条直线所截，如果同位角相等，或者内错角相等，或者同旁内角互补，那么这两条直线平行。另外，平行于同一条直线的两条直线平行；在同一平面内，垂直于同一条直线的两条直线平行。

同位角相等 ⇒ a∥b；内错角相等 ⇒ a∥b；同旁内角互补 ⇒ a∥b；a∥c，b∥c ⇒ a∥b

怎么用：证平行，先找截线，再找角。写理由用「同位角相等，两直线平行」这样的完整句子。多次平行，用「平行于同一直线的两直线平行」传递。

易错：判定和性质混用；同旁内角要互补才平行，相等不行；「垂直于同一直线」必须强调在同一平面内。

4.5垂线

两条直线相交成直角时，这两条直线互相垂直，记作 a⊥b，交点叫垂足。在同一平面内，过一点有且只有一条直线与已知直线垂直。连接直线外一点与直线上各点的所有线段中，垂线段最短，这条垂线段的长度，叫点到直线的距离。

垂直 ⇒ 夹角 90°；过一点有且只有一条垂线；垂线段最短；点到直线的距离 = 垂线段的长度

怎么用：画垂线用三角尺：一条直角边贴已知直线，另一条边过已知点。求点到直线的距离，先作垂线段，再量长度。

易错：点到直线的距离是垂线段的长度，不是垂线段本身；「过一点有且只有一条垂线」要在同一平面内；垂直是相交的特殊情况。

4.6两条平行线间的距离

两条平行线中，一条直线上任意一点到另一条直线的距离，叫这两条平行线间的距离。平行线间的距离处处相等，所以可以用它来说明同底等高的三角形面积相等。

平行线间的距离处处相等；夹在两条平行线间的平行线段相等；同底等高的三角形面积相等

怎么用：求两平行线间的距离：在一条上任取一点，作另一条的垂线段，量它的长度。证明面积相等，先找平行线，说明高相等。

易错：距离是垂线段的长度，不是斜线段；「处处相等」指所有垂线段都相等；两条平行线间的距离与所取点的位置无关。

本章核心概念
  • 同一平面内，两条直线相交或平行
  • 对顶角相等，邻补角互补
  • 两直线平行：同位角相等、内错角相等、同旁内角互补
  • 平移不改变图形的形状和大小
  • 平行线间的距离处处相等
关键公式 / 结论
a∥b ⇒ 同位角相等、内错角相等、同旁内角互补；a⊥b ⇒ 夹角 90°
怎么记 / 怎么用
  • 认角：先找截线，再按「同旁还是两侧」「内部还是外部」判断同位角、内错角、同旁内角。
  • 证平行：找截线、找角，用判定（同位角相等、内错角相等、同旁内角互补）。
  • 用性质：先有平行，再得角相等或互补；性质和判定别用反。
公式小题

已知 a∥b，∠1 与 ∠2 是内错角，∠1=72°，求 ∠2；若 ∠3 与 ∠1 是同旁内角，求 ∠3。

看解答
两直线平行，内错角相等，所以 ∠2=∠1=72°。两直线平行，同旁内角互补，所以 ∠3=180°−72°=108°。
综合题（平行线性质 + 一元一次方程）

已知 a∥b，∠1 与 ∠2 是同旁内角，且 ∠1 比 ∠2 的 3 倍少 20°，求 ∠1 和 ∠2 的度数。

看解答
两直线平行，同旁内角互补，所以 ∠1+∠2=180°。又已知 ∠1=3∠2−20°，代入得 3∠2−20°+∠2=180°，即 4∠2=200°，∠2=50°。于是 ∠1=3×50°−20°=130°。检验：130°+50°=180°，符合互补。
例题

已知 a∥b，∠1=65°，∠1 与 ∠2 是同位角，求 ∠2。

看解答
两直线平行，同位角相等，所以 ∠2=∠1=65°。
易错点
  • 判定与性质方向弄反
  • 同旁内角是互补，不是相等
  • 点到直线的距离是垂线段的长度，不是垂线段
小测（2 题）
  1. 两直线平行，内错角是什么关系？
  2. ∠1 与 ∠2 是同旁内角，∠1=70°，求 ∠2
点开看答案
  1. 相等。依据是「两直线平行，内错角相等」。
  2. 两直线平行时同旁内角互补，∠2=180°−70°=110°。

5第 5 章 轴对称与旋转

对称与旋转，图形的变换。

5.1轴对称

把一个图形沿某条直线折叠，直线两旁的部分能够互相重合，这个图形叫轴对称图形，这条直线叫它的对称轴。两个图形沿一条直线折叠后能完全重合，就说这两个图形成轴对称。轴对称的性质：对应点的连线被对称轴垂直平分；对应线段相等，对应角相等。

对应点连线被对称轴垂直平分；对应线段相等、对应角相等；折叠前后的图形全等

怎么用：判断轴对称图形，试着找一条折痕，能把图形对折后两边完全重合。画对称图形，先找关键点，作它们关于对称轴的对称点（作垂线、截等距），再连线。

易错：轴对称图形是一个图形自身的性质，成轴对称是两个图形的关系，别混；对称轴是直线，不是线段；对称轴垂直平分对应点的连线，「垂直」和「平分」两个条件都要有。

5.2旋转

把一个图形绕某一点按某个方向转动一个角度，叫旋转。这个点叫旋转中心，转动的角叫旋转角。旋转的三要素是：旋转中心、旋转方向、旋转角度。旋转的性质：对应点到旋转中心的距离相等；对应点与旋转中心连线的夹角等于旋转角；旋转前后的图形全等。

对应点到旋转中心的距离相等；旋转角相等；旋转前后图形全等；中心对称：旋转 180° 后能与原图形重合

怎么用：找旋转中心：连两组对应点，作它们连线的垂直平分线，交点就是。找旋转角：对应点与中心连线的夹角。画旋转图形：连中心与关键点，量角、截等长。

易错：旋转方向（顺时针、逆时针）弄反；旋转角不是对应线段的夹角，是对应点与中心连线的夹角；旋转中心不一定在图形上。

5.3平面图形变换的简单应用

平移、轴对称、旋转都是全等变换，变换前后图形的形状、大小不变，只改变位置或方向。利用这些变换，可以设计图案、计算长度和角度、说明线段相等或角相等。组合变换时要注意顺序，先后的顺序不同，最后的位置可能不同。

全等变换：平移、轴对称、旋转；变换前后对应线段相等、对应角相等；组合变换按顺序逐步作图

怎么用：分析图案：拆成基本图形，看它经过哪种变换得到。计算题：把分散的线段或角，通过变换集中到一个图形里。

易错：变换顺序不同，结果可能不同；轴对称会把图形左右翻转，平移和旋转不会翻转；变换前后面积不变，别重算。

本章核心概念
  • 轴对称图形沿对称轴折叠后，两部分重合
  • 成轴对称是两个图形关于一条直线对称
  • 旋转三要素：旋转中心、旋转方向、旋转角度
  • 平移、轴对称、旋转都是全等变换
关键公式 / 结论
对应点的连线被对称轴垂直平分；旋转前后对应点到旋转中心的距离相等，旋转角相等
怎么记 / 怎么用
  • 判断轴对称图形：试着找一条直线，对折后两边能否完全重合。
  • 画对称点：过点作对称轴的垂线，在另一侧截取相等的距离。
  • 找旋转中心：连两组对应点，作它们连线的垂直平分线，交点就是旋转中心。
公式小题

正方形绕它的中心至少旋转多少度能与自身重合？等边三角形呢？

看解答
正方形绕中心旋转 90° 后，每个顶点转到相邻顶点，与自身重合，所以至少 90°。等边三角形绕中心旋转 120° 后与自身重合，因为 360°÷3=120°。
综合题（折叠 + 轴对称性质）

把长方形纸片 ABCD 沿 EF 折叠，点 A 落在 A′ 处，E 在 AB 上。若 ∠AEF=70°，求 ∠A′EF 和 ∠A′EB 的度数。

看解答
折叠是轴对称变换，∠A′EF 与 ∠AEF 是对应角，相等，所以 ∠A′EF=70°。点 A、E、B 在同一条直线上，∠AEB=180°，所以 ∠A′EB=180°−70°−70°=40°。
例题

画点 A 关于直线 l 的对称点 A′。

看解答
第一步，过 A 作 l 的垂线，垂足记作 O；第二步，在垂线上 l 的另一侧截取 OA′=OA；第三步，点 A′ 就是所求的对称点。
易错点
  • 轴对称图形与成轴对称混淆
  • 旋转方向（顺时针、逆时针）弄反
  • 对称轴是直线，不是线段
小测（2 题）
  1. 等腰三角形是轴对称图形吗？
  2. 等边三角形绕中心至少旋转多少度与自身重合？
点开看答案
  1. 是，对称轴是底边的垂直平分线，也是顶角平分线所在的直线。
  2. 360°÷3=120°，至少旋转 120°。

6第 6 章 收集、整理与描述数据

抽样、频数、统计图。

6.1抽样调查

为了解总体情况，对全体对象进行调查，叫全面调查，也叫普查；只抽取一部分对象进行调查，叫抽样调查。所要考察的全体对象叫总体，其中每一个考察对象叫个体，抽取的那部分个体叫总体的一个样本，样本中个体的数目叫样本容量。抽样时样本要有代表性，容量要适当；每个个体被抽到的机会相等，叫简单随机抽样。

总体、个体、样本、样本容量；样本容量不带单位；频率 = 频数 ÷ 总数

怎么用：判断用普查还是抽样：对象少、要求精确，用普查；对象多、有破坏性，用抽样。说样本容量时只写数字，不带单位。

易错：样本容量不带单位；样本是「一部分个体」，不是「个体的数目」；抽样要有代表性，只抽方便的样本不行。

6.2统计图

条形图能清楚看出每个项目的具体数目；折线图能反映数据的变化趋势；扇形图能反映各部分占总体的百分比。扇形图中，各部分对应的扇形圆心角 = 该部分的频率 × 360°。把数据分组后，各组数据的频数用条形表示，可以画频数分布直方图。

频率 = 频数 ÷ 总数；圆心角 = 频率 × 360°；各部分频率之和 = 1

怎么用：选统计图看目的：比多少用条形图，看变化用折线图，看比例用扇形图。画扇形图，先算频率，再乘 360° 得圆心角。

易错：圆心角算成频数 × 360°，要用频率；扇形图各部分百分比之和应为 100%，算完要检查；条形图的纵轴是具体数目，别和频率混。

本章核心概念
  • 全面调查与抽样调查
  • 总体、个体、样本、样本容量
  • 频数、频率 = 频数 ÷ 总数
  • 条形图看数量、折线图看变化、扇形图看比例
关键公式 / 结论
频率 = 频数 ÷ 总数；圆心角 = 频率 × 360°
怎么记 / 怎么用
  • 选调查方式：对象少、要精确用普查；对象多或有破坏性用抽样。
  • 选统计图：比数量用条形图，看趋势用折线图，看比例用扇形图。
  • 扇形图：先算频率，再乘 360° 得圆心角，最后画图。
公式小题

某班 40 人，其中 12 人喜欢篮球，求喜欢篮球的人数所占的频率和对应扇形的圆心角。

看解答
频率 = 频数 ÷ 总数 = 12÷40 = 0.3。圆心角 = 频率 × 360° = 0.3×360° = 108°。
综合题（扇形图 + 用样本估计总体）

某校抽查 200 名学生，其中步行上学的有 50 人。求步行上学所占的频率和圆心角；若全校 1200 人，估计步行上学的有多少人。

看解答
频率 = 50÷200 = 0.25；圆心角 = 0.25×360° = 90°。用样本估计总体：1200×0.25 = 300，所以估计全校步行上学的约有 300 人。
例题

某班 40 人，12 人喜欢篮球，求对应扇形的圆心角。

看解答
先算频率：12÷40=0.3。再算圆心角：0.3×360°=108°。
易错点
  • 把频率当频数
  • 圆心角算成频数×360°
  • 样本要有代表性，不能只挑方便的
小测（2 题）
  1. 50 人中 15 人步行，频率是多少？
  2. 频率 0.25 对应的圆心角是多少？

  1. 频率 = 频数 ÷ 总数 = 15÷50 = 0.3。
  2. 圆心角 = 频率 × 360° = 0.25×360° = 90°。

★二级结论 · 考场直接用

这些不是课本黑体字，但都是从基本公式推出来的「捷径」。先懂怎么来的，再记结论，最后拿题验一遍。

  • a² + b² = (a+b)² − 2ab = (a−b)² + 2ab
    怎么用：已知和与积求平方和：先算 (a+b)²，再减 2ab。
    例：a+b=5，ab=6，则 a²+b² = 25−12 = 13。
  • |a − b| 就是数轴上两点 a、b 的距离
    怎么用：看到「距离」先想绝对值，不用分左右。
    例：−2 与 3 的距离 = |3−(−2)| = 5。
  • 数轴中点 = (a + b) / 2
    怎么用：两点坐标相加除以 2，和求平均一样。
    例：−4 与 6 的中点 = 1。
  • 同角（或等角）的余角相等、补角相等
    怎么用：几何里遇到「互余/互补」先标等号，再找公共角。
    例：∠1+∠2=90°，∠2+∠3=90° ⇒ ∠1=∠3。
  • 去分母、去括号、移项，三步别乱序
    怎么用：解方程先「清场」：分母、括号清完再移项。
    例：x/2 + 1 = x/3 + 2 ⇒ 3x+6=2x+12 ⇒ x=6。
记法：不要死背一整串，记「它解决什么问题」——看到题里的关键词，能想起用哪条就够了。
