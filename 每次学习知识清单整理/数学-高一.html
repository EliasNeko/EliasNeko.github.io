01集合与常用逻辑用语

数学的语言从这里开始：把「对象」装进集合，把「关系」写成推理。

1.1集合的概念

把一些确定的、彼此不同的对象整体放在一起，就叫集合，对象叫元素。元素有三个特征：确定性（是不是成员能判断）、互异性（同一元素不重复算）、无序性（顺序无关）。a∈A 读作 a 属于 A。常用数集：N 自然数、N* 正整数、Z 整数、Q 有理数、R 实数。

a∈A 或 a∉A；N*⊆N⊆Z⊆Q⊆R；描述法 {x∈A | P(x)}

怎么用：判断一组对象能否组成集合，先看「确定性」；用描述法时先写代表元素，再写满足的条件，中间用竖线隔开。

易错：{x | x>1} 没写 x 的范围，默认 x∈R；集合里元素不能重复，{1,1,2} 就是 {1,2}。

1.2集合间的基本关系

若 A 中每个元素都在 B 中，称 A 是 B 的子集，记 A⊆B；若 A⊆B 且 A≠B，称 A 是 B 的真子集，记 A⊊B。A=B 当且仅当 A⊆B 且 B⊆A。空集 ∅ 不含任何元素，是任何集合的子集。

A⊆B ⇔ 任意 x∈A 都有 x∈B；含 n 个元素的集合有 2ⁿ 个子集、2ⁿ−1 个真子集

怎么用：判断子集关系用定义逐个检验；已知 A⊆B 求参数，先讨论 A=∅，再让区间端点满足包含关系。

易错：∅ 与 {∅} 不是一回事：前者没有元素，后者有一个元素「∅」；∅⊆A 恒成立，但 ∅∈A 不一定。

1.3集合的基本运算

交集取公共部分，并集取全部（重复只写一次），补集是在全集 U 中把 A 去掉。德摩根律把「并的补」变成「补的交」。

A∩B={x|x∈A 且 x∈B}；A∪B={x|x∈A 或 x∈B}；∁_U A={x|x∈U 且 x∉A}；∁_U(A∪B)=(∁_U A)∩(∁_U B)

怎么用：有限集用韦恩图，连续区间用数轴；含参数时按「A 在 B 左边 / 重合 / 右边」分类。

易错：并集里的「或」包含两者都取；求补集前必须先明确全集 U，否则无从补起。

1.4充分条件与必要条件

若 p 成立一定能推出 q 成立（p⇒q），则 p 是 q 的充分条件，q 是 p 的必要条件；若还能 q⇒p，则 p、q 互为充要条件。判断口诀：小范围推出大范围。

p⇒q；p⇔q；p 是 q 的充分不必要条件 ⇔ p⇒q 且 q⇏p

怎么用：把 p、q 各自解成集合，比较包含关系：小集合是大集合的充分条件；证明充要条件要正反各证一次。

易错：「p 是 q 的充分条件」与「p 的充分条件是 q」方向相反，读题先定位谁推谁。

1.5全称量词与存在量词

「所有」「任意」是全称量词，记 ∀；「存在」「至少有一个」是存在量词，记 ∃。全称命题的否定是存在命题，存在命题的否定是全称命题；否定时量词要换、结论要否。

¬(∀x∈M, p(x)) ⇔ ∃x∈M, ¬p(x)；¬(∃x∈M, p(x)) ⇔ ∀x∈M, ¬p(x)

怎么用：写否定分两步：先换量词，再否定结论；判断全称命题为假，举一个反例就够。

易错：只否定结论、不改条件；「至少有一个」的否定是「一个也没有」，不是「至多有一个」。

本章核心概念
  • 集合元素的确定性、互异性、无序性
  • 子集、真子集、集合相等
  • 交集、并集、补集与德摩根律
  • 充分条件、必要条件、充要条件
  • 全称量词与存在量词及其否定
关键公式 / 结论
A∩B = {x | x∈A 且 x∈B}；A∪B = {x | x∈A 或 x∈B}；∁_U A = {x | x∈U 且 x∉A}
怎么记 / 怎么用
  • 判断元素是否属于集合：先看集合的代表元素和条件，再把对象代进去检验。
  • 求子集个数：含 n 个元素 → 2ⁿ 个子集；已知 A⊆B 求参数，先讨论 A=∅。
  • 判断条件关系：把 p、q 解成集合，小范围 ⇒ 大范围；充要条件要正反各证一次。
公式小题

已知 A={1,2,3}，B={2,3,4}，求 A∩B 与 A∪B。

看解答
A∩B={2,3}（公共元素）；A∪B={1,2,3,4}（全部元素，重复只写一次）。
综合题（集合 + 不等式）

已知 A={x | −1<x≤3}，B={x | x>a}，若 A⊆B，求 a 的取值范围。

看解答
A 中最小无限接近 −1，要让 A 的每个元素都大于 a，必须 a≤−1。检验：a=−1 时 B={x>−1}，A=(−1,3] 确实全在 B 内。所以 a≤−1。
例题

用描述法表示「所有大于 1 的实数」。

看解答
{x∈R | x>1}。先写代表元素 x∈R，再写条件 x>1。
易错点
  • 空集是任何集合的子集，也是任何非空集合的真子集
  • 「或」与「且」弄反；并集用「或」，交集用「且」
  • 集合元素互异，写答案时别重复
小测（2 题）
  1. A={x|x>1}，B={x|x<3}，求 A∩B
  2. x>1 是 x>2 的什么条件？
点开看答案
  1. {x | 1<x<3}
  2. 必要不充分（x>2 ⇒ x>1，反之不成立）

02一元二次函数、方程和不等式

三个二次，一个套路：图象、根、解集是同一件事的三种说法。

2.1等式性质与不等式性质

等式两边同加同乘（乘数非零）仍相等；不等式两边同加一个数方向不变，同乘正数方向不变，同乘负数方向翻转。比较两个代数式大小最常用作差法：看 a−b 的符号。

a>b ⇔ a−b>0；a>b, c>0 ⇒ ac>bc；a>b, c<0 ⇒ ac<bc

怎么用：比较大小：作差 → 因式分解或配方 → 判断符号；证明不等式常从已知同向不等式相加、同向正数相乘出发。

易错：同向不等式能相加，但不能直接相减、相除；乘负数一定要记得变号。

2.2基本不等式

两个正数的算术平均数不小于几何平均数；等号只在两数相等时成立。它把「和」与「积」联系起来，是求最值的常用工具。

a,b>0 ⇒ (a+b)/2 ≥ √(ab)，即 a+b ≥ 2√(ab)；ab ≤ ((a+b)/2)²；a²+b² ≥ 2ab

怎么用：用前默念「一正、二定、三相等」：先确认都是正数，再凑出定值（和定求积最大、积定求和最小），最后检验等号能否取到。

易错：等号取不到时不能用它下结论；写最值必须写清「当且仅当 a=b 时取等」。

2.3二次函数与一元二次方程、不等式

二次函数图象、一元二次方程的根、一元二次不等式的解集，是同一件事的三种说法：抛物线与 x 轴交点的横坐标就是方程的根，也是解集的分界点。

Δ=b²−4ac；x₁+x₂=−b/a，x₁x₂=c/a；a>0 且 Δ<0 ⇒ ax²+bx+c>0 恒成立

怎么用：解不等式：先化二次项系数为正 → 求根（能因式分解先分解）→ 画开口向上的抛物线 →「大于取两边，小于取中间」。

易错：二次项系数为负要先乘 −1 并变号；含参数时讨论 a=0 与 Δ 的正负，别漏情况。

本章核心概念
  • 作差法比较大小
  • 不等式的基本性质（同加、同乘）
  • 基本不等式与「一正二定三相等」
  • 二次函数、二次方程、二次不等式的对应关系
关键公式 / 结论
a+b ≥ 2√(ab)（a,b>0）；Δ=b²−4ac；x₁+x₂=−b/a，x₁x₂=c/a
怎么记 / 怎么用
  • 比较大小：作差 → 因式分解或配方 → 判断符号。
  • 基本不等式：先验正数，再凑定值，最后检查等号能否取到。
  • 解二次不等式：化 a>0 → 求根 → 画抛物线 → 大于取两边、小于取中间。
公式小题

a,b>0，a+b=4，求 ab 的最大值。

看解答
ab ≤ ((a+b)/2)² = 4，当且仅当 a=b=2 时取等，所以最大值是 4。
综合题（二次不等式 + 分类讨论）

解关于 x 的不等式 x²−(a+1)x+a<0。

看解答
因式分解：(x−1)(x−a)<0。比较 1 与 a：a>1 时解集为 1<x<a；a=1 时原式为 (x−1)²<0，无解；a<1 时解集为 a<x<1。
例题

解 x²−x−6<0。

看解答
(x−3)(x+2)<0，开口向上，两根 −2、3，小于取中间：−2<x<3。
易错点
  • 二次项系数为负，先乘 −1 并改变不等号方向
  • 基本不等式取等条件不成立时不能直接用
  • 同向不等式不能直接相减、相除
小测（2 题）
  1. 解 x²−4>0
  2. a,b>0，a+b=4，ab 最大值？
点开看答案
  1. x<−2 或 x>2
  2. 4（a=b=2 时）

03函数的概念与性质

先有定义域，再谈一切；单调与对称是函数的两副骨架。

3.1函数的概念及其表示

设 A、B 是非空实数集，按某种对应关系 f，对 A 中任意一个 x，B 中都有唯一确定的 y 与它对应，就称 f 为从 A 到 B 的函数，记 y=f(x)。定义域、对应关系、值域合称函数三要素。分段函数是一个函数，不是几个函数。

y=f(x)，x∈A；定义域优先

怎么用：求定义域盯四件事：分母不为 0、偶次根号下非负、对数真数为正、零次幂底数不为 0；判断两个函数是否相同，看定义域和对应关系是否都相同。

易错：f(x) 表示函数，f(a) 表示函数在 x=a 处的值；先化简再求定义域容易漏掉原式的限制。

3.2函数的基本性质

单调性描述函数在区间上的增减：区间内任取 x₁<x₂，若 f(x₁)<f(x₂) 则递增。奇偶性描述对称：定义域关于原点对称时，f(−x)=−f(x) 为奇函数（图象关于原点对称），f(−x)=f(x) 为偶函数（图象关于 y 轴对称）。

增函数：x₁<x₂ ⇒ f(x₁)<f(x₂)；奇：f(−x)=−f(x)；偶：f(−x)=f(x)

怎么用：证明单调性用定义五步：取值、作差、变形（因式分解/通分/配方）、定号、下结论；判断奇偶先看定义域是否对称。

易错：单调区间之间不能用「∪」连接；奇函数若在 x=0 处有定义，则 f(0)=0。

3.3幂函数

形如 y=x^α（α 为常数）的函数叫幂函数，系数必须是 1、底数是自变量。α>0 时在 (0,+∞) 上递增，α<0 时递减；图象都过点 (1,1)。

y=x^α；x^α·x^β=x^(α+β)；(x^α)^β=x^(αβ)

怎么用：比较幂值大小：同底看指数（用单调性），同指数看底数，底和指数都不同就插入中间量 1 或 0。

易错：y=x⁰ 的定义域是 x≠0；y=2x²、y=x²+1 都不是幂函数。

3.4函数的应用（一）

用函数解决实际问题：先弄清变量各代表什么，再根据等量关系写出解析式，标出实际意义的定义域，最后求最值并回答。

常见模型：一次函数 y=kx+b；二次函数 y=ax²+bx+c；分段函数；反比例 y=k/x

怎么用：审题时先写「设……为 x，……为 y」，再找等量关系；求最值别忘比较定义域端点。

易错：实际问题不写定义域是常见丢分点；单位不统一（米/千米、元/万元）会算错。

本章核心概念
  • 函数三要素：定义域、对应关系、值域
  • 单调性的定义与证明
  • 奇偶性与图象对称
  • 幂函数的图象与性质
关键公式 / 结论
f(−x)=−f(x) 为奇函数；f(−x)=f(x) 为偶函数；y=x^α
怎么记 / 怎么用
  • 求定义域：分母≠0、偶次根号下≥0、对数真数>0、零次幂底≠0。
  • 证单调性：取值—作差—变形—定号—结论。
  • 判奇偶：先看定义域是否关于原点对称，再算 f(−x) 与 f(x) 的关系。
公式小题

求 f(x)=√(x−1)+1/(x−3) 的定义域。

看解答
根号要求 x−1≥0，分母要求 x−3≠0，所以 x≥1 且 x≠3，定义域 [1,3)∪(3,+∞)。
综合题（奇函数 + 分段求解析式）

f(x) 是定义在 R 上的奇函数，当 x>0 时 f(x)=x²−2x，求 f(x) 的解析式。

看解答
x<0 时 −x>0，f(−x)=x²+2x；由奇函数 f(x)=−f(−x)=−x²−2x。x=0 时 f(0)=0。所以 x>0 时 f(x)=x²−2x；x=0 时 0；x<0 时 −x²−2x。
例题

求 f(x)=√(x−1) 的定义域。

看解答
x−1≥0 ⇒ x≥1，定义域 [1,+∞)。
易错点
  • 先化简再求定义域会漏掉原式的限制
  • 奇偶性要求定义域关于原点对称
  • 单调区间之间不能用「∪」连接
小测（2 题）
  1. f(x)=1/(x−2) 的定义域？
  2. f(x)=x³ 的奇偶性？
点开看答案
  1. x≠2
  2. 奇函数

04指数函数与对数函数

增长与压缩互为反函数：一个把加法变乘法，一个把乘法变加法。

4.1指数

n 次方根与分数指数幂互化：ⁿ√(aᵐ)=a^(m/n)（a>0）。规定 a⁰=1（a≠0）、a⁻ⁿ=1/aⁿ；指数运算的三条性质是化简的基础。

a^(m/n)=ⁿ√(aᵐ)；a⁻ⁿ=1/aⁿ；aᵐ·aⁿ=aᵐ⁺ⁿ；(aᵐ)ⁿ=aᵐⁿ；(ab)ⁿ=aⁿbⁿ

怎么用：根式先化成分数指数，同底数再合并；化简顺序：先乘方、再乘除、最后加减。

易错：负数指数不是负数，a⁻ⁿ 是倒数；n 为偶数时 ⁿ√(aⁿ)=|a|。

4.2指数函数

y=aˣ（a>0 且 a≠1）叫指数函数：定义域 R，值域 (0,+∞)，图象恒过 (0,1)；a>1 时递增，0<a<1 时递减；y=aˣ 与 y=(1/a)ˣ 的图象关于 y 轴对称。

a>1 增，0<a<1 减；值域 (0,+∞)；过定点 (0,1)

怎么用：比较大小先化同底，不能同底就找中间量 1；解指数不等式化同底后，按底数大于 1 或小于 1 决定不等号方向。

易错：底数含参数要分 0<a<1 与 a>1 讨论；指数函数值域取不到 0。

4.3对数

若 aˣ=N（a>0,a≠1,N>0），则 x=log_a N，指数与对数互为逆运算。真数必须为正；log_a 1=0，log_a a=1；积的对数等于对数的和。

a^(log_a N)=N；log_a(MN)=log_aM+log_aN；log_a(M/N)=log_aM−log_aN；log_a Mⁿ=n log_a M

怎么用：化简对数先指对互化或统一底数；真数是积、商、幂时拆开算。

易错：log_a(M+N) ≠ log_aM+log_aN；真数 ≤0 时对数无意义。

4.4对数函数

y=log_a x（a>0,a≠1,x>0）叫对数函数：定义域 (0,+∞)，值域 R，图象恒过 (1,0)；a>1 递增，0<a<1 递减；它与 y=aˣ 互为反函数，图象关于直线 y=x 对称。

y=log_a x ⇔ x=aʸ；换底公式 log_a b=ln b/ln a

怎么用：比较对数大小：同底看单调性，同真数看底数（底大图靠右），都不同就找 0 或 1 作中间量。

易错：定义域是 (0,+∞) 不是 R；底数与真数的位置不要写反。

4.5函数的应用（二）

使 f(x)=0 的实数 x 叫函数的零点，零点是一个数，不是点。零点存在定理：f(x) 在 [a,b] 上连续，且 f(a)f(b)<0，则 (a,b) 内至少有一个零点；二分法不断取中点把区间缩小。

f(a)f(b)<0 ⇒ (a,b) 内存在零点；二分法每步区间长度减半

怎么用：判断零点所在区间，代端点算符号；用二分法求近似解，直到区间长度小于精度要求。

易错：f(a)f(b)<0 只保证「存在」，不保证唯一；零点不是坐标点。

05三角函数

圆上的匀速运动写了两次：一次用角，一次用正弦余弦。

5.1任意角和弧度制

角可以按旋转方向分成正角、负角、零角；与 α 终边相同的角组成集合 {β | β=α+k·360°, k∈Z}。弧度制用弧长与半径的比度量角：α=l/r，π 弧度=180°。

180°=π rad；1 rad=(180/π)°；l=|α|r；S扇形=½lr=½|α|r²

怎么用：角度化弧度乘 π/180，弧度化角度乘 180/π；扇形问题先统一用弧度，再套 l、S 公式。

易错：弧度制下角是实数，可以不带单位；扇形面积别和三角形面积公式混。

5.2三角函数的概念

角 α 终边上任取一点 P(x,y)（不与原点重合），r=√(x²+y²)，定义 sinα=y/r，cosα=x/r，tanα=y/x。三角函数值的符号由终边所在象限决定：一全正、二正弦、三正切、四余弦。

sin²α+cos²α=1；tanα=sinα/cosα；r=√(x²+y²)

怎么用：已知一个三角函数值求另外两个，用平方关系和商数关系，先根据象限定符号。

易错：由 sin²α+cos²α=1 开方时要带 ±，符号看象限；tanα 在 x=0 时无意义。

5.3诱导公式

诱导公式把任意角的三角函数化到锐角：口诀「奇变偶不变，符号看象限」。「奇偶」指 π/2 的奇数倍还是偶数倍，「符号」把 α 当锐角，看原函数在对应象限的正负。

sin(π+α)=−sinα；cos(π+α)=−cosα；sin(−α)=−sinα；cos(−α)=cosα；sin(π/2−α)=cosα

怎么用：化角三步：先去掉 k·360°，再用 π±α 化到 [0,π]，最后用 π/2±α 化到锐角。

易错：判断符号时把 α 看成锐角，不要用题中 α 的真实象限；函数名变不变只看 π/2 的倍数。

5.4三角函数的图象与性质

y=sinx、y=cosx 的周期是 2π，y=tanx 的周期是 π；sinx 是奇函数，cosx 是偶函数，tanx 是奇函数。用「五点法」可以快速画出一个周期的图象。

sin(x+2kπ)=sinx；cos(x+2kπ)=cosx；tan(x+π)=tanx；tanx 定义域 x≠π/2+kπ

怎么用：求 y=Asin(ωx+φ) 的单调区间、对称轴，把 ωx+φ 整体代入 sinx 的相应区间或方程。

易错：写单调区间要注明 k∈Z；正切函数图象在 x=π/2+kπ 处断开。

5.5三角恒等变换

两角和差公式是全部恒等变换的源头；由它令 β=α 得二倍角公式。cos2α 有三种等价写法，按题目需要选。辅助角公式把 a sinx+b cosx 合成一个正弦。

sin(α±β)=sinαcosβ±cosαsinβ；cos(α±β)=cosαcosβ∓sinαsinβ；sin2α=2sinαcosα；cos2α=cos²α−sin²α=2cos²α−1=1−2sin²α；a sinx+b cosx=√(a²+b²)sin(x+φ)

怎么用：化简先看「角」的关系（和差、倍角、互补），再看「函数名」，目标是化成同一个角、同一个函数、一次式。

易错：cos2α 的三个形式按需选用，别死记一个；正切公式要求分母不为 0。

5.6函数 y=Asin(ωx+φ)

A 叫振幅（|A|），ω 决定周期 T=2π/|ω|，φ 叫初相。图象变换有两种顺序：先平移后伸缩，或先伸缩后平移，平移量不同。

T=2π/|ω|；f=1/T；五点法取 ωx+φ=0, π/2, π, 3π/2, 2π

怎么用：求解析式：先由最值定 A，再由周期定 ω，最后代入一个特殊点求 φ。

易错：先伸缩后平移时，平移量是 φ/ω 而不是 φ；φ 不唯一，通常取 |φ|<π/2。

5.7三角函数的应用

简谐运动、潮汐、气温等周期现象常用 y=Asin(ωx+φ)+b 建模：A 由振幅定，b 由平衡位置定，ω 由周期定，φ 由初始状态定。

A=(最大值−最小值)/2；b=(最大值+最小值)/2；T=2π/ω

怎么用：先读图找最高点、最低点、周期，再代特殊点求 φ；最后回答实际问题时注意定义域。

易错：实际问题中 x 有范围，别把整个实数轴当答案；相位 φ 的取值不唯一，要按题目要求取。

06平面向量及其应用

有方向的量：几何的箭头，代数的坐标，物理的力。

6.1平面向量的概念

既有大小又有方向的量叫向量，用有向线段表示；向量的大小叫模，记 |a|。长度为 1 的叫单位向量，长度为 0 的叫零向量（方向任意）。方向相同或相反的非零向量叫平行（共线）向量。

|a|；a∥b ⇔ 存在实数 λ 使 a=λb（b≠0）

怎么用：判断两个向量是否相等，要同时看方向和模；用有向线段表示时，起点可以任意平移。

易错：向量不能比较大小，只能说模相等；零向量与任何向量平行，但方向不确定。

6.2平面向量的运算

加法用三角形法则或平行四边形法则，减法「共起点、指向被减向量」；数乘 λa 只改变长度和方向。数量积 a·b=|a||b|cosθ 的结果是一个实数，不是向量。

a·b=|a||b|cosθ；|a|²=a·a；cosθ=a·b/(|a||b|)；a·b=0 ⇔ a⊥b（非零向量）

怎么用：求模先平方：|a±b|²=|a|²±2a·b+|b|²；求夹角先算数量积和两个模。

易错：数量积不满足结合律，(a·b)c ≠ a(b·c)；a·b=0 也可能是其中一个为零向量。

6.3平面向量基本定理及坐标表示

若 e₁、e₂ 是同一平面内两个不共线向量，则对该平面内任一向量 a，存在唯一一对实数 λ₁、λ₂，使 a=λ₁e₁+λ₂e₂。取正交单位基底后，向量可以用坐标表示，几何问题变成代数运算。

a±b=(x₁±x₂, y₁±y₂)；λa=(λx₁, λy₁)；a·b=x₁x₂+y₁y₂；a∥b ⇔ x₁y₂−x₂y₁=0；a⊥b ⇔ x₁x₂+y₁y₂=0

怎么用：建系后先写各点坐标，再算向量坐标；判断平行、垂直直接套坐标判别式。

易错：平行与垂直的坐标公式不要记反；共线定理中基底必须不共线。

6.4平面向量的应用

向量可以证明平行、垂直、求长度和夹角；解三角形时，余弦定理处理「两边夹一角」或「三边求角」，正弦定理处理「两角一边」或「两边及一边对角」。

c²=a²+b²−2ab cosC；a/sinA=b/sinB=c/sinC=2R；S=½ab sinC

怎么用：解三角形先画图、标已知，再选定理；已知两边及夹角求第三边用余弦定理，已知两角一边用正弦定理。

易错：用正弦定理求角可能出现两解，要结合「大边对大角」取舍；余弦定理中边与角的对应别错位。

07复数

i²=−1：数系再一次扩充，平面上的点从此能相乘。

7.1复数的概念

形如 z=a+bi（a,b∈R）的数叫复数，a 是实部，b 是虚部，i 是虚数单位且 i²=−1。两个复数相等当且仅当实部、虚部分别相等。复数 z=a+bi 对应复平面内的点 (a,b)，模 |z|=√(a²+b²)。

i²=−1；z=a+bi；z̄=a−bi；|z|=√(a²+b²)；z·z̄=a²+b²

怎么用：复数相等列两个方程解参数；判断实数、虚数、纯虚数分别看虚部是否为 0、是否非 0、实部是否为 0。

易错：虚部是 b 不是 bi；两个虚数不能比较大小。

7.2复数的四则运算

加减法实部、虚部分别相加减；乘法按多项式展开，遇到 i² 换成 −1；除法分子分母同乘分母的共轭复数，把分母变成实数。

(a+bi)(c+di)=(ac−bd)+(ad+bc)i；(a+bi)/(c+di)=((a+bi)(c−di))/(c²+d²)

怎么用：除法先写成分式，再「分母实数化」；记住 (1+i)²=2i、(1−i)²=−2i 可以提速。

易错：除法别漏乘分子的共轭；i³=−i，i⁴=1，按周期 4 计算。

7.3复数的三角表示

复数 z=a+bi 可以写成 z=r(cosθ+isinθ)，其中 r=|z| 是模，θ 是辐角。三角形式下，乘法是「模相乘、辐角相加」，除法是「模相除、辐角相减」，几何上就是旋转与伸缩。

z₁z₂=r₁r₂[cos(θ₁+θ₂)+isin(θ₁+θ₂)]；z₁/z₂=(r₁/r₂)[cos(θ₁−θ₂)+isin(θ₁−θ₂)]

怎么用：求复数的高次幂用三角形式加棣莫弗定理；把代数形式化三角形式，先算 r，再定象限求 θ。

易错：辐角不唯一，通常取主值；化三角形式时先看点在哪个象限。

08立体几何初步

从纸面站起来：先认图形，再算面积体积，最后证平行垂直。

8.1基本立体图形

多面体包括棱柱、棱锥、棱台；旋转体包括圆柱、圆锥、圆台、球。棱柱的侧棱互相平行，棱锥的侧棱交于一点，棱台是用平行于底面的平面截棱锥得到的。

球：S=4πR²，V=4πR³/3；圆柱侧面积 2πrh

怎么用：认组合体先拆成基本几何体，再分别算；画图时先画底面，再画侧棱或母线。

易错：球不是多面体；棱台上下底面相似，侧棱延长后交于一点。

8.2立体图形的直观图

斜二测画法画直观图：x 轴方向长度不变，y 轴方向长度减半，z 轴方向长度不变；平行关系保持不变，但角度会变。

y 方向线段长度 × ½；S直观/S原 = √2/4（水平放置的平面图形）

怎么用：画直观图先建三条轴，再按「横不变、纵减半、竖不变」定点，最后连线。

易错：斜二测画出的图不是真实投影，不能直接从图上量角度；长度只有 x、z 方向保持原长。

8.3简单几何体的表面积与体积

柱体体积等于底面积乘高；锥体是等底等高柱体体积的三分之一；台体用上下底面积和中间项；球的表面积、体积公式要背熟。

V柱=Sh；V锥=⅓Sh；V台=⅓h(S₁+√(S₁S₂)+S₂)；S球=4πR²；V球=4πR³/3

怎么用：求体积先找底面积和高（高是两底面间的距离）；组合体用割补法拆开或补形。

易错：锥体别忘 ⅓；圆锥侧面积用母线 l，不是高 h。

8.4空间点、直线、平面之间的位置关系

基本事实：两点确定一条直线；不共线的三点确定一个平面；两个不重合的平面若有公共点，则交于一条过该点的直线。空间中两条直线的位置关系有相交、平行、异面三种。

异面直线所成角的范围 (0°,90°]；公理 1、2、3

怎么用：判断位置关系时用正方体模型比划；证明点共线、线共点，用基本事实找公共点。

易错：异面直线是「不同在任何一个平面内」，不是「不相交」那么简单；空间中垂直于同一直线的两直线不一定平行。

8.5空间直线、平面的平行

线面平行判定：平面外一条直线与平面内一条直线平行，则该直线与平面平行。线面平行性质：一条直线与一个平面平行，过这条直线的平面与已知平面的交线与它平行。面面平行由两组相交直线分别平行来判定。

a⊄α，b⊂α，a∥b ⇒ a∥α；a∥α，a⊂β，α∩β=b ⇒ a∥b

怎么用：证线面平行，先在平面内找（或作）一条平行线；证面面平行，找一个平面内两条相交直线都平行于另一个平面。

易错：判定定理必须强调直线在平面外；性质定理必须出现「过该直线的平面与原平面的交线」。

8.6空间直线、平面的垂直

线面垂直判定：一条直线与平面内两条相交直线都垂直，则它垂直于这个平面。线面垂直性质：垂直于同一个平面的两条直线平行。面面垂直判定：一个平面经过另一个平面的一条垂线，则两平面垂直。

l⊥m，l⊥n，m∩n=P，m,n⊂α ⇒ l⊥α；l⊥α，l⊂β ⇒ α⊥β

怎么用：证线面垂直，在平面内找两条相交直线；证面面垂直，先证线面垂直，再看这条线是否在另一个平面内。

易错：两条直线必须相交，平行不够；异面直线也可以垂直，垂直不一定相交。

本章核心概念

  • 斜二测画法
  • 表面积与体积公式
  • 空间点线面位置关系
  • 线面、面面平行与垂直的判定和性质
关键公式 / 结论
S球=4πR²；V球=4πR³/3；V柱=Sh；V锥=⅓Sh
怎么记 / 怎么用
  • 求体积：先找底面积和高，锥体乘 ⅓；组合体用割补。
  • 证平行：线线平行 ⇒ 线面平行 ⇒ 面面平行。
  • 证垂直：线线垂直 ⇒ 线面垂直 ⇒ 面面垂直。

09统计

用一小撮数据，谨慎地推断一大群人的样子。

9.1随机抽样

简单随机抽样（抽签法、随机数法）要求每个个体被抽到的机会相等；分层随机抽样按各层个体数比例抽取，适合总体差异明显的情况。

分层抽样中某层抽取数 = 该层个体数 × 样本容量/总体个数

怎么用：总体由差异明显的几部分组成时用分层抽样；抽样前先编号，保证不重不漏。

易错：抽样必须保证每个个体等可能入样；样本容量是抽出的个体数，不是样本个数。

9.2用样本估计总体

频率分布直方图用面积表示频率，纵轴是「频率/组距」；平均数、中位数、众数刻画集中趋势，方差、标准差刻画离散程度。

频率=频数/样本容量；s²=[(x₁−x̄)²+…+(xₙ−x̄)²]/n；s=√(s²)

怎么用：直方图求平均数用各组的组中值加权平均；比较两组数据稳定性看方差，方差越小越稳定。

易错：直方图纵轴不是频率，面积才是频率；中位数是使左右面积各为 0.5 的值，不是最高矩形的中点。

9.3统计案例

用样本估计总体时，先明确总体、样本、样本容量，再选择合适的图表和数字特征；结论必须由数据支撑。

样本平均数 x̄ 估计总体平均数 μ；样本方差 s² 估计总体方差 σ²

怎么用：先看数据想回答什么问题：分布用直方图，趋势用折线图，比较用平均数加方差。

易错：样本不能代表总体时，结论无效；相关不等于因果。

  • 频率分布直方图
  • 平均数、中位数、众数
  • 方差与标准差
关键公式 / 结论
频率=频数/样本容量；s²=[(x₁−x̄)²+…+(xₙ−x̄)²]/n
怎么记 / 怎么用
  • 直方图：面积=频率，纵轴是频率/组距，求平均数用组中值加权。
  • 中位数：把数据排序后取中间位置，偶数个取中间两数的平均。
  • 方差：先求平均数，再求偏差平方的平均。
公式小题

数据 2,3,3,5,7 的平均数、中位数、众数。

看解答
平均数 (2+3+3+5+7)/5=4；中位数 3；众数 3。
综合题（分层抽样 + 方差比较）

某校高一男 30 人、女 20 人，用分层抽样抽 10 人，男女各几人？若两组方差分别为 1.2 和 3.5，哪组更稳定？

看解答
按 30:20=3:2 分配，男 6 人、女 4 人；方差小的更稳定，所以第一组更稳定。
例题

求 3,5,7,9 的中位数。

看解答
排序后中间两数 5、7，中位数 (5+7)/2=6。
易错点
  • 直方图纵轴是频率/组距，不是频率
  • 偶数个数据的中位数要取中间两数的平均
  • 众数可能不唯一

10概率

把「可能」变成可以计算的数，再用它做决定。

10.1随机事件与概率

随机试验所有可能结果组成的集合叫样本空间 Ω，随机事件是 Ω 的子集。古典概型要求样本点有限且等可能，此时 P(A)=A 包含的样本点数/样本点总数。

P(A)=m/n；P(Ω)=1，P(∅)=0，0≤P(A)≤1；P(A∪B)=P(A)+P(B)−P(A∩B)

怎么用：古典概型先列（或算）样本点总数，再数有利事件数；复杂事件用对立事件 1−P(Ā) 更快。

易错：每个样本点必须等可能，否则不能用 m/n；互斥事件概率相加，对立事件概率之和为 1。

10.2事件的相互独立性

若 P(AB)=P(A)P(B)，则事件 A、B 相互独立；直观上是一个事件发生与否不影响另一个事件的概率。n 次独立重复试验中事件恰发生 k 次的概率用二项式公式。

P(AB)=P(A)P(B)；P(X=k)=C(n,k)pᵏ(1−p)ⁿ⁻ᵏ

怎么用：判断独立看定义或实际意义；求「至少一次」用 1−P(一次都不发生)。

易错：互斥与独立是两回事，两个概率非零的事件不可能既互斥又独立；独立不是「没有关系」。

10.3频率与概率

大量重复试验中，事件发生的频率会稳定在某个常数附近，这个常数就是概率；可以用频率估计概率，也可以用随机数模拟试验。

f_n(A)=n_A/n；n 越大，f_n(A) 越接近 P(A)

怎么用：试验次数足够多时用频率估计概率；模拟试验要先规定随机数的对应规则。

易错：频率是试验值，概率是客观值，二者不能画等号；试验次数少时频率波动很大。

本章核心概念
  • 样本空间与随机事件
  • 古典概型 P(A)=m/n
  • 互斥事件与对立事件
  • 事件的相互独立性
  • 频率估计概率
关键公式 / 结论
P(A)=m/n；P(A∪B)=P(A)+P(B)−P(A∩B)；P(AB)=P(A)P(B)（独立）
怎么记 / 怎么用
  • 古典概型：先数列样本空间，再数有利事件，最后化简。
  • 「至少」问题：用对立事件 1−P(全不发生)。
  • 独立重复试验：P(X=k)=C(n,k)pᵏ(1−p)ⁿ⁻ᵏ。
公式小题

掷一枚骰子，求点数为偶数的概率。

看解答
偶数有 2、4、6 共 3 个，P=3/6=1/2。
综合题（独立性 + 对立事件）

甲、乙独立射击，命中率分别为 0.8、0.7，求至少一人命中的概率。

看解答
两人都没命中概率 0.2×0.3=0.06；至少一人命中 1−0.06=0.94。
例题

掷骰子，求点数大于 4 的概率。

看解答
5、6 两种，P=2/6=1/3。
易错点
  • 概率不能大于 1，算出大于 1 说明样本点算重了
  • 互斥与对立混淆：对立一定互斥，互斥不一定对立
  • 独立与互斥不是一回事

★二级结论 · 考场直接用

这些不是课本黑体字，但都是从基本公式推出来的「捷径」。先懂怎么来的，再记结论，最后拿题验一遍。

  • f(x+a) = −f(x) ⇒ 周期 T = 2a；f(x+a) = 1/f(x) ⇒ T = 2a
    怎么用：抽象函数求周期：迭代两次回到原式。
    例：f(x+2)=−f(x) ⇒ f(x+4)=f(x)。
  • 奇函数在对称区间单调性相同，偶函数相反
    怎么用：画图记：奇函数像「斜线」，偶函数像「U」。
    例：f 奇且在 (0,+∞) 增 ⇒ 在 (−∞,0) 也增。
  • a sinx + b cosx = √(a²+b²) sin(x+φ)
    怎么用：辅助角公式：先提模长，再找 tanφ = b/a。
    例：sinx+cosx = √2 sin(x+π/4)。
  • a²+b² ≥ 2ab；a+b ≥ 2√(ab)（a,b>0）
    怎么用：两个正数，和定积最大、积定和最小。
    例：a+b=4 ⇒ ab ≤ 4。
  • log_a b = ln b / ln a；log_a b · log_b c = log_a c
    怎么用：换底把不同底统一，链条相乘会「约掉」。
    例：log₂3 · log₃4 = log₂4 = 2。
  • |a+b|² = |a|² + 2a·b + |b|²
    怎么用：向量模长先平方，数量积就出来了。
    例：|a|=2，|b|=1，夹角 60° ⇒ |a+b|²=4+2+1=7。
记法：不要死背一整串，记「它解决什么问题」——看到题里的关键词，能想起用哪条就够了。
