01计数原理

分类加法、分步乘法、排列组合。

6.1分类加法计数原理与分步乘法计数原理

做一件事，如果只有几类互不相交的办法，每类里各有若干种做法，那么总做法数就把各类的做法数加起来，这叫分类加法计数原理。如果这件事要分成几个步骤才做得完，每一步各有若干种做法，那么总做法数就把各步的做法数乘起来，这叫分步乘法计数原理。两个原理说白了就两句话：分类要「不重不漏」，分步要「步步相依」。判断用哪个，只看这件事是「几种情况并列」还是「几个动作接力」。

分类：N = m₁ + m₂ + … + mₙ；分步：N = m₁ × m₂ × … × mₙ。用加法时各类之间不能有重复，用乘法时每一步都不能漏。

怎么用：先问一句：这件事是「要么这样、要么那样」，还是「先这样、再那样」？并列就分类相加，接力就分步相乘。分类前先定一个标准，比如按性别分、按选不选甲分，保证不重不漏；分步时把每一步的做法数写清楚，最后连乘。做完拿一个小数字的例子验一遍。

易错：分类时两类有重叠，同一个办法被数了两次，答案偏大；分步时漏掉一步，或者把「先选甲再选乙」和「先选乙再选甲」当成两种，答案也偏大。还有一类：题目里既有分类又有分步，先把每一步内部乘完，再把各类加起来，顺序弄反就全乱了。

6.2排列与组合

从 n 个不同元素里取出 m 个（m≤n），如果取出的顺序不同就算不同的结果，这叫排列，所有排列的个数记作 A(n,m)；如果只管取出哪 m 个、不管顺序，这叫组合，个数记作 C(n,m)。排列是先选后排，组合是只选不排，两者只差一个「排」字：把每一组选出的 m 个元素再排一次，有 A(m,m) 种排法，所以 A(n,m) = C(n,m)·A(m,m)，反过来 C(n,m) = A(n,m)/A(m,m)。排列数还有一条常用性质：第一个位置有 n 种选法，剩下 m−1 个位置从 n−1 个元素里排，所以 A(n,m) = n·A(n−1,m−1)。

A(n,m) = n(n−1)…(n−m+1) = n!/(n−m)!；A(n,n) = n!；C(n,m) = A(n,m)/A(m,m) = n!/(m!(n−m)!)；C(n,m) = C(n,n−m)；C(n,0) = C(n,n) = 1；C(n+1,m) = C(n,m) + C(n,m−1)。

怎么用：先判「顺序算不算不同」：排队、站队、排名、设密码、分正副班长，这些有序，用 A；选代表、选小组、抽签不分角色，这些无序，用 C。遇到「至少」「至多」，正面分类太碎就反着数：总数减去不合要求的。相邻问题把相邻的绑成一个整体，先内部排再整体排；不相邻问题先排别人，再往空里插。

易错：把组合当排列算，答案大了 A(m,m) 倍；把排列当组合算，答案小了同样的倍数。n 个元素里一个都不取也算一种取法，C(n,0)=1，别写成 0。捆绑法容易忘内部还要排，甲乙相邻要乘 2；插空法容易忘两端也能插。还有：题目说「选出 3 人分别担任三个职务」，这是排列不是组合，别漏乘 3!。

6.3二项式定理

把 (a+b)ⁿ 按乘法展开、合并同类项，得到的是 n+1 个单项式相加，每一项都是 a 的某次幂乘 b 的某次幂，两个指数加起来正好是 n，前面的系数是组合数 C(n,k)。这个展开式叫二项式定理，C(n,k) 叫二项式系数。要分清：二项式系数和「项的系数」不是一回事，项的系数还要把 a、b 自带的数字系数一起乘进去。展开式的第 k+1 项叫通项，求指定项、指定项的系数、常数项，都从通项下手。二项式系数还有一套性质：所有二项式系数之和是 2ⁿ，奇数项与偶数项各占一半，中间那一项（或两项）最大。

(a+b)ⁿ = Σ(k 从 0 到 n) C(n,k)·a^(n−k)·b^k；通项 T(k+1) = C(n,k)·a^(n−k)·b^k；C(n,0)+C(n,1)+…+C(n,n) = 2ⁿ；奇数项二项式系数和 = 偶数项二项式系数和 = 2ⁿ⁻¹；n 为偶数时中间一项 C(n,n/2) 最大，n 为奇数时中间两项 C(n,(n−1)/2) 与 C(n,(n+1)/2) 并列最大。

怎么用：求指定项：先写通项，让字母的指数满足题目要求，解出 k，再代回去算系数。求各项系数和：令 a=b=1；求奇数项和与偶数项和：先令 a=1、b=−1 得到交替和，再和总和加减联立。求常数项，就是让字母的指数等于 0。比二项式系数的大小，看 n 的奇偶，找中间那项。

易错：二项式系数 C(n,k) 和项的系数混为一谈，比如 (2x+1)ⁿ 里系数还要带 2 的幂。通项里的 k 从 0 开始，第 k+1 项对应 b 的 k 次方，题目说「第 5 项」时 k=4，别差一位。求系数和时忘了常数项也参与；赋值法令 x=1，别把「各项系数和」和「二项式系数和」搞混。

本章核心概念
  • 分类加法计数原理：几类互斥方案，总数相加
  • 分步乘法计数原理：几个步骤接力，总数相乘
  • 排列有序用 A(n,m)，组合无序用 C(n,m)
  • 二项式定理：展开式的系数是组合数，通项管单项
  • 二项式系数与项的系数不是一回事
关键公式 / 结论
A(n,m) = n!/(n−m)!；C(n,m) = n!/(m!(n−m)!)；C(n,m) = C(n,n−m)；(a+b)ⁿ = Σ C(n,k)·a^(n−k)·b^k
怎么记 / 怎么用
  • 判断有序无序：排队、排名、设密码用 A；选人、选组、抽签用 C。
  • 分类相加、分步相乘；分类要不重不漏，分步要每步都算到。
  • 二项式题先写通项 T(k+1)=C(n,k)·a^(n−k)·b^k 定 k；求系数和令字母等于 1。
公式小题

计算 C(6,3) + A(4,2)。

看解答
先算组合：C(6,3)=6!/(3!·3!)=(6×5×4)/(3×2×1)=20。再算排列：A(4,2)=4×3=12。相加得 20+12=32。
综合题（分步乘法 + 组合）

从 4 名男生、3 名女生中选 3 人，要求至少有 1 名女生，有多少种选法？

看解答
反面算最快：不加限制从 7 人里选 3 人，C(7,3)=35 种；一名女生都没有，就是全从 4 名男生里选，C(4,3)=4 种；所以至少 1 名女生有 35−4=31 种。正面验一遍：1 女 2 男 C(3,1)C(4,2)=3×6=18，2 女 1 男 C(3,2)C(4,1)=3×4=12，3 女 C(3,3)=1，合计 18+12+1=31，两边一致。
例题

求 (2x+1)⁴ 展开式中 x² 的系数。

看解答
写通项：T(k+1)=C(4,k)·(2x)^(4−k)·1^k。要 x²，令 4−k=2，得 k=2。系数为 C(4,2)·2² = 6×4 = 24。
易错点
  • 有序无序弄反：组合当成排列算，答案大了 A(m,m) 倍
  • 「至少」「至多」正面分类容易漏，优先用总数减去反面
  • 二项式系数与项的系数混淆，通项里的 k 与「第几项」差 1
小测（2 题）
  1. C(6,3) = ?
  2. 5 人排成一排有多少种？
点开看答案
  1. 20（6×5×4 除以 3×2×1）
  2. A(5,5)=5!=120 种

02随机变量及其分布

分布列、期望、方差。

7.1条件概率与全概率公式

在已知 A 发生的条件下，B 发生的概率叫条件概率，记作 P(B|A)。它等于 A、B 同时发生的概率除以 A 的概率，直观上就是把样本空间缩小到 A 里面，重新算一次比例。把乘法公式反过来用，就得到全概率公式：如果事件 B 可能由几种互斥的原因 A₁、A₂、…、Aₙ 引起，那么 B 的概率等于每种原因的概率乘上「在这种原因下 B 发生」的概率，再全部加起来。先分情况、再加权，这是全概率公式的实质。由结果反推原因，用贝叶斯公式。

P(B|A) = P(AB)/P(A)（P(A)>0）；P(AB) = P(A)P(B|A) = P(B)P(A|B)；全概率公式 P(B) = Σ P(Aᵢ)P(B|Aᵢ)；贝叶斯公式 P(Aᵢ|B) = P(Aᵢ)P(B|Aᵢ)/P(B)。

怎么用：看到「在……的条件下」「已知……求……」就先想条件概率：先算分母 P(A)，再算分子 P(AB)。题目分几个阶段、几种来源，就画树状图：第一层写原因，第二层写结果，每条路径的概率相乘，同一结果的各条路径相加。要「结果已经出现，反推是哪个原因造成的」，用贝叶斯公式，分母就是刚算出的全概率。

易错：P(B|A) 和 P(A|B) 写反，这是最常见的错。P(AB) 与 P(A)P(B) 混用：只有 A、B 独立时才能直接相乘。全概率公式里各原因必须互斥且穷尽，漏掉一种情况，分母就少了。条件概率的样本空间已经缩小，不能再拿原来的总数当分母。

7.2离散型随机变量及其分布列

试验结果可以用一个数来表示的随机变量，叫离散型随机变量。把它每个可能取值 xᵢ 和对应的概率 pᵢ 一一列出来，就是分布列，通常写成表格。分布列有两条硬要求：每个 pᵢ 都大于等于 0，所有 pᵢ 加起来等于 1。写分布列就是把「有哪些取值」和「每个取值多大概率」说清楚：先定取值，再逐个算概率，最后验总和。两点分布是最简单的一种，X 只取 0 和 1，P(X=1)=p，P(X=0)=1−p。

P(X=xᵢ) = pᵢ，i=1,2,…,n；pᵢ ≥ 0；Σpᵢ = 1；两点分布 P(X=1)=p，P(X=0)=1−p。

怎么用：三步走：先列全 X 的所有可能取值，别漏 0 和最大值；再对每个取值算概率，古典概型就数样本点，复杂的分情况相加；最后列成表，检查加起来是不是 1。求「X 在某个范围」的概率，就把范围内各取值的概率相加。分布列写完后用 Σpᵢ=1 反求未知参数，是最快的检查手段。

易错：取值漏掉或者多写，比如摸球问题里忘了「一个都没摸到」这种 0。概率算完不检查总和，错了也看不出来。把分布列写成函数解析式，忘了 X 只能取离散的几个值。还有：P(X≤2) 要加 P(X=0)、P(X=1)、P(X=2) 三项，不是只算 P(X=2)。

7.3离散型随机变量的数字特征

均值 E(X) 是把 X 的每个取值乘上它的概率再相加，表示「平均来看 X 取多少」，也叫数学期望。方差 D(X) 是每个取值与均值之差的平方、再乘概率相加，表示 X 的取值有多分散；标准差是方差的算术平方根。均值刻画位置，方差刻画波动，两个都是加权平均，权就是概率。随机变量的数字特征不用做实验，直接从分布列算出来。线性变换 aX+b 的期望和方差有现成公式，不用重新列分布列。

E(X) = Σ xᵢpᵢ；E(aX+b) = aE(X)+b；D(X) = Σ(xᵢ−E(X))²pᵢ = E(X²)−[E(X)]²；D(aX+b) = a²D(X)；σ(X) = √D(X)。

怎么用：先有分布列，再算均值：一行取值乘一行概率，加起来。算方差有两条路：定义法，先算均值再算每个偏差的平方乘概率；公式法，先算 E(X²) 再减均值的平方，数大时用公式法省事。遇到 aX+b 这种线性变换，直接套 E(aX+b)=aE(X)+b、D(aX+b)=a²D(X)。比较两台设备谁稳定，看方差，小的稳定。

易错：D(X) 不是 [E(X)]²，也不是 E(X²)，三者完全不同。D(aX+b) 里常数 b 不影响方差，别写成 a²D(X)+b。方差的单位是原数据单位的平方，比较波动时用标准差更直观。还有：E(X) 不一定是 X 可能取到的值，比如掷一枚骰子，均值是 3.5。

7.4二项分布与超几何分布

做 n 次独立重复试验，每次只有「成功」与「失败」两种结果，成功的概率都是 p，那么成功的次数 X 服从二项分布，记作 X~B(n,p)。如果是不放回地抽样：总体 N 个里有 M 个目标，从中抽 n 个，抽到的目标个数 X 服从超几何分布。两者的分水岭是「放不放回」：有放回、每次概率不变，用二项分布；不放回、每抽一个总体就变，用超几何分布。n 远小于 N 时，超几何分布可以近似看成二项分布。

二项分布 P(X=k) = C(n,k)·p^k·(1−p)^(n−k)，k=0,1,…,n；E(X)=np，D(X)=np(1−p)。超几何分布 P(X=k) = C(M,k)·C(N−M,n−k)/C(N,n)；E(X) = nM/N。

怎么用：先判模型：每次试验独立、概率不变，用二项；从有限总体不放回地抽，用超几何。二项分布套公式时，C(n,k) 别丢，(1−p) 的指数是 n−k。求「至少一次」用对立事件 1−(1−p)ⁿ。判断是不是二项分布，三句话都要对上：次数固定为 n、每次独立、成功概率恒为 p。超几何分布的 k 有范围：max(0, n−(N−M)) ≤ k ≤ min(n,M)。

易错：不放回抽样硬套二项分布，概率算错。二项分布里 (1−p) 的指数写成 k。把「至少一次」直接算成 np。超几何分布的组合数上下标弄反，C(N−M,n−k) 写成 C(N−M,k)。还有：二项分布里的 n 是试验次数，不是别的量。

7.5正态分布

连续型随机变量的概率分布用密度曲线描述。如果这条曲线中间高、两边低、左右对称，像一口钟，就称这个随机变量服从正态分布，记作 X~N(μ,σ²)。μ 是均值，决定钟形的中心位置；σ 是标准差，决定钟形的胖瘦：σ 越小越瘦高、数据越集中，σ 越大越扁平、数据越分散。密度曲线下的总面积是 1，X 落在某个区间的概率就是那一段曲线下的面积。μ=0、σ=1 的情形叫标准正态分布。

f(x) = 1/(σ√(2π))·e^(−(x−μ)²/(2σ²))；曲线关于直线 x=μ 对称；P(μ−σ<X<μ+σ)≈0.6827，P(μ−2σ<X<μ+2σ)≈0.9545，P(μ−3σ<X<μ+3σ)≈0.9973；P(X<μ)=P(X>μ)=0.5。

怎么用：先看对称轴 μ，把要求的区间画在钟形图上，用对称性把不规则区间翻折成规则区间。常用拆分：a>μ 时 P(X<a)=0.5+P(μ<X<a)，P(X>a)=0.5−P(μ<X<a)。题目给 μ、σ 和某个概率，求分界点时，先化成「距 μ 几个 σ」，再对称回去。3σ 原则用来判断异常值：落在 (μ−3σ, μ+3σ) 外的几乎不可能发生。

易错：把 σ² 当成 σ 用，题目给 N(1,4) 时 σ=2，不是 4。对称性用错方向：P(X<μ−a) 与 P(X>μ+a) 相等，不是与 P(X<μ+a) 相等。用 Φ 标准化时忘了先减 μ 再除 σ。还有：正态分布是连续型，P(X=某个具体值)=0，别去算单点概率。

本章核心概念
  • 条件概率 P(B|A)=P(AB)/P(A)，样本空间缩小到 A
  • 分布列两条硬要求：pᵢ≥0，Σpᵢ=1
  • E(X)=Σxᵢpᵢ，D(X)=E(X²)−[E(X)]²
  • 二项分布看「独立重复」，超几何分布看「不放回」
  • 正态曲线关于 x=μ 对称，σ 决定胖瘦
关键公式 / 结论
P(B|A) = P(AB)/P(A)；E(X) = Σxᵢpᵢ；D(X) = E(X²)−[E(X)]²；D(aX+b) = a²D(X)；X~B(n,p) 时 E=np，D=np(1−p)
怎么记 / 怎么用
  • 先认模型：独立重复用二项，不放回抽样用超几何，连续对称用正态。
  • 分布列写完先加一遍，概率和必须是 1，不对就回头查。
  • 线性变换用 E(aX+b)=aE(X)+b、D(aX+b)=a²D(X)，不用重列分布列。
公式小题

X~B(3, 1/2)，求 E(X) 与 D(X)。

看解答
二项分布直接套：E(X)=np=3×(1/2)=1.5；D(X)=np(1−p)=3×(1/2)×(1/2)=0.75。想验算就列分布列：P(X=0)=1/8，P(X=1)=3/8，P(X=2)=3/8，P(X=3)=1/8，和是 1；均值 0×1/8+1×3/8+2×3/8+3×1/8=12/8=1.5，对得上。
综合题（全概率公式 + 条件概率）

甲箱有 2 红 3 白，乙箱有 3 红 2 白。先等可能地随机选一箱，再从箱中取一球。求取到红球的概率；若取到红球，求它来自甲箱的概率。

看解答
设 A=选到甲箱，B=取到红球。P(A)=P(Ā)=1/2，P(B|A)=2/5，P(B|Ā)=3/5。全概率公式：P(B)=1/2×2/5 + 1/2×3/5 = 1/5 + 3/10 = 1/2。贝叶斯公式：P(A|B)=P(A)P(B|A)/P(B) = (1/2×2/5)/(1/2) = (1/5)/(1/2) = 2/5。
例题

袋中有 3 红 2 白共 5 球，不放回地取 2 球，求红球个数 X 的分布列与 E(X)。

看解答
X 可取 0、1、2。P(X=0)=C(3,0)C(2,2)/C(5,2)=1/10；P(X=1)=C(3,1)C(2,1)/C(5,2)=6/10；P(X=2)=C(3,2)C(2,0)/C(5,2)=3/10。和为 1。E(X)=0×1/10+1×6/10+2×3/10=1.2，与超几何期望 nM/N=2×3/5=1.2 一致。
易错点
  • 分布列写完要检查概率和是不是 1
  • D(X) 不是 [E(X)]²，也不是 E(X²)
  • P(B|A) 与 P(A|B) 写反；只有独立才能 P(AB)=P(A)P(B)
小测（2 题）
  1. X~B(4,1/2)，E(X)=?
  2. D(2X) 与 D(X) 的关系？
点开看答案
  1. E=np=4×1/2=2
  2. D(2X)=2²D(X)=4D(X)

03成对数据的统计分析

相关系数、回归直线。

8.1成对数据的统计相关性

两个变量之间，一个变化另一个也跟着变，但又不能用一个公式精确算出来，这种关系叫相关关系。把成对数据画成散点图，如果点大致沿着一条直线走，就叫线性相关：直线向上倾斜是正相关，向下倾斜是负相关。散点图只能看个大概，要量化「线性相关有多强」，就用样本相关系数 r。r 的绝对值越接近 1，点越贴近一条直线；越接近 0，线性关系越弱。

r = Σ(xᵢ−x̄)(yᵢ−ȳ) / √(Σ(xᵢ−x̄)²·Σ(yᵢ−ȳ)²)；−1 ≤ r ≤ 1；r>0 为正相关，r<0 为负相关；|r| 越接近 1，线性相关越强。

怎么用：先画散点图看形状，再算 r 定量。算 r 分四步：求 x̄ 和 ȳ；算每个 xᵢ−x̄ 与 yᵢ−ȳ；分子求乘积和，分母求两个平方和再开方；最后相除。判断强弱记一句话：越接近 ±1 越强，越接近 0 越弱。还要会说「相关不等于因果」，r 大只说明同步变化，不说明谁引起谁。

易错：r 的公式漏掉分母的根号，算出来会大于 1。r=0 只说明没有线性相关，不代表两个变量没关系，可能是弯曲的关系。把负相关当成「相关弱」，其实 r=−0.9 比 r=0.5 强得多。还有：相关系数受异常值影响很大，一个离群点能把 r 拉得很偏。

8.2一元线性回归模型及其应用

两个变量线性相关时，我们想用 x 去预测 y，就建一元线性回归模型：Y = bx + a + e，其中 bx+a 是 x 决定的直线部分，e 是随机误差，满足 E(e)=0、D(e)=σ²。用样本估计出 b、a 的估计值 b̂、â，得到经验回归方程 ŷ = b̂x + â。这条直线是所有直线里「残差平方和最小」的那一条，所以叫最小二乘估计，它一定经过样本中心点 (x̄, ȳ)。

b̂ = Σ(xᵢ−x̄)(yᵢ−ȳ) / Σ(xᵢ−x̄)²；â = ȳ − b̂x̄；经验回归方程 ŷ = b̂x + â；残差 êᵢ = yᵢ − ŷᵢ；R² = 1 − Σ(yᵢ−ŷᵢ)²/Σ(yᵢ−ȳ)²。

怎么用：求回归方程三步：算 x̄、ȳ；套公式算 b̂，它的分子和相关系数的分子是同一个；用 â=ȳ−b̂x̄ 算截距。预测时把 x 代进方程，别外推太远。判断拟合好坏看 R²，越接近 1 解释得越好。看残差图：点随机散布在 0 附近说明模型合适，出现明显形状说明该换模型。b̂ 的含义是「x 每增加 1 个单位，y 平均变化 b̂ 个单位」。

易错：把 b̂ 说成「x 增加 1，y 一定增加 b̂」，其实是平均变化，不是必然。截距 â 在 x=0 没有实际意义时，别硬解释。回归直线不一定过原点，除非 ȳ 恰好等于 b̂x̄。用 x 预测 y 可以，反过来把方程解出 x 去预测 y 不行，那不是同一条直线。外推超出样本范围，结论不可靠。

8.3列联表与独立性检验

两个分类变量（比如性别与是否喜欢某门课）之间有没有关联，先把数据整理成 2×2 列联表，四个格子的数分别记 a、b、c、d。独立性检验先假设「两个变量无关」，在这个假设下算一个统计量 χ²，看实际数据和「无关」差多远。χ² 越小，越支持「无关」；χ² 越大，越有把握说「有关」。最后查临界值表，按小概率标准下结论。

χ² = n(ad−bc)² / ((a+b)(c+d)(a+c)(b+d))，其中 n=a+b+c+d；临界值：χ²≥2.706 时有 90% 把握，≥3.841 时有 95%，≥6.635 时有 99%，≥10.828 时有 99.9%。

怎么用：四步走：列 2×2 列联表，标清 a、b、c、d；算 n 和四个和；代入 χ² 公式，分子别忘了乘 n、括号里别忘了平方；拿 χ² 和临界值比，写结论时带上「在犯错误概率不超过 0.05 的前提下，认为两变量有关」。结论要完整：既说有没有关联，也说这个判断的可靠程度。

易错：χ² 公式忘了乘 n，或者 (ad−bc) 忘了平方，结果差很远。a、b、c、d 的位置摆错，行列颠倒，数就对不上。结论写成「两变量一定有关」，检验只给概率把握，不给绝对结论。把「没有充分证据认为有关」说成「证明无关」，这是两回事。样本量太小时，χ² 检验不可靠。

本章核心概念
  • 散点图看相关的方向与强弱
  • 相关系数 r∈[−1,1]，越接近 ±1 线性越强
  • 回归直线过样本中心点 (x̄, ȳ)，残差平方和最小
  • R² 越接近 1，回归拟合得越好
  • 独立性检验：χ² 越大，越有把握认为两变量有关
关键公式 / 结论
r = Σ(xᵢ−x̄)(yᵢ−ȳ)/√(Σ(xᵢ−x̄)²Σ(yᵢ−ȳ)²)；b̂ = Σ(xᵢ−x̄)(yᵢ−ȳ)/Σ(xᵢ−x̄)²；â = ȳ−b̂x̄；χ² = n(ad−bc)²/((a+b)(c+d)(a+c)(b+d))
怎么记 / 怎么用
  • 先画散点图，再算 r；r 只量线性关系，弯曲的关系它看不出来。
  • 求回归方程：先算两个平均数，再算 b̂，最后 â=ȳ−b̂x̄，写完把 x̄ 代进去验证 ŷ=ȳ。
  • 独立性检验四步：列联表、算 χ²、查临界值、带上把握程度下结论。
公式小题

已知经验回归方程 ŷ = 2x + 1，x̄ = 3，求 ȳ。

看解答
经验回归直线一定过样本中心点 (x̄, ȳ)。把 x̄=3 代入方程：ŷ=2×3+1=7，所以 ȳ=7。
综合题（相关系数 + 回归方程）

某组数据 x̄=2，ȳ=5，Σ(xᵢ−x̄)(yᵢ−ȳ)=8，Σ(xᵢ−x̄)²=4，Σ(yᵢ−ȳ)²=25。求 b̂、â 与经验回归方程；再求相关系数 r，并判断线性相关的强弱。

看解答
先求斜率：b̂ = 8/4 = 2。再求截距：â = ȳ − b̂x̄ = 5 − 2×2 = 1。经验回归方程为 ŷ = 2x+1，代 x̄=2 得 ŷ=5=ȳ，验算通过。相关系数 r = 8/√(4×25) = 8/10 = 0.8。r>0 说明正相关，|r|=0.8 比较接近 1，说明两变量有较强的正线性相关。
例题

某校调查 100 名学生是否喜欢数学，男生 50 人中喜欢 30 人，女生 50 人中喜欢 20 人。列出 2×2 列联表并计算 χ²，判断能否在犯错误概率不超过 0.05 的前提下认为性别与是否喜欢数学有关。

看解答
列联表：喜欢、不喜欢、合计，男生 30、20、50，女生 20、30、50，合计 50、50、100。这里 a=30，b=20，c=20，d=30，n=100。χ² = 100×(30×30−20×20)²/(50×50×50×50) = 100×500²/6250000 = 100×250000/6250000 = 4。因为 4>3.841，所以在犯错误概率不超过 0.05 的前提下，认为性别与是否喜欢数学有关。
易错点
  • r 为负表示负相关，不是相关弱
  • 回归直线不一定过原点，但一定过 (x̄, ȳ)
  • χ² 公式漏乘 n、漏平方，或把「没有证据认为有关」说成「证明无关」
小测（2 题）
  1. r = 0.9 说明什么？
  2. 回归直线一定过哪个点？
点开看答案
  1. 正相关，且 |r| 接近 1，线性相关较强
  2. 样本中心点 (x̄, ȳ)

★二级结论 · 考场直接用

这些不是课本黑体字，但都是从基本公式推出来的「捷径」。先懂怎么来的，再记结论，最后拿题验一遍。

  • C(n,0)+C(n,1)+…+C(n,n) = 2ⁿ；奇数项和 = 偶数项和 = 2ⁿ⁻¹
    怎么用：令 (1+1)ⁿ 和 (1−1)ⁿ 相加相减。
    例：n=4：总和 16，各半 8。
  • 二项分布 X~B(n,p)：E = np，D = np(1−p)
    怎么用：期望是「次数×概率」，方差再乘失败概率。
    例：n=10，p=0.3 ⇒ E=3，D=2.1。
  • 超几何分布 E = n·M/N
    怎么用：抽 n 个、总体 N 个、其中 M 个目标。
    例：N=10，M=3，n=4 ⇒ E=1.2。
  • 回归直线必过样本中心 (x̄, ȳ)
    怎么用：求回归方程先算两个平均数，再代。
    例：x̄=3，ȳ=7，斜率 2 ⇒ 截距 1。
  • 排列组合：相邻捆绑、不相邻插空
    怎么用：「必须挨着」绑成一个人；「不能挨着」先排别人再插空。
    例：5 人排一排，甲乙相邻：2×4! = 48。
  • 正态分布：P(μ−σ
    怎么用：对称性：两边各 0.3413；2σ 约 0.9545。
    例：P(X<μ+σ) ≈ 0.8413。
记法：不要死背一整串，记「它解决什么问题」——看到题里的关键词，能想起用哪条就够了。
