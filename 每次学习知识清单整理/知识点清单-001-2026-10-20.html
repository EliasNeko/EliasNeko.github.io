01网页的三层

一个网页由三层组成，各管一件事，最好别混着写：

层语言管什么
结构HTML有什么内容、谁包含谁
样式CSS长什么样：颜色、大小、位置
行为JavaScript点了会怎样、数据怎么变
备注：咱们的咖啡店现在只有前两层，第三层（购物车）还没上。先把结构写对、样式写顺，交互才不打架。

02HTML 骨架

每个页面都是同一副骨架，背下来都不亏：

<!DOCTYPE html>
<html lang="zh-CN">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>龙潜猫隐的咖啡店</title>
  </head>
  <body>
    ……看得见的内容全在这里……
  </body>
</html>
备注：中文乱码，第一个怀疑对象就是 charset="UTF-8"。手机端能正常缩放，靠的是那行 viewport——没有它，手机上你的页面会缩成一小块。

03常用标签

标签不是越多越好，用“意思对”的那个：

<section class="hero">   一个区块
<nav>                    导航
<h1> ~ <h6>              标题，h1 一页尽量只一个
<p>                      段落
<a href="#menu">          链接
<ul> <li>                列表
<article class="card">   一张独立的卡片
<div> / <span>           纯盒子，没有语义
<button>                 按钮
<img src="..." alt="..."> 图片，alt 一定要写
备注：div 是万能盒子，但全用 div 的页面像一间没有门牌的房子。语义标签让代码更可读，也利于搜索引擎和屏幕阅读器。

04class 与 id

两个都是“起名字”，但用处不同：

class="card"     可以重复用，一页能有很多个
id="menu"        全页唯一，锚点跳转靠它

<a href="#menu">菜单</a>     ← 跳到本页 id=menu 的位置
<section id="menu">         ← 被跳到的目标
备注：href 里那个 # 是关键。写 href="menu"，浏览器会去找一个叫 menu 的文件，然后报「未能加载页面」——这个坑咱们踩过。

05选择器

CSS 的第一句话永远是“选中谁”，然后才是“改成什么样”：

p { }              标签选择器：所有 <p>
.hero { }          类选择器：class="hero" 的元素
.hero h1 { }       后代选择器：.hero 里面的 h1
.btn:hover { }     伪类：鼠标悬停时
* { }              通配：所有元素
备注：少了那个点，意思完全变了。nav-links a 找的是名叫 <nav-links> 的标签——世界上根本没有这个东西，所以整条规则被默默跳过。

06层叠与优先级

同一个元素被多条规则选中时，谁说了算：

/* 同一个规则里，写在后边的赢 */
.hero h1 {
  letter-spacing: 3px;    ← 被下面覆盖
  letter-spacing: 10px;   ← 真正生效的是这句
}
备注：这就是昨晚最后那个坑：新写了一行 48px，旧的那行忘了删，结果旧规则继续生效。改样式时，先删旧的，再加新的。

07盒模型

页面上每个元素都是一个盒子，从里到外四层：

content（内容）
  ↑ padding（内边距，撑开自己和边框的距离）
  ↑ border（边框）
  ↑ margin（外边距，推开别的盒子）

/* 起手式：让宽度包含 padding 和 border */
* { margin: 0; padding: 0; box-sizing: border-box; }
备注：不写 box-sizing: border-box 的话，你设 width: 300px 再加 20px 内边距，实际会变成 340px——这是新手最常遇到的“算不准”。

08单位

单位含义用在哪
px像素，绝对单位字号、边框、间距
%相对父元素宽度
vh / vw视口高度 / 宽度的 1%100vh = 正好一屏
frGrid 里的“份”平分剩余空间
备注：首屏那个 min-height: 100vh，就是让头图不管什么屏幕都铺满一屏。

09Flex 布局

一维布局：让一堆东西横着或竖着排，还能对齐。

/* 居中三件套：hero 就是这么居中的 */
.hero {
  display: flex;
  flex-direction: column;      /* 竖着排 */
  justify-content: center;     /* 主轴居中（竖排时是上下） */
  align-items: center;         /* 交叉轴居中（竖排时是左右） */
}

/* 两端对齐：导航栏 logo 在左、菜单在右 */
.nav { display: flex; justify-content: space-between; }
备注：记口诀：justify 管主轴，align 管交叉轴。换个 flex-direction，它俩的方向也跟着换，别死记“水平垂直”。

10Grid 布局

二维布局：同时管行和列，卡片列表的最佳选择。

/* 一行魔法：能放几列就放几列，最少 260px，剩下的平分 */
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(260px, 1fr));
  gap: 28px;
}
备注：Grid 是爸爸的属性，管的是孩子怎么排。三张卡片各自包一个 .cards，就变成三个爸爸各带一个孩子，永远排不出三列——这个坑咱们踩过。拖动窗口宽度试试，卡片会自动变三列、两列、一列。

11定位与层级

.nav {
  position: fixed;     /* 钉在窗口上，滚动不动 */
  top: 0; left: 0; right: 0;
  z-index: 10;         /* 层级，数字大的在上 */
}
备注：fixed 会把元素从正常文档流里“揪出来”，后面的内容会当它不存在，可能被它盖住——通常给页面加个上内边距来避让。z-index 不加，滚动时内容可能会从导航上面划过去。

12颜色与质感

color: #c9a86a;                         十六进制：金
background: rgba(20, 16, 14, 0.65);     带透明度的黑
background: radial-gradient(circle at 50% 30%, #3a2a1e, #14100e);
border-radius: 999px;                   圆角胶囊
box-shadow: 0 20px 40px rgba(0,0,0,.45);
backdrop-filter: blur(10px);            毛玻璃
transition: all 0.3s;                   变化要慢慢来
transform: translateY(-8px);            往上抬 8px
备注：#c9a86a 是三位一组：红 c9、绿 a8、蓝 6a。rgba 的第四个数是透明度，0 全透、1 不透。阴影写成 0.20px 会整条失效，因为 0 后面不该有小数点。

13交互状态

.btn:hover { background: #c9a86a; color: #14100e; }

button {
  cursor: pointer;        鼠标变成小手
  font-family: inherit;   否则按钮不继承页面字体
}
备注：:hover 是“鼠标停上去的时候”。按钮、输入框这类表单控件默认不继承字体，所以总要多写一句 font-family: inherit，不然字体跟全站不搭。

14调试方法

CSS 最大的特点是：写错不报错，只是悄悄不生效。所以得学会自己找。

现象说明怎么办
规则面板里找不到这条规则选择器没匹配上查类名拼写、查那个点
规则被划了横线被别的规则覆盖了看谁更靠后、谁更具体
整块样式没反应可能写在 <style> 外面检查标签是否闭合
备注：快捷键：F12 开面板，Ctrl + Shift + C 点选元素。养成“先看它匹配了没”的习惯，能省掉一大半抓狂时间。

15第一晚踩过的六个坑

#你写的正确后果
1class="bin"class="btn"样式完全不生效
2nav-links a.nav-links a链接还是蓝色下划线
3href="menu"href="#menu"报「未能加载页面」
4三个 .cards一个 .cards卡片竖着排，不成网格
50.20px 40px0 20px 40px阴影整条失效
6旧 letter-spacing 没删删掉旧的那行新字号被旧字距覆盖
备注：六个坑里有五个都是“名字/符号写错”，没有一个涉及高深语法。前端入门期，拼写就是技术。
