02同一套 Grid 再用一次

门店区的左右两栏，用的还是卡片那行代码，只是把最小宽度改大了：

/* 三张卡片：一列最小 260px，能放三列 */
.cards { grid-template-columns: repeat(auto-fit, minmax(260px, 1fr)); }

/* 门店两栏：一列最小 280px，放不下三列，正好两栏 */
.store-box { grid-template-columns: repeat(auto-fit, minmax(280px, 1fr)); }
备注：同一个套路，换个数字就是另一种版式。这就是「学原理」比「抄代码」值钱的地方——你只需要记住这一行能干什么，剩下的靠调参。

03:not() 否定伪类

门店信息里，「地址 / 电话 / 怎么来」三个标签，第一个上面不要留白，后面两个要留：

/* 所有 label 的样式 */
.store-info .label { margin-bottom: 4px; }

/* 除了第一个之外的 label，上面留 26px */
.store-info .label:not(:first-child) { margin-top: 26px; }
备注：没有 :not() 的话，你得给第一个标签单独加一个类去覆盖——多一个类，多一处要维护。能用一个选择器解决的，别加类。

04主信息与副信息

地址拆成两行之后，需要让第二行「退后一步」：

<p>湖南省株洲市石峰区田心大道 18 号</p>
<p class="small">湖南铁道职业技术学院（田心南校区）</p>

.small { font-size: 13px; color: #8d7f6d; margin-top: 4px; }
备注：「小一号 + 暗一档」是最省力的层级手段。层级不是靠加粗、加大、加颜色堆出来的，是靠对比拉开的。

05排版三件套

故事区从「不整洁」变「像杂志」，主要靠三个数字：

.story { max-width: 660px; margin: 0 auto; }   /* 收窄 */

.story-body p {
  font-size: 16px;      /* 从 15 提到 16 */
  line-height: 2.05;    /* 松一点 */
  margin-bottom: 22px;  /* 段距固定，不再用 <br><br> */
}
备注：<br><br> 是「手写排版」，间距全凭感觉；margin-bottom 是「排版系统」，间距是一个可以调的数字。能用规则的地方，别用手感。

06一行多少字

中文正文一行 18–24 个字读着最舒服。超过 30 字，眼睛扫到行尾再折回来，会很累。

660px ÷ 16px ≈ 41 个字   ← 这是「字符数」上限
但中文一个字约等于一个字号宽，实际一行约 30+ 字
所以真要舒服，宽度还可以再收到 560–600px
备注：这是「杂志和网页」最大的差别之一：杂志栏宽由纸张决定，网页的栏宽要你自己决定。宽度是排版的第一个决定，不是字号。

07衬线体与字重

.story h2 {
  font-family: "Songti SC", "SimSun", serif;   /* 宋体 */
  font-weight: 400;                            /* 细，不粗 */
  letter-spacing: 3px;
  line-height: 1.75;
}
备注：黑体厚重、适合标题和界面；宋体清瘦、适合讲故事。同一个标题，换一种字体，气质完全不同——字体是情绪，不是格式。

08两端对齐

.story-body {
  text-align: justify;
  text-justify: inter-ideograph;   /* 中文按字间距分配，不留大洞 */
}
备注：中文用 justify 效果通常不错，因为汉字等宽；英文用 justify 有时会把单词间距撑得很难看。所以「同一个属性，中英文结果不同」。

09伪元素做水印

故事区背后那个巨大的「01」，不是图片，是 CSS 画出来的：

.story { position: relative; }

.story::before {
  content: "01";
  position: absolute;
  top: 28px; left: 50%;
  transform: translateX(-50%);
  font-family: Georgia, serif;
  font-size: 190px;
  color: rgba(201, 168, 106, 0.04);   /* 4% 透明度 */
  pointer-events: none;               /* 别挡住鼠标 */
}
备注：content 让伪元素有内容，position: absolute 让它脱离排版，父元素必须写 position: relative 才有定位参照。「高级感」最便宜的做法：给背景一个巨大的、几乎看不见的字。

10标签两边的短线

.kicker {
  display: inline-flex;
  align-items: center;
  gap: 14px;
}

.kicker::before,
.kicker::after {
  content: "";
  width: 26px;
  height: 1px;
  background: rgba(201, 168, 106, 0.45);
}
备注：用伪元素「画」两条线，而不是插两个 <span>。页面上那些精致的细线、小三角、圆点，九成都是伪元素画的，不用图片。

11text-wrap 的边界

拿它去解决「一家」被拆到两行的问题——没效果，而且不是写错了。

text-wrap: pretty;   /* 管的是：最后一行只剩一两个字 */
                     /* 不管：一个词被拆到两行 */
备注：中文没有空格，浏览器按「字」断行，它不知道「一家」是一个词。所以真正管用的是改文案，或者用 white-space: nowrap 把词焊住。 遇到「属性没反应」，先问：这个属性到底管什么？

12中文标点

错对为什么
决定。—— 开一家决定：开一家句号和破折号不能连用，两个都是停顿
决定: 开一家决定：开一家中文用全角冒号，后面不加空格
怀化市石峰区株洲市石峰区石峰区属于株洲，田心也在株洲
备注：标点不影响代码运行，但它决定「看起来专不专业」。代码是给机器看的，排版是给人看的。

13对齐线

页脚和门店的左边缘差了 48px，原因是内容宽度算错了：

/* 门店：1100 的盒子里含 48 的内边距 → 内容宽 1004 */
.store { max-width: 1100px; padding: 100px 48px; }

/* 页脚：1100 的盒子里没有内边距 → 内容宽 1100 */
.footer-inner { max-width: 1100px; }

/* 修法：让页脚也留出 48 */
.footer-inner { padding-left: 48px; padding-right: 48px; }
备注：全局 box-sizing: border-box 之后，padding 是「从宽度里扣」的。所以你以为一样宽的两块，其实内容宽度差了两个 padding。拉一条竖线看对齐，是设计师最常用的检查动作。

14页脚的三列

.footer-inner {
  display: grid;
  grid-template-columns: 2fr 1fr 1fr;   /* 品牌占两份，两列信息各一份 */
  gap: 40px;
}

.footer-bottom {
  display: flex;
  justify-content: space-between;       /* 版权在左，落款在右 */
  border-top: 1px solid rgba(201,168,106,0.1);
}
备注：fr 是「份」，不是像素。2fr + 1fr + 1fr = 四份，第一列占两份宽。页脚那条 border-top 很重要——没有它，页脚像没关好的抽屉。

15窄屏兜底

@media (max-width: 820px) {
  .footer-inner {
    grid-template-columns: 1fr;   /* 三列变一列 */
    gap: 32px;
  }
  .footer-bottom {
    flex-direction: column;       /* 左右变上下 */
  }
}
备注：@media 是「当屏幕小于 820px 时，换一套规则」。桌面优先、手机兜底，是最常见的写法。响应式不是技术，是替用户着想。
