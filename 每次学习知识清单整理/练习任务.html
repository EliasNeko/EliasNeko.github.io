这些题是给你在自己电脑上做的：不给答案，也不在课程里挖坑——课程负责讲明白，任务负责让你动手。 每门三门，从易到难；做不出来就回课程里找对应那一节，别硬扛。

Python

  1. 读一个 CSV 文件，统计每个城市的订单数，按数量倒序打印前 5 个。
  2. 写一个命令行记账：add 金额 备注 / list / total，数据存 JSON。
  3. 用 requests 抓一个公开网页，把标题和所有链接打印出来。

Java

  1. 写一个 Coffee 类（名称、价格），主程序读入数量，算总价并四舍五入到分。
  2. 用 ArrayList 做一个通讯录：增、删、按名字查，控制台菜单操作。
  3. 把订单数据写进文件，程序重启后还能读出来（对象转 JSON 或逐行文本都可以）。

C 语言

  1. 输入 10 个整数，用冒泡排序排好输出，要求用函数拆分。
  2. 写一个结构体数组存 5 本书（书名、价格），按价格排序输出。
  3. 读一个文本文件，统计行数、单词数、字符数（类似 wc 命令）。

JavaScript

  1. 做一个待办清单：添加、勾选完成、删除，刷新后还在（localStorage）。
  2. 写一个倒计时页面：输入分钟数，归零时弹提示。
  3. 用 fetch 拉一个公开 JSON 接口，把结果渲染成卡片列表。

Rust

  1. 写一个猜数字游戏：随机 1-100，提示大了小了，统计猜了几次。
  2. 读一个文本文件，统计每个单词出现次数，输出前 10。
  3. 定义一个结构体表示咖啡，写方法计算总价，用 Vec 存多杯。

Go

  1. 写一个并发下载器：三个网址同时抓，打印状态码和耗时。
  2. 用 net/http 写一个接口，返回 JSON 格式的咖啡菜单。
  3. 读一个日志文件，统计每种错误出现的次数。

Lua

  1. 写一个命令行记账：add / list / total，数据存文本文件。
  2. 用表实现一个简单的栈：push、pop、peek。
  3. 读一个配置文件（key=value 格式），解析成表并打印。

Kotlin

  1. 写一个控制台记账：add / list / del，数据存文件。
  2. 用 data class 表示学生，按成绩排序并输出前三名。
  3. 读一个 CSV，过滤出某一列满足条件的行，打印结果。

MySQL

  1. 建 orders 表，插入 10 条测试数据，写出「每人消费总额」查询。
  2. 给某个字段加索引，用 EXPLAIN 对比加索引前后的执行计划。
  3. 用事务模拟转账：扣款、加款、提交；中途手动 ROLLBACK 看数据。

Anaconda

  1. 建一个 data 环境，装 numpy、pandas、matplotlib，导出 environment.yml。
  2. 在另一个环境里装不同版本的 pandas，确认两个环境互不影响。
  3. 用 Jupyter 读一个 CSV，画一张折线图并保存成图片。

Node.js

  1. 写一个接口：GET /api/list 返回 JSON，POST /api/add 往里加一条。
  2. 用 fs 写一个文件统计脚本：行数、字符数。
  3. 用 Express 写一个静态文件服务器，能打开本地 HTML。

Git

  1. 给一个项目建仓库，写 .gitignore，提交并推到 GitHub。
  2. 开一个分支改点东西，合并回 main，故意制造一次冲突并解决。
  3. 用 git log / git diff / git show 复述一次提交改了什么。
