先给结论：VS Code

我现在所有代码都用它写：网页、Java 后端、C 语言作业、Python 脚本。它不是「最好的编辑器」，但它是一个能装下所有语言的地方——换语言不用换软件。

免费、Windows / Mac / Linux 都有，装完是英文的，装个中文包就变中文。

我的设置（可以照抄）

  • 字号 15：1080P 屏幕下不累眼
  • 保存时自动格式化：editor.formatOnSave: true
  • 自动保存：files.autoSave: "afterDelay"，写一半切窗口不怕丢
  • 终端字体：Consolas + 微软雅黑，中文注释不乱码
  • 删除不二次确认：explorer.confirmDelete: false，手快的时候很爽，手滑的时候很痛

为什么最后留在 VS Code

  • 一个软件装下所有语言：今天写 HTML、明天写 Java、后天写 C，不用来回换 IDE
  • 免费且跨平台：宿舍 Windows、机房 Windows、以后 Mac 都能用同一套配置
  • 插件按需装：不写 Java 就不装 Java 包，编辑器不会一上来就几百 MB
  • 终端就在下面：Ctrl + ` 打开，编译、跑服务器不用切窗口
  • Git 集成：改了哪些文件、要不要提交，左边一眼看到
  • 远程开发：以后连服务器写代码，也是它

缺点也说清楚：它不是 IDE。大型 Java 项目的重构、Spring 那一套，IDEA 还是更强；Python 的科学计算，PyCharm 的调试更顺。等你真做到那一步，再换也不迟。

几个每天都会用到的快捷键

  • Ctrl + P：按文件名跳转，比点目录快
  • Ctrl + Shift + P：命令面板，所有功能都能搜
  • Ctrl + `：打开 / 关闭终端
  • Ctrl + B：收起侧边栏，屏幕小的时候很有用
  • Alt + ↑ / ↓：整行上下移动
  • Shift + Alt + F：格式化当前文件
  • F5：启动调试

如果你现在要装

  • 只写网页：装 Live Server + Prettier + HTML CSS Support 就够了
  • 要写 Java：装 Extension Pack for Java，再确认电脑有 JDK 17
  • 要写 C：装 C/C++，Windows 上还要有 MinGW 或 MSVC 编译器
  • 要写 Python：装 Python，它会自动带 Pylance

装完别急着装一堆插件。先写一个能跑起来的文件，再按需要加。
