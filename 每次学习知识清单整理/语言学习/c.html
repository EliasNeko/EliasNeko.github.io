01它是什么

C 语言 1972 年诞生在贝尔实验室，本来是为了写 UNIX 操作系统 才发明的。五十年过去，它还在——Linux 内核、Python 解释器、你手机里的芯片固件，底层全是 C。

它和 Python、Java 最大的区别：C 不替你收拾烂摊子。

内存你自己申请（malloc）、自己归还（free）。忘了还，就是内存泄漏；还错了，程序直接崩
检查数组越界、指针乱指，编译器不管，运行时也不一定报错——直接给你一个「段错误」
速度快。C 写的代码几乎能直接变成机器指令，没有垃圾回收、没有虚拟机
抽象很少。你能直接操作内存地址，这是它的力量，也是它的危险
一句话：C 是没有安全网的语言。学会它，你对「程序到底在干什么」的理解会完成一次升级；但你也会第一次真的把程序写崩。

04装好，让它跑起来

Windows 上最省事的是 MinGW-w64（自带 gcc），或者直接装 Dev-C++（学生常用，自带编译器）。

第 1 步装 MinGW-w64（推荐 winlibs.com 的压缩包），解压到 C:\mingw64
第 2 步把 C:\mingw64\bin 加进系统环境变量 Path
第 3 步新开 cmd，敲 gcc --version，出版本号才算成
第 4 步新建 hello.c，写下面几行
#include <stdio.h>

int main(void) {
    printf("你好，世界\n");
    return 0;
}
gcc hello.c -o hello.exe     ← 编译
hello.exe                    ← 运行
#include <stdio.h>引入标准输入输出库。printf 靠它，不写就报「未声明」
int main(void)程序入口，必须有，返回 int
return 0;告诉系统「正常结束」。非 0 表示出错
\n换行符。C 里不用它，输出会全挤在一行
三个新手坑：① 每条语句要以分号结尾；② 编译报错先看第一条，后面的往往是连锁反应；③ 中文乱码是编码问题——文件存成 UTF-8，Windows 控制台可能要 chcp 65001。

05第一行代码：printf 和 scanf

#include <stdio.h>

int main(void) {
    printf("你好，世界\n");
    printf("数字：%d，小数：%.2f，字符：%c\n", 42, 3.14159, 'A');

    int age;
    printf("你几岁？");
    scanf("%d", &age);        // 注意这个 &
    printf("你 %d 岁\n", age);

    return 0;
}
%d整数%f小数
%c单个字符%s字符串
%.2f保留两位小数%ldlong
最常见的崩溃：scanf("%d", age) 少写 &——程序会当场崩（段错误）。scanf 要地址，printf 要值。这一条能救你无数次。

06变量与类型

#include <stdio.h>

int main(void) {
    int age = 18;
    float price = 19.9f;        // 小数常量加 f
    double pi = 3.1415926;      // 默认就是 double
    char level = 'A';           // 单引号，一个字符
    long big = 123456789L;
    unsigned int count = 10;    // 不能为负

    printf("%d %f %lf %c\n", age, price, pi, level);
    printf("size of int = %zu\n", sizeof(int));   // 4（字节）
    return 0;
}
int整数，一般 4 字节
char1 字节。既能存字符，也能存小整数
float / double单精度 / 双精度小数。C 里小数默认 double
sizeof看一个类型占几字节。C 不保证 int 一定是 4 字节
没有 StringC 没有字符串类型，字符串就是一个 char 数组（第 08 节讲）
和 Python/Java 最大的不同：变量不初始化就可能是任何值（垃圾数据）。声明时就给初值，是个好习惯。

07数字与运算

int a = 7, b = 2;
printf("%d\n", a / b);      // 3   ← 整数相除，砍掉小数
printf("%d\n", a % b);      // 1   ← 余数
printf("%f\n", a / 2.0);    // 3.500000
printf("%d\n", 10 > 3);     // 1   ← C 里「真」是 1，「假」是 0

int x = 5;
x++;            // 6
x += 3;         // 9
printf("%d\n", x);
布尔C 没有 true/false（C99 可以 #include <stdbool.h>）。用 0 表示假，非 0 表示真
整数除法7 / 2 是 3，不是 3.5。想得小数，至少一边是 double
溢出int 大约 ±21 亿，超了不会报错，会变成负数
自增i++ 先用后加，++i 先加后用。单独一行时没差别
坑：0.1 + 0.2 != 0.3，所有语言都一样。涉及钱，用整数「分」来算。

08数组与字符串

#include <stdio.h>
#include <string.h>

int main(void) {
    int nums[5] = {90, 85, 77, 60, 100};
    printf("%d\n", nums[0]);        // 90，下标从 0 开始
    printf("%zu\n", sizeof(nums) / sizeof(nums[0]));  // 5，元素个数

    char name[20] = "阿猫";          // 字符串就是 char 数组
    printf("%s\n", name);
    printf("%zu\n", strlen(name));   // 字节数，不是字数！
    return 0;
}
长度数组不知道自己有多长——C 不给你 length。要自己算或另存一个变量
越界nums[5] 不会报错，会写到别人的内存里。最容易埋雷的地方
字符串结尾C 用 '\0'（数字 0）标记字符串结束。"阿猫" 实际占 7 个字节
中文UTF-8 下一个汉字占 3 个字节，strlen 算的是字节
必背：字符串数组一定留够空间。char name[3] = "阿猫"; 会越界——要 [7] 以上。C 不会帮你检查。

09类型转换

int a = 10;
double b = a;              // 自动转：小 → 大，安全
int c = (int) 3.99;        // 强制转：砍掉小数，得 3
char ch = 'A';
int code = ch;             // 65，字符本质是数字

int x = 7, y = 2;
double r = x / y;          // 3.000000 ← 先整数除，再转 double，晚了！
double r2 = (double) x / y; // 3.500000 ← 先转再除
自动转换char → int → float → double，往大走自动
强制转换(类型) 值，可能丢数据，自己负责
字符与数字'A' 就是 65。所以 'a' - 'A' 得 32，大小写转换靠它
第 09 节最值钱的一句：先转换，再运算。写 x / y 再赋给 double，小数已经丢了，转不回来。

10if 与 switch

int score = 85;

if (score >= 90) {
    printf("优秀\n");
} else if (score >= 60) {
    printf("及格\n");
} else {
    printf("不及格\n");
}

// switch 只能判断整数或字符
int day = 3;
switch (day) {
    case 1:
    case 2:
    case 3:
        printf("工作日\n");
        break;          // 忘了 break 会「穿透」到下一个 case
    default:
        printf("休息日\n");
}
条件C 里「非 0 即真」，if (1) 合法，和 Java 不同
==比较要用两个等号。if (a = 5) 是赋值，永远为真——经典 bug
switch只能配整数/字符，不能配字符串，也不能判断范围
break每个 case 结束都要 break，否则会一直往下执行
写反了怎么查：把常量写在左边——if (5 == a)。这样漏写一个等号会编译报错，而不是悄悄变成赋值。

11循环

// for
for (int i = 0; i < 5; i++) {
    printf("%d ", i);
}

// while
int n = 1;
while (n <= 3) {
    printf("第 %d 次\n", n);
    n++;
}

// do-while：至少执行一次
int k = 10;
do {
    printf("一定执行一次\n");
} while (k < 5);

// break / continue
for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) continue;   // 偶数跳过
    if (i > 7) break;           // 超过 7 停
    printf("%d ", i);
}
for三段式。C99 之后才能在 for 里声明 int i，老编译器要写在外面
死循环忘了 i++，或者条件是赋值。while (1) 是合法的无限循环
break / continue跳出整个循环 / 跳过本次，只影响最内层
小练习：打印九九乘法表。外层 i 1~9，内层 j 1~i，格式 printf("%d*%d=%d ", j, i, i*j);

12函数

#include <stdio.h>

// 先声明（告诉编译器有这么个函数）
int add(int a, int b);
void sayHello(char *name);

int main(void) {
    printf("%d\n", add(1, 2));
    sayHello("阿猫");
    return 0;
}

// 再定义
int add(int a, int b) {
    return a + b;
}

void sayHello(char *name) {
    printf("你好，%s\n", name);
}
声明 vs 定义声明只写「长什么样」，定义写「怎么做」。先声明后使用，否则编译器不认识
void没有返回值
参数C 是值传递：传进去的是副本，函数里改了，外面不变（想改外面要传指针，第 15 节）
数组参数void f(int arr[]) 实际收到的是指针，长度要另外传
好习惯：一个函数不超过 40 行，只做一件事。C 没有类，函数就是唯一的组织单位，写乱了没人救你。

13作用域与 static

#include <stdio.h>

int counter = 0;          // 全局变量：整个文件都能用

void ping(void) {
    static int calls = 0; // 只在第一次初始化为 0
    calls++;
    printf("第 %d 次调用\n", calls);
}

int main(void) {
    ping();   // 1
    ping();   // 2
    ping();   // 3
    return 0;
}
局部变量在函数里的 { } 中，出了大括号就没了（栈上）
全局变量文件顶部，所有函数都能改。尽量少用，谁改的都不知道
static 局部只初始化一次，函数返回后值还在，下次调用接着用
static 全局限定只在本文件可见，别的文件看不到
为什么少用全局变量：它像公共黑板，谁都能写。项目一大，出问题时你根本不知道是哪个函数改的。

14指针入门 · C 的灵魂

#include <stdio.h>

int main(void) {
    int a = 10;
    int *p = &a;          // p 指向 a 的地址

    printf("%d\n", a);    // 10  值
    printf("%p\n", p);    // 0x7ffd... 地址
    printf("%d\n", *p);   // 10  解引用：跟着地址去取值

    *p = 99;              // 通过指针改值
    printf("%d\n", a);    // 99  ← a 也变了
    return 0;
}
&取地址。&a 是「a 住在哪」
*两种含义：声明时表示「这是指针」；使用时表示「取这个地址里的值」
int *p「指向 int 的指针」。指针也有类型，因为要知道读几个字节
NULL空指针。没指向任何东西，解引用它必崩
一句话理解：变量是「房间」，指针是「写着房间号的纸条」。& 是查房间号，* 是按号码去开门。
int *q = NULL;
// printf("%d", *q);   // 千万别这么干：段错误

15指针与函数 · 让函数改外面的变量

#include <stdio.h>

// 值传递：改不了外面
void badAdd(int x) { x = x + 1; }

// 传地址：能改外面
void goodAdd(int *x) { (*x)++; }

int main(void) {
    int a = 10;
    badAdd(a);
    printf("%d\n", a);   // 10，没变

    goodAdd(&a);
    printf("%d\n", a);   // 11，变了
    return 0;
}
(*x)++先解引用再加一。括号不能省，*x++ 是另一回事
数组传参void f(int arr[], int len)，数组会退化成指针，长度必须另传
scanf它要的就是地址，所以写 &age。第 05 节那个坑，现在你懂为什么了
规律：想让函数改外面的东西，就传地址；只读，就传值。scanf、strcpy 这些标准函数，参数里全带指针。

16结构体 struct

#include <stdio.h>
#include <string.h>

typedef struct {
    char name[20];
    int age;
    double score;
} Student;

int main(void) {
    Student s1;
    strcpy(s1.name, "阿猫");
    s1.age = 18;
    s1.score = 92.5;

    printf("%s %d %.1f\n", s1.name, s1.age, s1.score);

    Student list[3];          // 结构体数组
    list[0] = s1;

    Student *p = &s1;
    printf("%s\n", p->name);   // 指针用 ->，等价于 (*p).name
    return 0;
}
struct把几个不同类型的字段打包成一个新类型
typedef给类型起个短名字，之后不用写 struct Student
. / ->结构体变量用点，指针用箭头
字符串字段不能直接 s1.name = "阿猫"，要用 strcpy
为什么用它：没有结构体，一个学生要开三个数组（名字、年龄、分数），删一个要动三处。结构体让「一条数据」变成一个整体。

17动态内存 · malloc 与 free

#include <stdio.h>
#include <stdlib.h>

int main(void) {
    int n = 5;
    int *arr = malloc(n * sizeof(int));   // 申请堆内存
    if (arr == NULL) {
        printf("内存不够\n");
        return 1;
    }

    for (int i = 0; i < n; i++) arr[i] = i * 10;
    for (int i = 0; i < n; i++) printf("%d ", arr[i]);

    free(arr);      // 用完还回去
    arr = NULL;     // 防止野指针
    return 0;
}
栈 vs 堆函数里的数组在栈上，函数结束就没了；malloc 在堆上，你不 free 它就一直占着
sizeofmalloc(n * sizeof(int))，别写死 4
检查 NULL内存可能申请失败，必须判断
free不 free = 内存泄漏；free 两次 = 崩溃
最贵的三个 bug：① 忘了 free（程序越跑越占内存）；② free 之后又用（野指针）；③ 数组越界写坏别人的内存。这三个，编译器都不会提醒你。

18字符串函数 · string.h

#include <stdio.h>
#include <string.h>

int main(void) {
    char a[20] = "hello";
    char b[20] = "world";
    char c[40];

    printf("%zu\n", strlen(a));        // 5
    strcpy(c, a);                      // 复制
    strcat(c, " ");                    // 拼接
    strcat(c, b);
    printf("%s\n", c);                 // hello world
    printf("%d\n", strcmp(a, b));     // 负数：a 在 b 前面

    if (strcmp(a, "hello") == 0) printf("相等\n");   // 比较字符串用 strcmp
    return 0;
}
strlen到 '\0' 为止的长度（字节）
strcpy复制。不检查目标够不够大，这是历史上最多漏洞的来源
strcat拼接，同样不检查空间
strcmp比较，返回 0 表示相等。不能用 == 比较字符串
更安全的写法：snprintf(buf, sizeof(buf), "%s %s", a, b);——它知道缓冲区多大，不会溢出。新代码优先用它。

19文件读写

#include <stdio.h>

int main(void) {
    FILE *fp = fopen("notes.txt", "w");   // w 写，a 追加，r 读
    if (fp == NULL) {
        printf("打不开文件\n");
        return 1;
    }
    fprintf(fp, "第一行\n");
    fprintf(fp, "第二行\n");
    fclose(fp);                            // 一定要关

    fp = fopen("notes.txt", "r");
    char line[100];
    while (fgets(line, sizeof(line), fp) != NULL) {
        printf("[%s]", line);
    }
    fclose(fp);
    return 0;
}
fopen打开文件，返回指针。失败返回 NULL，必须判断
模式"r" 读（不存在就失败）、"w" 写（清空原内容）、"a" 追加
fgets读一行，读到换行或 n-1 个字符为止，自动补 '\0'
fclose不关文件，数据可能还在缓冲区里没写进去
坑："w" 会先清空文件。想保留旧内容用 "a"。用 "w" 打开一个已有文件，等于把它的内容删了。

20预处理 · #include 和 #define

#include <stdio.h>
#define MAX 100
#define SQUARE(x) ((x) * (x))

int main(void) {
    int nums[MAX];
    printf("%d\n", SQUARE(3));    // 9
    printf("%d\n", MAX);
    return 0;
}
#include把另一个文件的内容「粘贴」进来。标准库用 < >，自己的头文件用 " "
#define宏替换，在编译前完成，不是变量
宏的坑#define SQUARE(x) x*x 里 SQUARE(1+2) 会变成 1+2*1+2——参数和整体都要加括号
#ifdef条件编译，调试代码可以这样临时开关
现代做法：常量优先用 const int MAX = 100;——它有类型，调试器看得见；宏不会。

21多文件与头文件

// student.h   ← 声明
#ifndef STUDENT_H
#define STUDENT_H
typedef struct { char name[20]; int age; } Student;
void printStudent(Student s);
#endif

// student.c   ← 实现
#include <stdio.h>
#include "student.h"
void printStudent(Student s) {
    printf("%s %d\n", s.name, s.age);
}

// main.c      ← 使用
#include "student.h"
int main(void) {
    Student s = {"阿猫", 18};
    printStudent(s);
    return 0;
}
gcc main.c student.c -o app.exe
为什么拆文件一大，一个 .c 几千行没法维护。按功能拆开
头文件保护#ifndef / #define / #endif，防止同一份头文件被包含两次
编译把所有 .c 一起交给 gcc，它会分别编译再链接
一句话：头文件写「有什么」，.c 写「怎么做」。这是 C 项目的标准结构，你以后看任何开源项目都是这个样子。

22最常见的十个错误

1scanf 忘了 & → 运行时直接崩
2数组越界 → 有时没事，有时数据被莫名改掉，最难查
3字符串比较用 == → 永远不相等，要用 strcmp
4字符串数组没留 '\0' 的位置
5忘了 free → 内存泄漏
6free 之后继续用 → 野指针
7if (a = 5) 写成赋值 → 条件永远为真
8switch 忘了 break → 全部穿透
9printf 的格式符和参数对不上（用 %d 打印 double）
10指针没初始化就用 → 段错误
段错误（Segmentation fault）几乎只有一个原因：你访问了不该访问的内存——空指针、野指针、越界、free 过的内存。看到它，先查这四个。

23调试 · 让程序自己说话

gcc -Wall -Wextra hello.c -o hello.exe

-Wall 打开所有警告。警告不是噪音，是提前告诉你的 bug。新代码建议永远带上。

printf 大法在可疑的地方打印变量值。土，但有效
分段排查注释掉一半代码，看还崩不崩，二分定位
gdb命令行调试器：gcc -g 编译，gdb app.exe，然后 run、bt 看调用栈
IDEVS Code + C/C++ 插件可以打断点，比 gdb 好上手
顺序：先看编译器警告 → 再看第一行报错 → 再 printf → 最后上调试器。很多人第一条就没做。

25动手：学生成绩管理

目标：录入几个学生、算平均分、找最高分。用到结构体、数组、函数、循环——正好把前面串起来。

#include <stdio.h>

#define N 3

typedef struct {
    char name[20];
    int score;
} Student;

void printAll(Student list[], int n) {
    for (int i = 0; i < n; i++) {
        printf("%d. %s\t%d\n", i + 1, list[i].name, list[i].score);
    }
}

double average(Student list[], int n) {
    int sum = 0;
    for (int i = 0; i < n; i++) sum += list[i].score;
    return n == 0 ? 0 : (double) sum / n;
}

int best(Student list[], int n) {
    int idx = 0;
    for (int i = 1; i < n; i++) {
        if (list[i].score > list[idx].score) idx = i;
    }
    return idx;
}

int main(void) {
    Student list[N];

    for (int i = 0; i < N; i++) {
        printf("第 %d 个学生，姓名 分数：", i + 1);
        scanf("%19s %d", list[i].name, &list[i].score);
    }

    printAll(list, N);
    printf("平均分：%.1f\n", average(list, N));
    int b = best(list, N);
    printf("最高分：%s %d\n", list[b].name, list[b].score);
    return 0;
}

这段代码在讲什么

第 1 步用 typedef struct 定义「一个学生长什么样」
第 2 步三个函数各做一件事：打印、算平均、找最高
第 3 步数组和长度一起传——C 的数组不知道自己多长
第 4 步scanf("%19s") 限长度，防止名字太长撑爆数组
练手方向（自己动手改）：加「按分数排序」；加「低于 60 分标记不及格」；把结果写进文件「成绩.txt」。

26独立项目：写一个通讯录

这一节没有完整代码。给你需求、验收标准、和卡住时的提示。

要做什么

1添加：姓名、电话，存进数组
2显示：列出全部联系人
3查找：按姓名查电话
4保存：退出时写进文件，下次启动自动读回来

验收标准

1最多存 20 个，满了要提示「通讯录已满」
2查找不存在的名字，要有提示，不能崩
3退出再进，数据还在
4输入选项乱输，程序能回到菜单
5至少有 3 个函数，每个不超过 30 行

卡住时的提示

提示 1联系人用 typedef struct { char name[20]; char phone[20]; } Contact;
提示 2数组加一个计数变量 int count，比用 sizeof 猜长度靠谱
提示 3存文件：fprintf(fp, "%s %s\n", list[i].name, list[i].phone);
提示 4读文件：while (fscanf(fp, "%19s %19s", name, phone) == 2)，返回 2 表示两个字段都读到了
做完之后：加一个「删除联系人」——删除时要把后面的元素往前挪一格。这一步是数组操作的经典练习。

28结语

C 是最诚实的语言。

你写错一个下标，它就真的把别人的数据盖掉；你忘了 free，它就真的占着内存不放。没有垃圾回收替你兜底，也没有异常机制帮你兜住——出问题，就是你在某个地方想错了。

这种诚实很烦，但也很值钱：学完 C 再看 Python 的列表、Java 的数组，你会知道它们底下是什么。

三个忠告：
① 编译带上 -Wall。警告是你唯一免费的助手。
② 指针看不懂就画图。谁指向谁，画一遍就通了。
③ 能跑 ≠ 没错。C 的 bug 常常安静地待着，等你演示那天才炸。
