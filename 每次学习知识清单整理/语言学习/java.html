01它是什么

Java 是 1995 年由 Sun 公司（后来被 Oracle 收购）发布的一门语言。它的口号是「Write Once, Run Anywhere」——写一次，到处运行。

这句话不是广告，它有物理实现：JVM（Java 虚拟机）。你写的 .java 文件先被编译成 .class 字节码，再由 JVM 翻译成那台电脑能懂的机器指令。所以同一份 .class，在 Windows、Mac、Linux 上都能跑——只要那台机器装了 JVM。

Hello.java  --javac-->  Hello.class  --java-->  在 JVM 上跑
（你写的）              （编译产物）              （运行时）
和 Python 最大的不同Python 是「解释执行」，写一行跑一行；Java 要先编译，能跑起来说明类型都对上了
类型强类型 + 静态类型：变量一旦声明成 int，就只能装整数，写错编译期就报错
面向对象几乎所有代码都写在类里面，连 main 方法也不例外
啰嗦比 Python 长很多。一个 Hello World 要写五行——但这五行每一行都有原因，后面会讲
一句话：Python 让你写得快，Java 让你改得动。项目一大、人一多，编译器帮你挡掉的那批错误，就是 Java 值钱的地方。

04装好，让它跑起来

Java 要装的是 JDK（Java Development Kit），不是 JRE。JDK 里带编译器 javac，JRE 只带运行环境。

第 1 步去 adoptium.net 下载 Temurin 17 (LTS)，选 Windows x64 的 .msi
第 2 步安装时勾上 Set JAVA_HOME 和 Add to PATH（默认是勾的）
第 3 步按 Win + R 输入 cmd，敲 java -version 和 javac -version，两个都出版本号才算成
第 4 步新建 Hello.java，写下面五行，保存
public class Hello {
    public static void main(String[] args) {
        System.out.println("你好，世界");
    }
}
javac Hello.java     ← 编译，生成 Hello.class
java Hello           ← 运行（注意：不加 .class）
public class Hello类名必须和文件名一模一样，且大小写敏感：Hello.java 里只能写 class Hello
public static void main(String[] args)程序入口，一个字母都不能错。改了它，程序就「找不到主类」
System.out.println打印一行并换行。print 不换行
三个新手必踩的坑：① 文件名和类名对不上（hello.java 里写 class Hello）；② 运行的时候加了后缀 java Hello.class；③ 装了 JDK 但 PATH 没生效——重开一个 cmd 窗口再试。
工具：记事本也能写，但推荐 IntelliJ IDEA 社区版（免费）或 VS Code + Java 插件。IDE 会实时标红，省一半时间。

05第一行代码：输出和输入

程序的两条腿：往外说（println）、往里收（Scanner）。

import java.util.Scanner;

public class Demo {
    public static void main(String[] args) {
        System.out.println("你好，世界");
        System.out.print("这一行不换行");
        System.out.println("，接在后面");
        System.out.println("1 + 1 = " + (1 + 1));

        Scanner sc = new Scanner(System.in);
        System.out.print("你叫什么名字？");
        String name = sc.nextLine();
        System.out.println("你好，" + name);
        sc.close();
    }
}
System.out.println打印并换行。括号里可以是字符串、数字、变量，用 + 拼起来
Scanner读键盘输入。要先 import，再 new 一个
nextLine()读一整行，结果是 String
nextInt()读一个整数。它是全 Java 最坑的输入方法，下一节细讲
第一个大坑：sc.nextInt() 只吃掉数字，把回车留在了缓冲区。紧接着调 sc.nextLine()，它会读到那个空回车，返回空字符串。解法：nextInt() 之后再补一句 sc.nextLine(); 把回车吃掉。

06变量 · 八种基本类型

是什么一个盒子，装着某种类型的数据。Java 的盒子必须先声明类型，而且只能装这种类型
怎么写类型 名字 = 值;，比如 int age = 18;
和谁搭任何计算都要靠它。名字起得好，代码就有一半可读性
int age = 18;              // 整数
long money = 10000000000L; // 长整数，数字后面加 L
double price = 19.9;       // 小数
boolean ok = true;         // 真假
char level = 'A';          // 单个字符，用单引号
String name = "阿猫";       // 字符串，用双引号（它不是基本类型）

var city = "株洲";          // Java 10+：让编译器自己推断类型
final int MAX = 100;       // 常量，赋值后不能改
byte / short小整数（-128~127 / -3 万~3 万），用得少
int最常用，约 ±21 亿
long更大的整数，字面量要加 L
float / double小数。float 要加 f，日常用 double
char单个字符，单引号 'A'
booleantrue / false，不能写 0/1
String不是基本类型，是类。但它用起来像基本类型
命名：小驼峰——totalPrice、userName；类名大驼峰——Hello、BankAccount；常量全大写——MAX_SIZE。别用拼音，更别用 a1、a2。

07数字与运算 · 让计算机算账

int a = 7, b = 2;
System.out.println(a + b);   // 9
System.out.println(a - b);   // 5
System.out.println(a * b);   // 14
System.out.println(a / b);   // 3  ← 整数相除，小数被丢掉
System.out.println(a % b);   // 1  ← 余数
System.out.println(a / 2.0); // 3.5 ← 有一个是小数，结果才是小数

System.out.println(10 > 3);  // true
System.out.println(10 == 3); // false
System.out.println(true && false); // false
System.out.println(!true);         // false

int max = a > b ? a : b;     // 三元：条件 ? 真 : 假
System.out.println(max);     // 7
/两个整数相除，结果还是整数，直接截断（不是四舍五入）。算钱之前一定要想清楚
%取余。判奇偶 n % 2 == 0、判断整除，都靠它
==比较。注意：比较字符串不能用 ==，第 08 节讲
&& || !与、或、非。而且它们短路：a && b 里 a 已经 false，b 就不算了
两个坑：① int 最大约 21 亿，超过会溢出成负数，几亿以上的钱用 long；② 0.1 + 0.2 != 0.3——小数在计算机里存不准，涉及金额一律用整数「分」来算。

08字符串 String

String name = "阿猫";
System.out.println(name.length());        // 2
System.out.println(name.substring(0, 1)); // 阿
System.out.println(name.toUpperCase());   // 阿猫（中文没变化，字母才变大写）
System.out.println("a,b,c".split(","));   // 得到数组 [a, b, c]
System.out.println(String.join("-", "a", "b")); // a-b
System.out.println(String.format("你好，%s，今年 %d 岁", name, 18));

String s = "咖啡";
s = s + "拿铁";        // 拼接会产生新对象
System.out.println(s);  // 咖啡拿铁
不可变String 一旦创建就改不了。s + "x" 是造了一个新的，不是改原来那个
长度length() 是方法，要带括号；数组的 length 不带括号——这是两个东西
拼接少量用 +；循环里拼几百次用 StringBuilder，不然会创建一堆垃圾对象
必考必踩：== 和 equals 的区别。
== 比的是「是不是同一个对象」（内存地址）；equals 比的是「内容是否相同」。
String a = "hi"; String b = "hi"; a == b 可能是 true（字符串常量池碰巧同一个）；
new String("hi") == new String("hi") 一定是 false。
结论：比较字符串内容，永远用 a.equals(b)。
// 循环里拼字符串的正确写法
StringBuilder sb = new StringBuilder();
for (int i = 0; i < 1000; i++) sb.append(i).append(",");
String result = sb.toString();

09类型转换 · 把「3」变成 3

int a = 10;
double b = a;              // 自动转：小范围 → 大范围，安全
int c = (int) 3.99;        // 强制转：小数 → 整数，直接砍掉小数，得 3

String s1 = "123";
int n = Integer.parseInt(s1);      // 字符串 → 整数
double d = Double.parseDouble("3.14");
String s2 = String.valueOf(456);   // 任意类型 → 字符串
String s3 = 456 + "";              // 也一样，但不推荐
自动转换byte → short → int → long → float → double，往大走不用写转换
强制转换(int) 这种写法，可能丢精度，自己负责
字符串转数字Integer.parseInt；如果字符串不是数字，会抛 NumberFormatException
包装类int 的类版本是 Integer，集合里只能装包装类
坑：Integer.parseInt("12.5") 会炸，因为它是小数。Integer 和 int 比较时，== 比的是引用——又回到第 08 节那个坑，用 equals 或先转成 int。

10if 与 switch · 让程序做选择

int score = 85;

if (score >= 90) {
    System.out.println("优秀");
} else if (score >= 60) {
    System.out.println("及格");
} else {
    System.out.println("不及格");
}

// switch 老写法（要记得 break，不然会「穿透」往下执行）
int day = 3;
switch (day) {
    case 1:
    case 2:
    case 3:
        System.out.println("工作日");
        break;
    default:
        System.out.println("休息日");
}

// switch 新写法（Java 14+，不会穿透）
String type = switch (day) {
    case 1, 2, 3, 4, 5 -> "工作日";
    case 6, 7 -> "休息日";
    default -> "不存在的日子";
};
if条件必须是 boolean，不能写 if (1)——Java 不像 C，整数不能当条件
>=大于等于。别写成 =>
switch只能判断「等于某个值」，不能判断范围；新写法用 -> 更安全
大括号哪怕只有一行也建议写，出问题时好改
最常见的逻辑错：把 else if 写成两个独立的 if——那样两个条件都会被判断，可能同时执行。

11循环 · 重复做同一件事

// for：知道要做几次
for (int i = 0; i < 5; i++) {
    System.out.print(i + " ");
}

// while：不知道几次，看条件
int n = 1;
while (n <= 3) {
    System.out.println("第 " + n + " 次");
    n++;
}

// do-while：至少执行一次
int k = 10;
do {
    System.out.println("一定执行一次");
} while (k < 5);

// 增强 for：遍历数组或集合，只读最方便
String[] names = {"阿猫", "小鱼"};
for (String name : names) {
    System.out.println(name);
}

// break 跳出整个循环，continue 跳过这一次
for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) continue;   // 偶数跳过
    if (i > 7) break;           // 超过 7 就停
    System.out.print(i + " ");
}
for (初始化; 条件; 更新)三段用分号隔开。写错顺序最容易变成死循环
i++先取值再加 1；++i 是先加再取值。单独一行时没区别
死循环忘了 i++，或者条件永远为真。程序卡住不动，多半是它
小练习：用双层 for 打印九九乘法表。提示：外层 i 从 1 到 9，内层 j 从 1 到 i。

12数组 · 一排固定长度的格子

import java.util.Arrays;

int[] scores = new int[5];          // 5 个格子，默认全是 0
int[] nums = {90, 85, 77};          // 声明时直接给值

System.out.println(nums.length);    // 3，注意没有括号
System.out.println(nums[0]);        // 90，下标从 0 开始
nums[0] = 95;                       // 改第一个

for (int x : nums) System.out.println(x);

Arrays.sort(nums);                  // 排序
System.out.println(Arrays.toString(nums));  // 打印成 [77, 85, 95]
长度固定建的时候多长，就永远多长。要加东西，得换 ArrayList
下标从 0 到 length - 1。写 nums[3] 就抛 ArrayIndexOutOfBoundsException
默认值int 是 0，boolean 是 false，String 是 null
二维int[][] grid = new int[3][4];，grid[1][2] 取第 2 行第 3 列
坑：直接 System.out.println(nums) 打印出来是 [I@1b6d3586 这种乱码——那是内存地址。要看得懂，用 Arrays.toString(nums)。

13ArrayList · 会变长的列表

import java.util.ArrayList;

ArrayList<String> list = new ArrayList<>();
list.add("拿铁");
list.add("美式");
System.out.println(list.size());      // 2
System.out.println(list.get(0));      // 拿铁
list.set(1, "馥芮白");                 // 改第 2 个
list.remove("拿铁");                   // 按内容删
list.remove(0);                       // 按下标删

for (String s : list) System.out.println(s);
System.out.println(list.contains("美式"));  // false
ArrayList<类型>尖括号里写它装什么。只能装类，不能装 int——要装 Integer
size()元素个数，是方法，要括号
get(下标)取元素。数组用 []，列表用 get
自动扩容不用管长度，加满了它自己变长
坑：list.remove(1) 是删下标 1 的元素；list.remove("1") 是删内容为 "1" 的元素。传数字删下标，传对象删内容——别再搞混。

14HashMap · 按名字找东西

import java.util.HashMap;

HashMap<String, Integer> stock = new HashMap<>();
stock.put("拿铁", 12);
stock.put("美式", 9);

System.out.println(stock.get("拿铁"));        // 12
System.out.println(stock.get("摩卡"));        // null（没有就是 null）
System.out.println(stock.getOrDefault("摩卡", 0)); // 0，安全写法
System.out.println(stock.containsKey("美式")); // true

stock.put("拿铁", stock.get("拿铁") - 1);      // 减库存

for (String key : stock.keySet()) {
    System.out.println(key + " 剩 " + stock.get(key));
}
是什么键值对。「键」唯一，用它查「值」。做计数、做缓存、做映射都用它
get键不存在返回 null，直接拿去运算会 NullPointerException，用 getOrDefault
keySet()拿到所有键，再遍历
无序HashMap 不保证顺序。要按顺序用 TreeMap 或 LinkedHashMap
计数套路（几乎每本教材都有）：
map.put(word, map.getOrDefault(word, 0) + 1);
一句话：有就加一，没有就从 0 开始加一。

15方法 · 把一段逻辑打包

public class Demo {
    // 有参数、有返回值
    static int add(int a, int b) {
        return a + b;
    }

    // 没有返回值
    static void sayHello(String name) {
        System.out.println("你好，" + name);
    }

    // 重载：同名不同参数
    static int add(int a, int b, int c) {
        return a + b + c;
    }

    public static void main(String[] args) {
        System.out.println(add(1, 2));      // 3
        sayHello("阿猫");
        System.out.println(add(1, 2, 3));   // 6
    }
}
结构修饰符 返回类型 方法名(参数) { 方法体 }
void没有返回值，return; 可以提前结束
static属于类本身，不用 new 对象就能调。main 就是 static，所以它直接调的方法也得是 static
重载方法名相同、参数不同。编译器按参数个数和类型挑
Java 只有值传递：传基本类型，传的是副本；传对象，传的是「引用的副本」——所以你在方法里改对象的字段，外面看得见；但把参数重新赋值成新对象，外面看不见。

16类与对象 · 把数据和操作打包

public class Coffee {
    private String name;     // 字段（属性）
    private int price;

    public Coffee(String name, int price) {   // 构造器
        this.name = name;     // this 指自己，用来区分同名参数
        this.price = price;
    }

    public String getName() { return name; }               // getter
    public void setName(String name) { this.name = name; }  // setter

    public int getPrice() { return price; }

    @Override
    public String toString() {
        return name + "（¥" + price + "）";
    }
}

// 用
Coffee c = new Coffee("拿铁", 32);
System.out.println(c);            // 拿铁（¥32）——自动调 toString
System.out.println(c.getPrice()); // 32
class模板；new 出来的才叫对象
构造器名字和类名一样、没有返回类型。不写的话编译器送一个无参的
private只有本类能改。外面想改必须走 setter——这就是封装
this指当前对象。参数和字段同名时，必须写 this.name = name
为什么要 private + getter：以后想加规则（比如价格不能为负），只改 setter 一处，所有调用者自动生效。字段全公开的话，你得满世界找赋值的地方。

17继承与接口 · 复用和多态

// 父类
class Animal {
    String name;
    Animal(String name) { this.name = name; }
    void speak() { System.out.println(name + " 叫了一声"); }
}

// 子类：extends
class Cat extends Animal {
    Cat(String name) { super(name); }   // 调父类构造器

    @Override
    void speak() { System.out.println(name + " 喵"); }
}

// 接口：只规定「必须有什么方法」
interface Playable {
    void play();
}

class Game implements Playable {
    public void play() { System.out.println("开始游戏"); }
}

// 多态：父类引用指向子类对象
Animal a = new Cat("咪咪");
a.speak();          // 咪咪 喵 —— 运行时才决定调谁
extends继承。Java 只能单继承，一个类只能有一个父类
super调用父类的构造器或方法
@Override告诉编译器「我在重写父类方法」，写错名字会报错
implements实现接口。可以同时实现多个接口
多态「父类引用调方法，实际执行子类的版本」——这是 Java 面向对象的核心
一句话记：extends 是「是什么」（猫是动物），implements 是「能干什么」（游戏能玩）。拿不准的时候，用接口。

18包与 import · 代码怎么分文件夹

// 文件：src/com/demo/Coffee.java
package com.demo;

public class Coffee { }

// 别的文件里用
import com.demo.Coffee;

public class Main {
    public static void main(String[] args) {
        Coffee c = new Coffee();
    }
}
package声明这个类属于哪个包。一行，必须在文件最上面
目录包名要跟文件夹对应：package com.demo; 的文件放在 com/demo/ 里
import用别的包里的类要先导入，比如 java.util.ArrayList
java.lang自动导入，所以 String、System、Math 不用 import
编译要带 -d：javac -d out src/com/demo/Coffee.java，它会把 .class 按包结构放进 out。用 IDE 的话这些都不用管。

19异常 · 出错但不崩

try {
    int n = Integer.parseInt("abc");   // 这里会抛异常
    System.out.println(n);
} catch (NumberFormatException e) {
    System.out.println("这不是数字：" + e.getMessage());
} finally {
    System.out.println("不管成不成功，这里都会执行");
}

// 抛出异常（告诉调用者：这事我处理不了）
static int divide(int a, int b) {
    if (b == 0) throw new IllegalArgumentException("除数不能是 0");
    return a / b;
}
NullPointerException拿 null 去调方法或取字段。Java 报错第一名
ArrayIndexOutOfBoundsException数组下标越界
NumberFormatExceptionparseInt 的字符串不是数字
ArithmeticException整数除以 0
ClassNotFoundException找不到类，多半是包名或 classpath 不对
受检异常编译器强制你 try 或 throws，比如 IOException
非受检RuntimeException 家族，编译器不管，运行时才炸
finally有没有异常都会执行，用来关资源
别这么写：catch (Exception e) { }——吞掉异常，出问题你永远不知道。哪怕只打一行 e.printStackTrace();。

20文件读写 · 让数据活过这一次运行

import java.nio.file.*;
import java.io.IOException;
import java.util.List;

public class Save {
    public static void main(String[] args) throws IOException {
        Path file = Paths.get("notes.txt");

        Files.writeString(file, "第一行\n第二行\n");   // 覆盖写

        String all = Files.readString(file);          // 一次读全部
        System.out.println(all);

        List<String> lines = Files.readAllLines(file); // 按行读
        for (String line : lines) System.out.println("[" + line + "]");

        Files.writeString(file, "追加一行\n", StandardOpenOption.APPEND);
    }
}
Path文件路径。用 Paths.get("a/b.txt") 造
Files.writeString写文件。默认覆盖，要追加加 StandardOpenOption.APPEND
Files.readString整个文件读成一个字符串
IOException受检异常，必须 throws 或 try/catch
乱码怎么办：Windows 记事本默认不是 UTF-8，读出来会乱。写的时候显式指定：Files.writeString(file, text, StandardCharsets.UTF_8)。

23读懂报错 · 这是最重要的技能

Exception in thread "main" java.lang.NullPointerException: Cannot invoke "String.length()" because "s" is null
    at Demo.main(Demo.java:5)
第一行异常类型 + 原因。NullPointerException 就是「你拿 null 用了」
at Demo.main(Demo.java:5)出错位置：Demo.java 第 5 行。直接跳过去看
一堆 at调用栈，从下往上看：别人调了你的方法，你的方法炸了
Caused by:真正的原因往往在这一段
编译错误还没跑就红：拼错、少分号、类型对不上。下面会告诉你第几行
运行错误跑起来才炸：空指针、越界、除零
找不到主类java Hello 的类名或路径不对，或者 .class 没生成
三句话：① 从第一行看类型，从 at 行看位置；② 空指针八成是「忘了赋值」或「查不到返回 null」；③ 看不懂就把报错原文粘给搜索引擎——英文原样搜，比中文翻译准。

25动手：写一个命令行记账本

目标：能记一笔、看列表、看总额、退出。用到的全是前面学过的：类、ArrayList、Scanner、循环、方法。

import java.util.ArrayList;
import java.util.Scanner;

public class Ledger {

    static class Item {
        String name;
        int amount;                 // 正数收入，负数支出
        Item(String name, int amount) {
            this.name = name;
            this.amount = amount;
        }
        @Override
        public String toString() {
            return name + "\t" + amount;
        }
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        ArrayList<Item> list = new ArrayList<>();

        while (true) {
            System.out.println();
            System.out.println("1 记一笔   2 看列表   3 看总额   0 退出");
            System.out.print("选：");
            String choice = sc.nextLine().trim();

            if (choice.equals("0")) {
                System.out.println("再见");
                break;
            } else if (choice.equals("1")) {
                System.out.print("项目：");
                String name = sc.nextLine().trim();
                System.out.print("金额（支出写负数）：");
                int amount = Integer.parseInt(sc.nextLine().trim());
                list.add(new Item(name, amount));
                System.out.println("已记录");
            } else if (choice.equals("2")) {
                if (list.isEmpty()) {
                    System.out.println("还没有记录");
                } else {
                    for (int i = 0; i < list.size(); i++) {
                        System.out.println((i + 1) + ". " + list.get(i));
                    }
                }
            } else if (choice.equals("3")) {
                int total = 0;
                for (Item it : list) total += it.amount;
                System.out.println("总额：" + total + " 元");
            } else {
                System.out.println("没有这个选项");
            }
        }
        sc.close();
    }
}

这段代码在讲什么

第 1 步先定「一条记录长什么样」——Item 类，两个字段
第 2 步用一个 ArrayList 装所有记录
第 3 步while (true) 循环菜单，break 退出
第 4 步全部用 nextLine() 读，避开 nextInt 的回车坑
练手方向（自己动手改）：加一个「删除第 n 笔」；加「按收入/支出分类统计」；把金额限制成必须大于 0，输了就重来；把数据存进文件，下次打开还在。你改得动，才算真的看懂了。

26独立项目：写一个「单词本」

这一节没有完整代码。给你需求、验收标准、和卡住时的提示。自己写出来，比抄十遍有用。

要做什么

一个命令行程序，能背单词：

1录入：输入英文和中文，存进列表
2测试：随机抽一个英文，让你输入中文，判对错
3统计：显示一共背了几个、错了几个
4保存：退出后重新打开，单词还在

验收标准（做到了才算完成）

1能录入至少 5 个单词，重复的单词不会重复加
2测试时随机出题，答对答错都有反馈
3退出再进，数据还在（文件读写）
4乱输菜单数字，程序不崩，能回到菜单
5至少有 3 个方法，每个不超过 25 行

卡住时的提示（按顺序看，别一次看完）

提示 1一条单词用类还是用两个列表？用类更清楚：Word(en, cn)
提示 2随机抽取：new Random().nextInt(list.size())
提示 3存文件时，用 list.size() 循环，一行写一个 en,cn；读的时候 split(",")
提示 4读文件用 Files.readAllLines，记得 throws IOException
做完之后：加一个「错题本」，答错的单词单独存一份，下次优先复习。这一小步，就是所有背单词软件的雏形。

28结语

Java 不讨喜。它啰嗦、它老派、它让你写五遍 public。

但它是那种越用越顺的语言：编译器帮你挡住一半错误，IDE 帮你补完另一半，写久了你会发现自己不再犯「把字符串当数字」这种错。

而且它实在——你写的每一个类，都能变成简历上的一行。

三个忠告：
① 先跑通，再理解。抄一遍能跑，比看懂一半强。
② 报错先读第一行。90% 的人败在这一步。
③ 每学一个点，立刻用它做点废物。一个只会打印九九乘法表的下午，比看三小时视频有用。
