01它是什么

JavaScript 是 1995 年 Brendan Eich 用十天写出来的语言。名字里带 Java，但它和 Java 没有血缘关系——当年只是为了蹭热度。

它是浏览器唯一会执行的语言。你在网页上见过的所有动画、弹窗、购物车、下拉菜单，背后都是它。现在它还能跑服务器（Node.js）、写小程序、做桌面软件（Electron）。

运行在哪浏览器里（Chrome 的 V8 引擎），或者装了 Node.js 的电脑上
类型动态类型：不用写 int，变量爱装什么装什么
单线程一次只做一件事，但它有「事件循环」，等网络的时候可以去干别的
生态全世界最大的包仓库（npm），但也有大量没人维护的垃圾
和 HTML/CSS 的分工：HTML 是骨架，CSS 是皮肤，JavaScript 是肌肉——只有它能「动」。

07运算 · 两个大坑

console.log(7 + 2);      // 9
console.log(7 / 2);      // 3.5  ← 和 C/Java 不同，没有整数除法
console.log(7 % 2);      // 1
console.log(2 ** 10);    // 1024

console.log("3" + 1);    // "31"  ← 坑一：+ 遇到字符串就拼接
console.log("3" - 1);    // 2     ← 减号会强制转数字
console.log(1 + 2 + "3"); // "33" ← 从左往右算

console.log(1 == "1");   // true  ← 坑二：== 会转换类型
console.log(1 === "1");  // false ← === 严格比较，类型也要一致
console.log(NaN === NaN); // false ← NaN 不等于任何东西

let max = 3 > 1 ? 3 : 1;  // 三元
+数字相加，字符串拼接。只要一边是字符串，结果就是字符串
== vs ===== 会转类型，=== 不会。永远用 ===
NaN「不是数字」，判断要用 Number.isNaN(x)
小数0.1 + 0.2 得 0.30000000000000004，涉及钱要小心
用 === 这一条能省你一半的诡异 bug。团队的代码规范里，== 基本是禁止的。

}

12数组 · 最常用的数据结构

let list = ["拿铁", "美式"];
list.push("摩卡");          // 末尾加
list.unshift("浓缩");        // 开头加
console.log(list.length);    // 4
console.log(list[0]);        // 浓缩
list.pop();                  // 删末尾
list.shift();                // 删开头
list.splice(0, 1);           // 从下标 0 删 1 个

let nums = [3, 1, 2];
nums.sort((a, b) => a - b);  // 数字排序要传比较函数
console.log(nums);            // [1, 2, 3]

// 三个最常用的「变换」
let doubled = nums.map(x => x * 2);          // [2, 4, 6]
let big = nums.filter(x => x > 1);           // [2, 3]
let sum = nums.reduce((s, x) => s + x, 0);   // 6
console.log(nums.includes(2));                // true
map每个元素变成另一个，返回新数组
filter筛选，返回新数组
reduce把数组「压」成一个值（求和、求最大）
sort默认按字符串排序，数字必须传 (a,b) => a - b
坑：[10, 9, 1].sort() 得到 [1, 10, 9]——因为默认按字符串比。数字排序一定要传比较函数。

13对象 · 一组有名字的数据

let coffee = {
    name: "拿铁",
    price: 32,
    hot: true,
    desc: function () {
        return this.name + " ¥" + this.price;
    }
};

console.log(coffee.name);        // 拿铁
console.log(coffee["price"]);    // 32
coffee.price = 35;               // 改
coffee.size = "大杯";             // 加新属性
delete coffee.hot;               // 删
console.log(coffee.desc());

// 解构
let { name, price } = coffee;
console.log(name, price);

// 可选链：对象可能是空的时候
console.log(coffee?.supplier?.phone);   // 不会报错，得到 undefined
点 vs 方括号名字固定用点；名字是变量用方括号 obj[key]
this在对象的方法里指这个对象本身
解构let { name } = obj 一行取出字段
可选链 ?.中间有一层是 null/undefined 就停下，返回 undefined，不报错
对象和数组的区别：数组按顺序取（list[0]），对象按名字取（obj.name）。

14函数 · 三种写法

// 1. 声明（会提升，能在定义前调用）
function add(a, b) {
    return a + b;
}

// 2. 函数表达式（赋值给变量）
const sub = function (a, b) {
    return a - b;
};

// 3. 箭头函数（最常用，写法短）
const mul = (a, b) => a * b;
const say = name => console.log("你好，" + name);

// 默认参数
function greet(name = "客人") {
    return "你好，" + name;
}
console.log(greet());        // 你好，客人
console.log(greet("阿猫"));   // 你好，阿猫

// 函数也是值，可以当参数传
[1, 2, 3].map(x => x * 2);
箭头函数(参数) => 返回值。只有一行时不用写 return
区别箭头函数没有自己的 this，它跟着外层的 this 走
参数JS 不检查参数个数，少传就是 undefined
什么时候用哪种：回调、数组方法用箭头函数；需要在对象里用 this 的方法，用普通函数。

15作用域与闭包

let a = 1;              // 全局

function outer() {
    let b = 2;          // 函数作用域
    if (true) {
        let c = 3;      // 块级作用域（let/const 才有）
        console.log(a, b, c);
    }
    // console.log(c);  // 报错：c 出不来
}

// 闭包：函数记住了它出生时的变量
function counter() {
    let n = 0;
    return function () {
        n++;
        return n;
    };
}

const next = counter();
console.log(next());   // 1
console.log(next());   // 2
console.log(next());   // 3
块级作用域let/const 只在最近的一对 { } 里有效
闭包内部函数「记住」了外部函数的变量，外部函数结束后那些变量还在
经典坑循环里用 var 绑事件，所有回调拿到的是同一个 i（最后的值）
闭包不是什么玄学：它就是「函数 + 它记得的那些变量」。计时器、防抖、模块私有变量，全靠它。

17事件 · 让页面响应

<button id="btn">点我</button>
<ul id="list">
    <li>第一项</li>
    <li>第二项</li>
</ul>

<script>

18表单 · 取值与拦住提交

<form id="form">
    <input id="name" placeholder="名字">
    <input id="age" type="number" placeholder="年龄">
    <button type="submit">提交</button>
</form>
<p id="msg"></p>

<script>
document.querySelector("#form").addEventListener("submit", function (e) {
    e.preventDefault();                 // 拦住默认的整页刷新

    let name = document.querySelector("#name").value.trim();
    let age = document.querySelector("#age").value;

    if (!name) {
        document.querySelector("#msg").textContent = "名字不能空";
        return;
    }
    if (Number(age) < 0 || Number(age) > 120) {
        document.querySelector("#msg").textContent = "年龄不对";
        return;
    }

    document.querySelector("#msg").textContent = "提交成功：" + name;
    e.target.reset();                   // 清空表单
});
</script>
preventDefault取消元素默认行为（表单提交会刷新页面、链接会跳转）
.value输入框的值，永远是字符串
前端校验只为体验。真正安全靠后端校验，用户按 F12 就能改
这个模式你以后会写一千遍：拦住提交 → 取值 → 校验 → 成功或提示 → 清空。

19JSON 与 localStorage

// 对象 → 字符串（存之前）
let user = { name: "阿猫", age: 18 };
let text = JSON.stringify(user);
console.log(text);                 // {"name":"阿猫","age":18}

// 字符串 → 对象（读之后）
let back = JSON.parse(text);
console.log(back.name);            // 阿猫

// 存在浏览器里，关掉页面还在
localStorage.setItem("user", text);
let saved = localStorage.getItem("user");
console.log(saved ? JSON.parse(saved).name : "没有");

// 数组也一样
let cart = [{ id: 1, qty: 2 }];
localStorage.setItem("cart", JSON.stringify(cart));

localStorage.removeItem("user");
// localStorage.clear();   // 别手滑，会清空全部
JSON.stringify对象/数组 → 字符串
JSON.parse字符串 → 对象，格式不对会抛异常
localStorage只能存字符串，永久保存在这台浏览器
sessionStorage关掉标签页就没了
只记得「这台浏览器」：换设备、换浏览器、清缓存，数据就没了。要跨设备，必须走后端。

20定时器 · 让事情晚点发生

// 多久之后执行一次
let timer = setTimeout(function () {
    console.log("3 秒到了");
}, 3000);

clearTimeout(timer);        // 取消它

// 每隔一段时间执行
let tick = setInterval(function () {
    console.log("每秒一次");
}, 1000);

setTimeout(function () {
    clearInterval(tick);    // 5 秒后停
}, 5000);
setTimeout延迟执行一次，返回一个编号
setInterval重复执行，一定要记得 clearInterval，否则越积越多
时间单位是毫秒。不保证精确，主线程忙的时候会推后
常见 bug：切页面、切标签时忘了清定时器，回来发现轮播转得飞快。离开时 clearInterval。

21异步 · Promise 与 async/await

// 一个「以后才有结果」的操作
function wait(ms) {
    return new Promise(function (resolve) {
        setTimeout(function () { resolve("等完了"); }, ms);
    });
}

// 旧写法：链式 then
wait(1000).then(function (msg) {
    console.log(msg);
});

// 新写法：async / await（推荐）
async function run() {
    console.log("开始");
    let msg = await wait(1000);     // 等它完成再往下走
    console.log(msg);
    console.log("结束");
}
run();
为什么异步JS 单线程，等网络的时候不能把整个页面卡住
Promise「将来会有结果」的盒子，有 resolve 和 reject
await等 Promise 出结果，只能在 async 函数里用
错误处理try { await ... } catch (e) { ... }
一句话：await 让异步代码看起来像同步，读起来顺得多。现代代码基本都这么写。

22fetch · 和服务器说话

async function load() {
    try {
        let res = await fetch("https://example.com/api/list");
        if (!res.ok) throw new Error("HTTP " + res.status);
        let data = await res.json();
        console.log(data);
    } catch (e) {
        console.log("请求失败：", e.message);
    }
}

// 发数据
async function save(user) {
    let res = await fetch("https://example.com/api/user", {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify(user)
    });
    return res.json();
}
fetch发请求，返回 Promise。要 await 两次：一次拿响应，一次拿内容
res.ok状态码 200~299 为 true。404、500 不会自动报错，要自己判断
res.json()把返回的 JSON 解析成对象
CORS跨域请求要对方允许，否则浏览器直接拦掉
坑：网络断了、跨域被拦，fetch 会直接抛异常——所以一定要 try/catch，不然页面就静悄悄没反应。

23模块与类 · 代码长大之后

没有 private较新版本才有 #field；一般靠约定（下划线开头表示内部用）
先别急着学框架：模块和类搞清楚，Vue/React 的代码你才看得懂。

Console看报错、打印、直接敲代码试
Elements看 DOM 和 CSS，改样式即时生效

Application看 localStorage、Cookie

排查顺序：看 Console 红字 → 看 Network 里请求成没成 → 断点看变量。90% 的问题到第二步就找到了。

25写干净的 JS

const 优先不变的用 const，减少「谁改了它」的猜疑
避免全局别在顶层到处 let；用函数、模块把变量关起来
函数短超过 30 行就拆
命名isLoading、userList，一眼看出是什么
别用魔法数if (code === 403) 写成常量 FORBIDDEN
早返回先处理异常情况，正常逻辑放最后，少一层缩进
// 不好
function f(u) {
    if (u) {
        if (u.name) {
            return u.name;
        }
    }
}

// 好
function nameOf(u) {
    if (!u) return "";
    if (!u.name) return "";
    return u.name;
}
真话：JS 的坑已经够多了（==、this、类型转换）。别自己再造新的。

26动手：写一个待办清单

目标：输入 → 添加 → 勾选完成 → 删除 → 刷新还在。用到数组、DOM、事件委托、localStorage。

<!DOCTYPE html>
<html lang="zh-CN">
<head><meta charset="utf-8"><title>待办</title>
<style>
    body { font-family: sans-serif; max-width: 420px; margin: 40px auto; }
    li { margin: 8px 0; }
    .done { text-decoration: line-through; color: #999; }
</style>
</head>
<body>
    <h2>待办清单</h2>
    <input id="input" placeholder="要做什么？">
    <button id="add">添加</button>
    <ul id="list"></ul>

    <script>
    let todos = JSON.parse(localStorage.getItem("todos") || "[]");

    const listEl = document.querySelector("#list");

    function save() {
        localStorage.setItem("todos", JSON.stringify(todos));
    }

    function render() {
        listEl.innerHTML = "";
        todos.forEach(function (t, i) {
            let li = document.createElement("li");
            li.className = t.done ? "done" : "";

            let span = document.createElement("span");
            span.textContent = t.text;
            span.style.cursor = "pointer";
            span.dataset.index = i;

            let del = document.createElement("button");
            del.textContent = "删除";
            del.dataset.del = i;

            li.appendChild(span);
            li.appendChild(del);
            listEl.appendChild(li);
        });
    }

    document.querySelector("#add").addEventListener("click", function () {
        let input = document.querySelector("#input");
        let text = input.value.trim();
        if (!text) return;
        todos.push({ text: text, done: false });
        input.value = "";
        save();
        render();
    });

    // 事件委托：一个监听器管所有项
    listEl.addEventListener("click", function (e) {
        if (e.target.dataset.index !== undefined) {
            let i = Number(e.target.dataset.index);
            todos[i].done = !todos[i].done;
            save();
            render();
        }
        if (e.target.dataset.del !== undefined) {
            let i = Number(e.target.dataset.del);
            todos.splice(i, 1);
            save();
            render();
        }
    });

    render();
    </script>
</body>
</html>

这段代码在讲什么

第 1 步数据先用一个数组 todos 表示
第 2 步render() 负责「把数据画出来」，每次改完都重画
第 3 步事件委托：一个监听器处理所有 li 的点击和删除
第 4 步dataset 把下标存到元素上，点击时取出来
练手方向（自己动手改）：加「全部 / 未完成 / 已完成」筛选；加「清空已完成」；加编辑功能；按回车也能添加。你改得动，才算真的看懂了。

27独立项目：做一个「搜索过滤列表」

这一节没有完整代码。给你需求、验收标准、和卡住时的提示。

要做什么

1页面上有一个搜索框，下面是一列表（电影、书、同学都行，自己编 10 条数据）
2边打字边过滤，不用点按钮
3没有结果时显示「没有找到」
4搜索词高亮显示（可选，加分）

验收标准

1输入「阿」，列表只剩包含「阿」的项
2清空输入框，全部恢复
3不区分大小写（英文时有用）
4数据是数组，渲染由一个 render(list) 函数完成

卡住时的提示

提示 1用 input 事件，不是 click：inputEl.addEventListener("input", ...)

29结语

JavaScript 是最容易被低估、也最容易被高估的语言。

说它被低估，是因为很多人只把它当「让按钮动一下」；说它被高估，是因为会写 console.log 的人也说自己会前端。

真正的分界线不在语法，在能不能把一个交互做稳：边界情况、加载失败、空数据、重复点击——这些才是前端工程师每天在想的事。

三个忠告：
① 用 ===，别用 ==。这一条能省你一半的诡异 bug。
② 先画出来，再想优雅。能跑的代码会告诉你哪里不好。
③ F12 是你的老师。任何网页都能拆开看，这是前端独有的特权。

—— 龙潜猫隐
