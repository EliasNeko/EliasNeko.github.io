Lua：藏在游戏里的脚本

几百 KB 的解释器，能塞进任何程序里，给它加一层可改的逻辑。

11 节难度 低更新 2026-10-23

01它是什么

Lua 是一个很小的脚本语言，整个解释器只有几百 KB，所以常被嵌进别的程序里：游戏引擎（魔兽世界的插件）、路由器、嵌入式设备。

它自己不太能单独做网站，但「给一个已经有的程序加可改的逻辑」，它是首选。

02装好、跑起来

Windows 可以去 luabinaries 下载，或者装 LuaDist。装完：

lua -v
lua hello.lua
print("你好，Lua")
坑：Windows 上容易装成 5.1 和 5.4 两个版本，插件开发常用 5.1，新项目用 5.4，先看清楚自己装的是哪个。

03变量和类型

local name = "咖啡"
local price = 32
local ok = true
local nothing = nil

print(type(name), type(price), type(nil))

默认是全局变量，加 local 才是局部。写库、写函数时永远加 local，不然会污染全局。

坑：nil 和 false 是唯二的假值，0 和 "" 在 Lua 里都算真——和 JavaScript 不一样。

04表：数组和字典是同一个东西

local list = { "咖啡", "茶", "果汁" }
print(list[1])          -- 咖啡（下标从 1 开始）

local stock = { coffee = 10, tea = 4 }
print(stock.coffee)     -- 10
stock.juice = 6

for i, v in ipairs(list) do print(i, v) end
for k, v in pairs(stock) do print(k, v) end
坑：下标从 1 开始，不是 0。这是新手最常见的越界来源。
坑：#list 只对连续数组可靠；中间有 nil 时长度是未定义的。

05函数和多返回值

local function add(a, b)
    return a + b
end

local function minmax(a, b)
    if a < b then return a, b end
    return b, a
end

local lo, hi = minmax(5, 3)
print(add(1, 2), lo, hi)

函数可以返回多个值，也可以把函数当参数传——Lua 里函数就是值。

06控制流

local score = 85

if score >= 90 then
    print("优")
elseif score >= 60 then
    print("及格")
else
    print("不及格")
end

for i = 1, 3 do print(i) end

local n = 0
while n < 3 do n = n + 1 end
坑：Lua 里 ~= 才是不等于，!= 会直接语法错误。

07字符串

local s = "咖啡,茶,果汁"
print(#s)                          -- 长度
print(s:upper())
print(s:sub(1, 2))

for part in s:gmatch("[^,]+") do
    print(part)
end

.. 是拼接："a" .. "b"。没有 +，用 + 会报错。

08模块

-- money.lua
local M = {}

function M.yuan(n)
    return string.format("¥ %.2f", n)
end

return M
local money = require("money")
print(money.yuan(32))
坑：require 只执行一次，结果会被缓存。重复 require 不会重新加载，改动代码要重启。

09元表：给表加“魔法”

local v = { x = 1, y = 2 }
v.__add = function(a, b) return { x = a.x + b.x, y = a.y + b.y } end

local w = setmetatable({ x = 3, y = 4 }, v)
local sum = w + w
print(sum.x, sum.y)   -- 6 8

元表决定了「这个表被 +、被索引、被 tostring 时会发生什么」。面向对象在 Lua 里就是用元表 + 表模拟出来的。

坑：元表是共享的，改一个对象的元表会影响所有用它的对象。做类的时候把方法放在元表的 __index 上，而不是每个实例一份。

10动手项目：命令行记账

要求：lua book.lua add 32 咖啡 记一笔，lua book.lua list 列出全部并算总额，数据存 book.txt。

验收：加三笔能列出、总额对得上；文件不存在时当空账本；金额不是数字时给提示而不是崩。

提示：

  • 参数在全局表 arg 里，arg[1] 是第一个参数
  • 写文件用 io.open(path, "a")，读用 io.lines
  • 转数字用 tonumber，失败返回 nil，正好用来校验
