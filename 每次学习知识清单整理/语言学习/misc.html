怎么学的

每一门都按同一个节奏走：它是什么 → 装上能跑 → 核心语法 → 容易踩的坑 → 一个自己动手的小项目。不追求把所有 API 讲完，先把「能干活」的那部分讲透。

先学哪个：想做后端先看 MySQL，想写工具先看 Git 和 Node.js，想弄懂内存再看 Rust。四门语言按兴趣挑，不用全学。
