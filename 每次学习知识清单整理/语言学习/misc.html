一 · 学语言

Rust筹备中
没有垃圾回收，也不会崩
用「所有权」在编译期解决内存问题。学起来陡，但写出来的程序又快又稳，现在连 Linux 内核都在用。
适合：想理解内存、又不想被指针折磨的人

Go筹备中
语法少，天生会并发
Google 做的后端语言，一个 goroutine 就是一条轻量线程。国内很多云原生项目（Docker、K8s）都是它写的。
适合：想写后端、又嫌 Java 重的人

Lua筹备中
藏在游戏里的脚本
整个语言只有几百 KB，常被嵌进游戏引擎（比如《魔兽世界》的插件）和硬件里做「可改的逻辑」。
适合：对游戏、嵌入式有兴趣的人

Kotlin筹备中
安卓现在的官方语言
跑在 JVM 上，能直接用 Java 的库，但写起来短很多：空指针在类型里就被拦住了。
适合：学完 Java 想再往前走一步的人

MySQL筹备中
数据最终住在哪
从「表、行、列」讲到建表、增删改查、索引。学完后端的那一刻，你总会需要它。
计划：概念 → 建库建表 → 增删改查 → 索引 → 和后端连起来
