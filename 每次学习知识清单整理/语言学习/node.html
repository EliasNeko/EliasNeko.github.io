Node.js：让 JS 跑在服务器上

它不是新语言，是把浏览器的 V8 引擎搬到了电脑上。

10 节难度 中等更新 2026-10-23

01它是什么

Node.js 不是新语言，是把 Chrome 的 V8 引擎搬到了电脑上，让 JavaScript 能脱离浏览器跑。写后端、写脚本、写工具，都能用它。

它的特点：单线程 + 事件循环。一段代码在等文件、等网络的时候，会切去干别的，所以一个人也能扛不少请求。

适合谁：已经会 JS，想让它「出浏览器」的人。

02装好、跑起来

node -v
npm -v

node hello.js
console.log("你好，Node");
坑：node 是运行环境，npm 是包管理器，两个都要有版本号才算装好。装完不重开终端会找不到。

03npm 和 package.json

npm init -y
npm install express
npm install --save-dev nodemon

package.json 记着项目名、依赖、脚本命令；node_modules 是装下来的包，不要提交进 git。

"scripts": {
  "start": "node index.js",
  "dev": "nodemon index.js"
}
坑：node_modules 一定要写进 .gitignore；别人拿到项目跑一次 npm install 就还原了。

04模块

// money.js
function yuan(n) { return "¥ " + n.toFixed(2); }
module.exports = { yuan };

// index.js
const { yuan } = require("./money");
console.log(yuan(32));

新版也能用 import/export，但要在 package.json 里加 "type": "module"。老项目多半还是 CommonJS，两种都认识最好。

坑：require("./money") 少了 ./ 会去 node_modules 里找，报「Cannot find module」。

05读写文件

const fs = require("fs");

const text = fs.readFileSync("a.txt", "utf8");
fs.writeFileSync("b.txt", text.toUpperCase(), "utf8");

带 Sync 的是同步，简单但会卡住整个进程；服务器里一般用异步或 Promise 版：

const fs = require("fs/promises");

async function main() {
  const text = await fs.readFile("a.txt", "utf8");
  console.log(text.length);
}
main();

06用 http 写个服务器

const http = require("http");

http.createServer((req, res) => {
  res.writeHead(200, { "Content-Type": "application/json; charset=utf-8" });
  res.end(JSON.stringify({ ok: true, path: req.url }));
}).listen(3000, () => {
  console.log("http://127.0.0.1:3000");
});
坑：中文不设 charset=utf-8 会乱码；res.end() 之后不能再写，否则报错。

07Express：路由和 JSON

const express = require("express");
const app = express();
app.use(express.json());

app.get("/api/hello", (req, res) => res.json({ msg: "你好" }));

app.post("/api/orders", (req, res) => {
  res.json({ got: req.body });
});

app.listen(3000);
坑：不写 app.use(express.json())，req.body 永远是 undefined——这是新手最常见的「POST 收不到数据」。

08async/await 和 fetch

async function getTitle(url) {
  const res = await fetch(url);
  if (!res.ok) throw new Error("HTTP " + res.status);
  const html = await res.text();
  return html.match(/<title>(.*?)<\/title>/)?.[1] || "没有标题";
}

await 只能写在 async 函数里；忘记 await，拿到的是 Promise 对象，不是结果。

坑：Node 18 之前没有全局 fetch，要装 node-fetch。先 node -v 看版本。

09动手项目：一个小接口

要求：写一个服务，GET /api/list 返回数组（从 data.json 读），POST /api/add 往里加一条并写回文件。

验收：curl 或浏览器能看到 JSON；POST 之后 GET 能读到新加的那条；data.json 不存在时当空数组，不崩。

提示：读写用 fs/promises；加锁问题先不管，单用户够用。

10往哪走

把 Express 的路由、中间件用熟，再看数据库（mysql2、pg）、鉴权（JWT）、部署（Render、Railway）。

一句话：Node 让同一种语言同时写前台和后台——但「能写」不等于「该写」，职责还是要分清。
