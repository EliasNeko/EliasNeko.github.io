01它是什么

Python 是一门「读起来像英语」的编程语言。写它的时候，你更像在写一份步骤说明，而不是在跟机器较劲。

1991 年由一个荷兰人做出来，名字取自一个喜剧团体 Monty Python——跟蟒蛇没关系。它最在意一件事：代码是写给人读的，顺便让机器执行。

举个最直白的对比。同样是打印十个数字：

# C 语言
for (int i = 0; i < 10; i++) { printf("%d\n", i); }

# Python
for i in range(10):
    print(i)

少了大括号、少了分号、少了类型声明。代价是它跑得慢（大概慢 10 到 100 倍），所以它不做游戏引擎、不做操作系统，它出现在「要把人从重复劳动里捞出来」的地方。

一句话：它不擅长把每件事做到最快，它擅长让你最快把事做完。

02能干什么

不用背，看一眼有印象就行——将来你需要哪块，回来查这块。

场景它在做什么常用库
数据分析几万行 Excel 读进来、算指标、出图pandas matplotlib
自动化办公批量改名、合并表格、生成 Word/PDFopenpyxl python-docx
爬虫自动下载网页上的公开数据requests BeautifulSoup
网站后端做接口、存数据、给前端递内容Flask Django FastAPI
人工智能训练模型、图像识别、大模型PyTorch scikit-learn
小工具定时提醒、整理文件、算成绩标准库就够
实话：你不需要全都学。选一个你现在就想解决的问题，从它开始。学语言最好的理由，是「我有件事想让它替我干」。

03学完能找什么工作

先看真相，再看希望。大学四年最怕的不是学不会，是学完了发现方向不对。

方向实际做什么一句实话
数据分析清洗数据、做报表、给决策找依据岗位多，但要会 SQL，也要懂业务
后端开发写接口、做服务、扛并发Python 岗比 Java 少，小团队和创业公司更爱用
测试 / 自动化写脚本跑测试、做自动化流程门槛相对低，需求稳定，适合当第一份工作
运维 / 脚本部署、监控、处理日志和 Linux 绑在一起学，性价比很高
算法 / AI训练模型、调参、做实验本科直接进很难，通常要硕士
爬虫抓公开数据、做数据源入门容易，但反爬和法律是坑
必须说清楚：Python 是入场券，不是护城河。只会 Python 的人竞争力有限——它得配一个领域（前端、后端、数据、测试）才值钱。语言是工具，你不是去当工具的。

04装好，让它跑起来

四步，十分钟。Windows 举例，Mac 把 python 换成 python3。

第 1 步去 python.org 下载 Windows 安装包（认准 3.10 以上）
第 2 步安装第一屏，务必勾上 Add python.exe to PATH（不勾，后面全是麻烦）
第 3 步按 Win + R 输入 cmd，敲 python --version，看到版本号就成了
第 4 步敲 python 进入交互模式（出现 >>>），试下面三行
>>> print("你好，世界")
你好，世界
>>> 1 + 1
2
>>> exit()

交互模式适合「试一句」，不适合写程序。真正的程序要写进文件：新建 hello.py，写一行 print("你好")，在 cmd 里 python hello.py。

三个新手必踩的坑：① 缩进是语法不是排版，四个空格别用 Tab；② 文件名别叫 random.py、json.py，会把自己写的文件当成标准库；③ 报错先看最后一行，那才是真正的原因。

05第一行代码：print 和 input

程序的两条腿：往外说（print）、往里收（input）。

print("你好，世界")
print("咖啡", "拿铁", sep=" + ")      # 自定义分隔
print("这一行不换行", end="")          # 默认结尾是换行，可以改
print("，接在后面")

name = input("你叫什么名字？")
print("你好，" + name)
print把东西显示出来。可以一次打多个，用逗号隔开
input停下来等你输入，按回车才算完。拿到的永远是字符串
第一个大坑：input() 返回的是字符串。想让它当数字用，必须 int(input(...))——不转，等下算钱的时候就是 "3" + "5" = "35"。

06变量 · 给数据起个名字

是什么一个名字，指向一个值。名字换内容，值就跟着换。
怎么写名字 = 值，不用提前声明类型，Python 自己认。
和谁搭任何东西都能装：数字、文字、列表、函数，甚至是另一个变量。
name = "阿猫"
age = 18
height = 1.75
is_student = True

print(name, age)
print(type(age))
print(type(height))
print(type(is_student))
输出：阿猫 18，然后 <class 'int'>、<class 'float'>、<class 'bool'>
备注：四种最常见的类型：int 整数、float 小数、str 文字、bool 真假。
命名：小写英文加下划线，total_price 比 tp 好，tp 比 a1 好。三个月后你会感谢现在的自己。

07数字与运算 · 让计算机算账

是什么加减乘除、比较大小、逻辑判断，这些符号决定了程序怎么算、怎么比。
怎么写算术 + - * / // % **；比较 == != > < >= <=；逻辑 and or not。
和谁搭if 判断、循环计数，全靠它。
print(7 + 3, 7 - 3, 7 * 3, 7 / 3)
print(7 // 3, 7 % 3, 2 ** 10)
print(10 > 3, 10 == 3)
print(True and False, True or False, not True)
输出：10 4 21 2.3333... / 2 1 1024 / True False / False True False
三个符号必记：/ 永远得小数，// 是整除取整，% 是余数（判断奇偶就靠它）。
坑：0.1 + 0.2 不等于 0.3，是 0.30000000000000004。这不是 Python 的毛病，所有语言都这样——涉及钱，用整数分来算。

08字符串 · 文字是怎么拼的

是什么一串文字。单引号双引号都行，两种完全等价。
怎么写拼接 +，格式化 f-string：f"你好 {name}"；切分 split，合并 join。
和谁搭输入、输出、文件、网页——凡是跟人打交道的地方都有它。
s = "咖啡,拿铁,dirty"
print(len(s))
print(s.split(","))
print("-".join(["a", "b", "c"]))
print(s.upper(), s.lower())
print(s[0], s[-1])
print(s[:2], s[5:8])
print("  空格  ".strip())
print(f"{'咖啡'} 花了 {32} 元")
输出：11 / ['咖啡', '拿铁', 'dirty'] / a-b-c / 咖啡,拿铁,DIRTY 咖啡,拿铁,dirty / 咖 y / 咖啡 拿铁 / 空格 / 咖啡 花了 32 元
备注：字符串不可变——replace、strip 都不改原字符串，而是返回一个新的。要写 s = s.replace(...) 才生效。
切片 s[5:8] 是「从 5 到 8，不含 8」，和 range 一个规矩。

09类型转换 · 把「3」变成 3

是什么文字和数字长得像，但不是一回事。转换就是把它们互相翻译。
怎么写int() 转整数、float() 转小数、str() 转文字。
和谁搭input、文件、爬下来的数据，进门第一件事就是转。
print("3" + "5")
print(int("3") + int("5"))
print(str(3) + str(5))
print(float("1.5") * 2)
print(int(3.9))
# print(int("3.5"))   # 会报错 ValueError
输出：35 / 8 / 35 / 3.0 / 3
坑：int() 不会四舍五入，是直接砍掉小数。int("3.5") 还会报错——得先 float("3.5") 再 int()。
口诀：从外面进来的数字，一律先转，别信它长什么样。

10if 判断 · 让程序做选择

是什么按条件走不同的路。程序所有的「聪明」，都是从这开始的。
怎么写if 条件: 换行缩进，可接 elif、else。
和谁搭比较运算符、and or not，还有 in（在不在里面）。
score = 82

if score >= 90:
    print("A")
elif score >= 80:
    print("B")
else:
    print("C")

if 60 <= score < 90:          # Python 支持连写
    print("及格，但还能再高一点")
输出：B 和 及格，但还能再高一点
备注：冒号不能少，缩进不能乱。Python 用缩进划分「谁属于谁」——这是它最不像别的语言、也最像人话的地方。
常见错：把 == 写成 =，程序不会报错，只会永远为真。

11for / while 循环 · 重复做同一件事

是什么for 是「对一堆东西逐个来」；while 是「只要条件还成立就一直来」。
怎么写for x in 一堆东西:；while 条件:（里面记得改条件，否则死循环）。
和谁搭range() 造数字，enumerate() 带序号，break 提前结束，continue 跳过这次。
for i in range(3):
    print("第", i + 1, "杯")

for i in range(1, 10, 2):        # 起点、终点、步长
    print(i, end=" ")

names = ["阿猫", "小鱼"]
for idx, n in enumerate(names):
    print(idx, n)

n = 0
while n < 3:
    n = n + 1
    if n == 2:
        continue                  # 跳过这一次
    print("还剩", n)
输出：第 1/2/3 杯；1 3 5 7 9；0 阿猫、1 小鱼；然后 还剩 1、还剩 3
备注：range(3) 是 0 1 2，不含 3。这个「左闭右开」你会记一辈子——列表下标、切片都是它。

12列表 list · 一排格子

是什么有序的一串东西。购物车、成绩表、待办清单，都是它。
怎么写[a, b, c]；append 加、remove 删、[0] 取、[a:b] 切。
和谁搭len() 长度，sort() 排序，in 判断，for 遍历。
cart = ["手冲", "拿铁", "dirty"]
cart.append("美式")
print(cart)
print(cart[0], cart[-1])
print(cart[:2])
print(len(cart))

cart.remove("拿铁")
print(cart)
print("dirty" in cart)

nums = [3, 1, 2]
nums.sort()
print(nums)
输出：['手冲','拿铁','dirty','美式'] / 手冲 美式 / ['手冲','拿铁'] / 4 / ['手冲','dirty','美式'] / True / [1, 2, 3]
备注：下标从 0 开始，-1 是最后一个。列表可变——sort() 直接改自己，sorted() 返回新的。

13元组与集合 · 两个配角

元组 tuple用 ( )，不能改。适合「一组固定的值」，比如坐标、一条记录的固定字段。
集合 set用 { }，自动去重、没有顺序。适合「有哪些人、有哪些标签」。
和谁搭元组能解包，集合能做交集并集。
point = (3, 5)
x, y = point              # 解包
print(x, y)
# point[0] = 9            # 报错：元组不能改

tags = {"咖啡", "咖啡", "猫"}
print(tags)               # 只剩两个
print(len(tags))
a = {1, 2, 3}
b = {2, 3, 4}
print(a & b, a | b)       # 交集、并集
输出：3 5 / {'咖啡','猫'} / 2 / {2,3} {1,2,3,4}
备注：新手 90% 的代码只会用到列表和字典，元组和集合是「需要时想起来还有这个」。不知道该用哪个，就用列表。

14字典 dict · 按名字找东西

是什么一堆「键 → 值」的配对。查起来快，更像真实世界的一条记录。
怎么写{"键": 值}；取值 d["键"]，键不存在会报错，用 .get() 更安全。
和谁搭for k, v in d.items() 遍历，json 模块天生跟它一家。
coffee = {"name": "手冲", "price": 32}

print(coffee["name"])
print(coffee.get("stock", 0))     # 没有这个键，返回默认值 0

coffee["price"] = 30
coffee["stock"] = 10

for k, v in coffee.items():
    print(k, "=", v)

order = {
    "user": "阿猫",
    "items": [{"name": "手冲", "qty": 2}],
}
print(order["items"][0]["name"])   # 一层层拆
输出：手冲 / 0 / name=手冲、price=30、stock=10 / 手冲
什么时候用字典：需要「用名字找」而不是「按顺序找」——一条记录、一份配置、一个 JSON。
嵌套：字典里放列表、列表里放字典，是真实数据最常见的形状，从外层往里一层层拆就对了。

15函数 def · 把一段逻辑打包

是什么给一段代码起个名字。以后喊名字就能用，还能传参数、拿回结果。
怎么写def 名字(参数): + 缩进 + return 结果。
和谁搭默认参数、关键字参数、可变参数，都是它的延伸。
def total(price, qty=1):        # qty 有默认值
    return price * qty

print(total(32))
print(total(32, 3))
print(total(qty=2, price=10))    # 按名字传，顺序无所谓

def greet(name):
    print(f"欢迎，{name}")

greet("阿猫")
print(greet("小鱼"))             # 没有 return，结果是 None
输出：32 / 96 / 20 / 欢迎，阿猫 / 欢迎，小鱼 然后 None
备注：return 一旦执行，函数当场结束。没有 return 的函数返回 None——这不是错误，是「只干活、不交货」。
坑：别用可变对象（列表、字典）当默认参数，它会在多次调用之间被共用。

16模块 import · 用别人写好的东西

是什么别人（或标准库）写好的功能包，import 进来就能用。
怎么写import 模块、from 模块 import 函数、import 模块 as 别名。
和谁搭第三方库要先装：pip install 名字。
import random
print(random.randint(1, 6))

from datetime import date
print(date.today())

import math as m
print(m.pi)

# 自己写的文件也能当模块：
# 同目录下建 tools.py，里面写 def hello(): ...
# import tools
# tools.hello()
输出：一个 1 到 6 的随机整数、今天的日期、3.141592653589793
备注：Python 自带几百个标准库，够解决大部分问题；不够时再 pip install。安装失败多半是网络，换国内镜像：pip install -i https://pypi.tuna.tsinghua.edu.cn/simple 名字。

17文件读写 · 让数据活过这一次运行

是什么把数据写进硬盘，下次打开还在。变量的命只有一次程序那么长，文件的不一样。
怎么写with open(文件名, "w", encoding="utf-8") as f:，w 写、r 读、a 追加。
和谁搭json 存结构化数据，csv 存表格。
with open("note.txt", "w", encoding="utf-8") as f:
    f.write("第一行\n")
    f.write("第二行\n")

with open("note.txt", "r", encoding="utf-8") as f:
    for line in f:
        print(line.strip())

import json
data = {"name": "阿猫", "scores": [90, 85]}
with open("data.json", "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False, indent=2)
输出：第一行 / 第二行，同时生成 note.txt 和 data.json
三个要点：① with 会自动关文件，比手动 close() 安全；② encoding="utf-8" 不写，Windows 上中文可能乱码；③ "w" 会清空原文件，想保留旧内容用 "a"。

18异常 try · 出错但不崩

是什么有些错误没法预防（用户乱输、文件不在、网断了），try 让你接住它。
怎么写try: 放可能出错的，except 错误类型: 放补救。
和谁搭finally 一定执行，raise 主动抛错。
try:
    n = int(input("输入一个数字："))
    print(10 / n)
except ValueError:
    print("这不是数字")
except ZeroDivisionError:
    print("不能除以 0")
else:
    print("一切正常")
finally:
    print("不管怎样都会执行")
输出：输入 abc → 这不是数字；输入 0 → 不能除以 0；输入 5 → 2.0 和 一切正常；最后都会打印「不管怎样都会执行」
备注：异常不是「错误处理」，是「允许失败」。真实程序里，用户什么都敢输，你必须接得住。

19类 class · 把数据和操作打包（了解即可）

是什么一个模板，用来批量生产「有数据、也有方法」的东西。
怎么写class 名字: + __init__ 初始化 + 普通方法。
和谁搭继承、组合，等你写出第三个类再研究。
class Coffee:
    def __init__(self, name, price):
        self.name = name
        self.price = price

    def label(self):
        return f"{self.name} ¥{self.price}"

c = Coffee("手冲", 32)
print(c.label())
输出：手冲 ¥32
备注：self 就是「这个东西自己」。新手别急着学类——函数能解决的先用函数。等你发现「数据和处理它的函数总是成对出现」，再来用类，那时你才看得懂它好在哪。

20列表推导式 · 一行顶一个循环

是什么用一种更短的方式，把「对每个元素做点什么」写在一行里。
怎么写[表达式 for x in 列表 if 条件]。
和谁搭过滤、转换、算平方，天天用。
nums = [1, 2, 3, 4, 5]

squares = [n * n for n in nums]
evens   = [n for n in nums if n % 2 == 0]
labels  = [f"第{i}名" for i in range(1, 4)]

print(squares)
print(evens)
print(labels)
输出：[1, 4, 9, 16, 25] / [2, 4] / ['第1名','第2名','第3名']
备注：推导式是「语法糖」——它和 for 循环做的事一模一样，只是更短。难读懂的时候就拆回循环，别为了短牺牲可读性。

21常用标准库 · 装了就能用，不用 pip

math开方、取整、圆周率。sqrt ceil floor pi
random随机数、随机抽。randint choice shuffle
datetime日期时间。date.today() datetime.now()
os和操作系统打交道：路径、文件、环境变量。os.getcwd() os.path.exists
json读写 JSON。dumps loads dump load
import math, random, datetime, os, json

print(math.sqrt(16), math.ceil(3.2), math.floor(3.8))
print(random.choice(["石头", "剪刀", "布"]))
print(datetime.date.today())
print(os.getcwd())
print(json.dumps({"a": 1}, ensure_ascii=False))
输出：4.0 4 3 / 随机一个 / 今天的日期 / 当前目录 / {"a": 1}
备注：这五个库能解决你 80% 的「小工具」需求。写之前先想想：标准库有没有现成的？十有八九有。

22读懂报错 · 这是最重要的技能

程序崩了不可怕，读不懂报错才可怕。看这个：

Traceback (most recent call last):
  File "demo.py", line 3, in <module>
    print(cart[3])
IndexError: list index out of range

从下往上读：最后一行是「什么错」，中间是「哪一行」，最上面是「怎么走到这儿的」。

错误类型人话常见原因
SyntaxError语法不对少冒号、括号不配对、中文标点
IndentationError缩进不对空格和 Tab 混用
NameError这名字我不认识变量名拼错、用之前没定义
TypeError类型对不上"3" + 5、函数少传参数
ValueError值不对int("abc")
IndexError下标越界列表只有 3 个，你取了第 4 个
KeyError字典里没这个键拼错键名，改用 .get()
AttributeError这东西没这个功能列表用了 .get()
排查三步：① 看最后一行是什么错误；② 看它指的第几行；③ 把那一行的变量 print 出来看看它到底是什么。90% 的 bug，打印一下就好了。

23写给人看的代码

代码是写给下一个读它的人看的，而那个人大概率是三个月后的你。

缩进统一 4 个空格（别用 Tab，编辑器里设置一下）
命名变量/函数用 小写下划线，类用 大驼峰，常量用 全大写
空行函数之间空两行，逻辑段落之间空一行
注释说「为什么」，不说「是什么」——i += 1 # 计数 这种注释是废话
# 不好
def f(a, b):
    return a * b * 0.9

# 好
def final_price(unit_price, quantity):
    """按九折算出总价。"""
    return unit_price * quantity * 0.9
一个检验方法：把你的代码念出来。能念成人话，就是好代码；念出来像咒语，就该改了。

24动手：写一个「记账本」

把前面二十多节串起来，做一个真能用的小东西：命令行记账本——记一笔、看清单、算合计，关掉再打开数据还在。

需求① 记一笔（名称 + 金额）② 看全部账目和合计 ③ 退出时自动保存
数据一条记录一个字典，全部记录一个列表：[{"item": "咖啡", "cost": 32}]
存哪同目录的 records.json，用 json 读写
用到字典、列表、函数、while、if、文件、异常
import json
import os

FILE = "records.json"

def load():
    if not os.path.exists(FILE):
        return []
    with open(FILE, "r", encoding="utf-8") as f:
        return json.load(f)

def save(records):
    with open(FILE, "w", encoding="utf-8") as f:
        json.dump(records, f, ensure_ascii=False, indent=2)

def main():
    records = load()
    while True:
        cmd = input("1 记一笔 / 2 看账本 / 3 退出：")

        if cmd == "1":
            item = input("买了什么：")
            cost = float(input("多少钱："))
            records.append({"item": item, "cost": cost})
            save(records)
            print("记下了。")

        elif cmd == "2":
            total = 0
            for r in records:
                print(f'{r["item"]}   ¥{r["cost"]}')
                total = total + r["cost"]
            print(f"合计 ¥{total}")

        elif cmd == "3":
            break

main()

这段代码在讲什么

load / save一对读写函数。读之前先问「文件在不在」，避免第一次运行就崩
with open(...)结束时自动关文件，比手动 close() 安全
ensure_ascii=False让 json 里存中文本身，而不是 \u5496 这种转义
while True + break菜单程序的经典写法：一直转，直到你喊停
f'{r["item"]}'外层单引号、内层双引号，字典取值不用转义
练手方向（自己动手改）：加一个「删除第 n 笔」；加「按分类统计」；把金额改成必须大于 0，输了就重来。你改得动，才算真的看懂了。

25独立项目：写一个「单词本」

这一节没有完整代码。给你需求、验收标准、和卡住时的提示。自己写出来，比抄十遍有用。

要做什么

功能① 添加单词（英文 + 中文）② 开始复习 ③ 退出
复习规则随机抽 5 个（不够就有几个抽几个），显示中文，让你输入英文
判分答对 +1，答错显示正确答案；结束打印「本轮 5 题，答对 3 题」
数据存 words.json，结构自己定——建议 [{"en": "apple", "cn": "苹果"}]
容错单词本为空时开始复习，不能崩，要提示「还没有单词」

验收标准（做到了才算完成）

1关掉程序再打开，之前加的单词还在
2输入 Apple / APPLE 也算对
3随便乱输菜单数字，程序不崩，能回到菜单
4至少有 3 个函数，每个不超过 25 行

卡住时的提示（按顺序看，别一次看完）

提示 1随机抽：random.sample(列表, 5)，但列表不足 5 个会报错——先判断长度
提示 2比较答案：你输入的.strip().lower() == 正确答案.lower()
提示 3把「加单词」「复习」「存盘」各写成一个函数，main() 只放菜单循环
提示 4读文件时用 try/except 包住——json 文件被改坏了，程序要能活下来
做完之后：加一个「错题本」，答错的单词单独存一份，下次优先复习。这一小步，就是所有背单词软件的雏形。

27结语

Python 最好的地方，不是它简单，是它不拦着你。

你脑子里的一个念头——「这个表格每天手动整理好烦」——从念头到跑起来，中间只隔二三十行代码。这种「想到就能做到」的爽感，是很多语言给不了的。

但它也有代价。写起来容易，意味着写烂也容易：变量名乱起、一个函数两百行、复制粘贴三遍。三个月后你回来改，会想掐死现在的自己。所以从今天开始养成三个习惯——

三个忠告：
① 命名比注释重要。叫 total_price 的变量不需要注释；叫 a1 的变量，注释也救不了。
② 先让它跑，再让它对，最后让它好看。顺序反了，你会在第一行就卡死。
③ 每学一个点，立刻用它做点废物。一个只会打印九九乘法表的下午，比看三小时视频有用。

最后一句：语言是工具，不是身份。你不是「一个学 Python 的人」，你是「一个想做出点东西的人」——Python 只是你现在手里最顺手的那把。

—— 龙潜猫隐
