01这是什么考试

全国计算机等级考试（NCRE），教育部考试中心主办，面向社会，不限学历、不限年龄，谁都能报。

二级是「程序员预备级」的难度：会写程序、能读懂一段代码、能完成指定功能。它不考算法竞赛，也不考工程能力，考的是「你会不会用这门语言把事做完」。

考试时长120 分钟
满分 / 及格100 分 / 60 分及格（上机考，无纸笔）
一年几次一般 3 月和 9 月各一次，具体看各省通知
报名各省教育考试院官网，通常提前 1–2 个月
证书有用吗部分学校能抵学分 / 评优加分；部分岗位（国企、事业单位、教师）会看。它不是万能的，但便宜、门槛低，性价比不错
提醒：题型、分值、大纲每年可能有微调，报名前务必去官网看当年的考试大纲。这一页给的是通用结构和常见考法。

02考哪些科目，选哪个

科目适合谁难度
二级 Python零基础、想快速拿证、以后想碰数据/AI相对低，语法短，上手快
二级 C学过 C、要考研/嵌入式方向中，指针和内存容易翻车
二级 Java学过后端、学校开了 Java 课中，概念多（类、继承、接口）
二级 C++要走算法/游戏方向偏高
二级 MySQL / Web / Office想快速拿证、方向偏应用较低
给你的建议：如果你的专业是软件技术、计算机应用这类，报 Python 或 Java 都合理——Java 和你正在学的后端对得上，Python 上手更快。别为了「看起来难」去报 C，除非你真的在用 C。

03Python 科目考什么（大纲范围）

官方大纲把内容分成七块，你按这个顺序复习就不会漏：

一、基本语法缩进、注释、变量、命名规则、保留字、input / print、源程序格式
二、基本数据类型整数、浮点、复数、字符串及常用操作、类型判断与转换
三、程序控制结构if / elif / else、for、while、break / continue、异常处理 try
四、函数与代码复用定义与调用、参数传递、默认参数、变量作用域、递归
五、组合数据类型列表、元组、字典、集合、切片、遍历
六、文件与数据格式化文件打开关闭、读写、逐行处理、CSV / JSON 基本读写
七、计算生态标准库 turtle random time math；第三方库 jieba wordcloud numpy matplotlib 的基本用法
还有 10 分公共基础知识（选择题里）：数据结构与算法、程序设计基础、软件工程基础、数据库设计基础。这块纯背，别花太多时间，但也不能全丢。

04题型与分值

题型分值说明
单项选择题约 40 分40 题，每题 1 分，含 10 分公共基础知识
基本操作题约 15 分补全代码、改错，通常 3 小题，最容易拿分
简单应用题约 25 分按功能要求写一段程序，通常 2 题
综合应用题约 20 分1 题，综合读写文件 / 统计 / 输出
策略：先扫一遍，先做基本操作题（送分，五分钟能拿十几分），再做简单应用，最后啃综合。选择题不会就蒙，别超过 15 分钟。

06三类操作题怎么答

基本操作题（15 分，必须全拿）

给一段不完整的代码，让你填 _____，或指出错误并改正。考的都是最基础的东西：

常见填空函数名、参数、循环范围、判断条件、return、文件模式
常见改错缩进错、= 与 == 混用、中文标点、变量名拼错
技巧先看输出结果，反推「中间该发生什么」，再决定填什么

简单应用题（25 分，拉开差距的地方）

给一段文字描述（比如「统计一段文本里每个词出现的次数」），让你写完整程序。分两步走：

第 1 步把需求翻译成数据流：输入是什么 → 中间怎么处理 → 输出什么格式
第 2 步先写能跑的最笨版本，再优化。能跑比优雅重要

综合应用题（20 分，通常是文件 + 统计）

一般流程固定：读文件 → 处理数据 → 统计/排序 → 按格式输出。背下这个骨架，题目怎么变都不慌：

with open("data.txt", "r", encoding="utf-8") as f:
    lines = f.readlines()

result = {}
for line in lines:
    key = line.strip().split(",")[0]
    result[key] = result.get(key, 0) + 1

for k in sorted(result, key=result.get, reverse=True):
    print(k, result[k])
注意分号和小数位数。题目要求「保留两位小数」就用 f"{x:.2f}"，要求「用逗号分隔」就别用空格——输出格式错，整题可能没分。

07最容易丢分的十个地方

1缩进用了 Tab，和空格混用 → IndentationError
2以为 input() 拿到的是数字，直接做加法
3range(5) 以为是 1–5，其实是 0–4
4列表切片 [a:b] 不含 b
5字典用 d["不存在的键"] 直接崩，应该用 .get()
6return 写在循环里以为会继续跑，其实函数结束了
7文件写完没关（或者用 w 模式把原文件清空了）
8try/except 把异常吞掉，导致后面逻辑全错
9输出格式不对：多一个空格、少两位小数、该换行没换
10题目要求用函数，你写成一整段平铺代码
这十条，比多刷五十道题有用。考场上的失分，八成不是因为不会，是因为「差一点」。

0830 天复习计划

第 1–7 天过一遍本站 Python 课程的 01–15 节，每节代码敲一遍
第 8–14 天16–23 节 + 把「记账本」独立写一遍（不看代码）
第 15–20 天刷真题选择题，错题抄在本子上（只抄错的那一个知识点）
第 21–26 天每天一道操作题，限时 20 分钟，写完对答案
第 27–30 天整套卷子限时模拟两次，熟悉 IDLE 的操作手感
关键：考试是在 IDLE 里写代码，不是 VS Code。提前用 IDLE 写几次，熟悉它的缩进提示和运行方式——考场上换编辑器，手会抖。

09考场提醒

提前到带身份证 / 准考证，提前 30 分钟到考场
先看文件题目会给素材文件（.txt / .csv），先确认路径和编码，别自己瞎猜
保存习惯写一段按一次 Ctrl + S，机器卡死不会白写
不会的题先跳过，把能拿的分拿满，最后回来蒙
交卷前把每个文件都运行一遍，确认没有红色报错
心态：二级是「合格考」不是「选拔考」，60 分就过。把基本操作题的 15 分拿满，就已经赢了一半人。

10结语

这张证书不会让你变成程序员，但它能证明一件挺重要的事：你能为了一个目标，坐下来把一本厚书啃完。

很多人卡在的不是知识点，是「报名了但没去考」「看了两章就停了」。能坐在考场里把卷子写完，已经比一半人强。

最后提醒三件事：
① 以当年官方大纲为准，这一页是地图不是答案。
② 证书是加分项，项目才是硬通货——一个能被别人打开的完整作品，比一张证书更能说明问题。
③ 考完别把 Python 放下，趁热做个小工具，不然三个月就忘光。

—— 龙潜猫隐
